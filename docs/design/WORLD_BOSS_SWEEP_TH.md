# World Boss และกวาดล้าง — ส่วนเพิ่มแผนพัฒนา

27 ตุลาคม 2026 (Asia/Bangkok) · สถานะ: ขอบเขตฟีเจอร์และคำแนะนำสำหรับพัฒนาต่อ ยังไม่เปิดใน runtime

เจ้าของขอเพิ่มบอสโลกให้ทุกคนในเซิร์ฟเวอร์ร่วมสู้ และก่อนหน้านี้เสนอระบบกวาดล้างด่านที่ผ่านแล้ววันละสามครั้งต่อด่านโดยเสียทรัพยากร เอกสารนี้บันทึกทั้งสองเรื่องตามคำขอ ตัวเลขเสบียง/จำนวนเข้า World Boss/ระยะเวลากิจกรรมเป็นค่าต้นแบบที่แนะนำ ไม่ใช่ข้อสรุปเศรษฐกิจที่ผ่านทดสอบ

อ่านร่วม [แผนพัฒนารวม](../DEVELOPMENT_PLAN_TH.md) และ [ระบบเลเวลร่วม/บอส](SHARED_LEVEL_TEAM_BOSSES_TH.md)

## 1. World Boss: ทั้งเซิร์ฟเวอร์ช่วยกันปราบ

รุ่นแรกแนะนำ **HP บอสส่วนกลาง ทุกคนใช้ทีมของตนเองเข้าสู้เป็นรอบ แล้วส่งผลงานที่เซิร์ฟเวอร์ตรวจมาหัก HP ส่วนกลาง** ผู้เล่นไม่ต้องออนไลน์พร้อมกันหรือรอหัวหน้าห้อง ทุกคนเห็น HP/เฟส/ความคืบหน้าและเป้าหมายรางวัลร่วมกัน หน้าสู้ยังคงระบบ turn-based อ่านเจตนาและสามสกิลของ Fateweave

นี่เป็น asynchronous server raid ซึ่งตอบโจทย์ร่วมปราบตัวเดียวกัน ส่วนการอยู่ในห้องสู้พร้อมกันหลายทีมเป็น scope ต่อจาก Co-op โดยต้องพิสูจน์การรอเทิร์น/หลุดเกม/โหลดก่อน ไม่ถือว่ามีแล้วจากการทำ HP ร่วม

ค่าต้นแบบ: หนึ่งกิจกรรมต่อสัปดาห์, เข้ารับผลงานฟรีวันละสามครั้งต่อบัญชี, รอบละไม่เกินแปดรอบศึก มีโหมดฝึกไม่รับของหรือหัก HP ไม่ใช้เสบียงกวาดล้างและไม่ขายรอบเพิ่มในรุ่นทดลอง จำนวนรอบ/สิทธิ์รายวันต้องวัดภาระรวมกับกิจกรรมอื่นก่อนเลือกจริง; ถ้าหนักเกินไปให้เปลี่ยนเป็นสิทธิ์สะสมต่อกิจกรรม

ผู้เข้าถึงระบบได้ทุกบัญชีที่ผ่านบทสอนที่จำเป็น ไม่ล็อกดาวสูง ตัวเฉพาะตู้ หรือระดับแข่งขัน มีระดับความพร้อมขั้นต่ำ/ทีมยืมสำหรับผู้เริ่มเล่นเป็นข้อเสนอที่ต้องออกแบบก่อนเปิดจริง

## 2. กลไกและความยุติธรรม

- บอสมีเจตนา/เฟสและโจทย์ เช่น ทำลายเกราะหรือหยุดการชาร์จ ทุกโจทย์บังคับต้องมีวิธีตอบอย่างน้อยสองทาง หนึ่งทางได้แน่นอนจากการเล่น
- สายรักษา/โล่/ควบคุมช่วยให้ทีมอยู่ครบและโจมตีได้ต่อ ไม่แสดงอันดับดาเมจเป็นตัวชี้คุณค่าของทุกอาชีพเพียงค่าเดียว
- HPส่วนกลางลดจากความเสียหายบอสที่ตรวจได้จริง ไม่แปลงยอดรักษาหรือโล่ที่ไม่มีใครใช้เป็นดาเมจฟรี; ของที่เกินจำเป็นและกลไกวนไม่สร้างผลงาน
- รางวัลหลักเป็นการเข้าร่วมที่มีการเล่นจริง + milestoneส่วนตัวที่เข้าถึงได้ + milestoneทั้งเซิร์ฟเวอร์ ไม่มีรางวัลพลังจำเป็นเฉพาะอันดับสูง/last hit
- เกณฑ์เข้าร่วมไม่เป็นดาเมจขั้นต่ำที่กันผู้เล่นใหม่: ตรวจคำสั่งถูกกฎหมาย/เงื่อนไขรอบหรือเป้าหมายที่บอกก่อนเข้า ต้องทดลองกับทีมสนับสนุนและทีมเริ่มต้น
- ถ้ามีอันดับ ให้เริ่มจากชื่อเกียรติยศ/ของตกแต่ง และแยกดาเมจกับการช่วยทีมอย่างอ่านได้ ไม่บวกคะแนนหลายชนิดโดยยังไม่มีสูตรตรวจว่าปั๊มไม่ได้
- HPกิจกรรมตั้งจากผู้เล่นactiveและผลรอบก่อน พร้อมกรอบขั้นต่ำ/สูงสุด กำหนดก่อนเริ่ม ไม่เพิ่ม HP กลางกิจกรรมเพราะคนช่วยเยอะ; เซิร์ฟเวอร์คนน้อยต้องรับรางวัลร่วมตามmilestoneได้แม้ไม่ปราบสำเร็จ
- หากบอสตายก่อนคนบางเขตเวลาได้เล่น ให้เข้าฝึกแบบechoที่นับสิทธิ์รางวัลเข้าร่วม/ส่วนตัวได้ตามเพดานเดิม แต่ไม่ลดHPบอสที่ตายแล้วและไม่แจกของซ้ำ

## 3. ผลงาน รางวัล และกรณีพร้อมกัน

เซิร์ฟเวอร์ออก attempt ID พร้อม bossInstanceId, rulesVersion, phaseSnapshot, roster/gear snapshot, seed, expiry และสิทธิ์ที่จองไว้ Replay/resolveจากข้อมูล authoritative ก่อนรับผลงาน ห้ามเชื่อตัวเลขดาเมจ/เวลา/รางวัลที่ client ส่งมาเฉยๆ

การจองสิทธิ์ ส่งผล รับรางวัล และคืนสิทธิ์กรณีเริ่มไม่ได้ ต้องมี idempotency และ transactionชัดเจน Disconnectกลับมาส่งattemptเดิมได้ภายในหน้าต่างที่ประกาศ; ใช้serverเวลา ไม่ใช่นาฬิกาเครื่อง การกดออกหรือหมดอายุหลังเล่นแล้วไม่ให้ลองสุ่มผลใหม่ฟรี

เฟสของattemptคงตามsnapshotเพื่อให้preview/replayตรงกัน เฟสส่วนกลางเปลี่ยนระหว่างเล่นไม่แก้กฎในศึกเงียบๆ กำหนดเวลาส่งผลและกติกาเมื่อกิจกรรมปิดก่อนเริ่มให้เห็นชัด

ผลที่ยืนยันแล้วบันทึกได้ครั้งเดียว HPส่วนกลางไม่ต่ำกว่า0 เมื่อหลายattemptจบพร้อมกันให้แยกค่าความเสียหายตรวจได้ของattemptจากจำนวนที่หักHPส่วนกลางจริง ผู้มาช่วงท้ายไม่เสียสิทธิ์ส่วนตัวเพียงเพราะมีHPเหลือน้อย แต่ต้องมีเพดานความเสียหายตามกฎ/จำนวนรอบ ไม่รวมoverkillไม่จำกัด คะแนนที่ไม่หักHPแล้วห้ามนำไปลดบอสตัวถัดไป

แยก account ledger และ global boss aggregate; ทดสอบ contention/throughput/retry ให้รองรับปริมาณจริงก่อนเลือก DOหนึ่งตัวต่อbossหรือแยกqueue/shards ห้ามอ้างว่ามี DO จึงรองรับทั้งเซิร์ฟเวอร์ได้โดยไม่มีload test

รางวัลเสนอใช้ทรัพยากรเดิม เช่น เศษดาวสากล/ตำรา/ของตกแต่ง ตามงบ P04 ไม่เพิ่มเหรียญ World Boss อีกชนิดโดยอัตโนมัติ มีประวัติผลงานและรับย้อนหลังตามช่วงเวลาที่ประกาศ ไม่เปิดช่องรับทั้งmailและclaimซ้ำ

## 4. กวาดล้างด่านที่จบแล้ว

ทิศทางจากเจ้าของ: จบด่านแล้วปลดกวาดล้าง สูงสุดวันละสามครั้งต่อด่าน และมีค่าใช้จ่าย คำแนะนำเดิมที่เก็บเป็นต้นแบบคือเสบียง1ต่อครั้ง แจก6ต่อวัน เก็บสูงสุด18 เลือกเป้าฟาร์มจากตารางด่านได้ ลงเล่นเองไม่ใช้เสบียง ตัวเลขยังต้องจำลองใน P04 ก่อนเลือกใช้

รางวัลเป็นชุดฟาร์มซ้ำที่แสดงก่อนกด ไม่รวมรางวัลครั้งแรก/หีบลับ/เควสต์เรื่อง/ปริศนา/การเลือกอีเวนต์ และไม่ทำความคืบหน้าเควสต์ประเภทนั้นอัตโนมัติ EXPค่ายถ้าจะให้ต้องมีค่าระบุเฉพาะ ไม่ยกผลทั้งเที่ยวมาบวก การจำกัดper-map/dayต้องระบุnormal/hardแยกกันหรือร่วมกันในสเปกก่อนเปิด ไม่ให้สลับโหมดเพื่อข้ามเพดาน

การใช้เสบียง+สิทธิ์รายวัน+ให้รางวัลเป็นtransactionเดียว retryไม่เสียของซ้ำหรือได้ของเพิ่ม; offline prototypeใช้วันที่เครื่องได้แต่ห้ามอ้างว่าเชื่อถือได้ สำหรับonlineต้องserverเวลาและledger P09 ไม่ใช้กวาดล้างกับWorld Boss เพราะต้องมีการร่วมเล่นตามกลไก
