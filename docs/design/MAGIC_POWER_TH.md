# พลังโจมตีและพลังเวท — เจ้าของอนุมัติ 2026-10-24

เจ้าของถามว่าดาเมจของไอร่าควรอิงพลังเสริมหรือไม่ และอนุมัติคำแนะนำให้แยกพลังโจมตีสำหรับกายภาพ กับพลังเวทสำหรับเวท รักษา และโล่ ใช้ร่วมทุกอาชีพและตรวจสมดุล การอนุมัตินี้ครอบคลุม resolver, content และการย้ายเซฟที่จำเป็นสำหรับงานนี้ แทนข้อจำกัด UI-only ของงาน rewards เดิมและข้อกำหนดให้ฝากงานแก้กติกาให้ Claude ใน AGENTS.md สำหรับงานนี้เท่านั้น

- เปลี่ยนชื่อที่ผู้เล่นเห็นจากพลังเสริมเป็น **พลังเวท** ค่ายังคงเป็นโบนัสเปอร์เซ็นต์เหนือพลังพื้นฐานของแต่ละสกิล ไม่ใช่ค่าสถานะแบบ flat ใหม่ ฟิลด์ภายใน `skillBonus` และอุปกรณ์ `support` คงชื่อเดิมเพื่อรักษาข้อมูล
- ดาเมจเวท: bolt, sigil, storm, dispel (จอมเวท), acid, bomb, catalyst (นักปรุงยา), finale และ note (กวี) ใช้พลังเวท สูตรลำดับการปัดเศษ โบนัสเลเวลสกิล และแต้มเพิ่มพลัง flat คงเดิม
- การรักษา โล่ และเพลงที่เพิ่มพลังได้ใช้พลังเวทเหมือนค่าพลังเสริมเดิม รวมถึงดาเมจและการรักษาของ finale
- โจมตีปกติยังเป็นการโจมตีพื้นฐานที่ใช้พลังโจมตี สกิลดาบ ธนู ทวน มีด และค้อนใช้พลังโจมตี ไม่มีการเปลี่ยนชนิด/เงื่อนไขโจมตีจากการเป็นอาชีพจอมเวทเพียงอย่างเดียว
- ท่าควบคุม คูลดาวน์ และท่าเปอร์เซ็นต์ลดความเสียหาย/เพิ่มพลัง (PERCENT_SKILLS) ไม่แรงขึ้นจากพลังเวท ระยะเวลาคงเดิม โบนัสจากเลเวลสกิลและโหนดเฉพาะยังใช้กติกาเดิม
- อาวุธจอมเวทใช้ main stat พลังเวท ด้วย curve เดิมของอาวุธ และ pool เดิมที่แทน attack ด้วย support; ยังมี leech ได้ โหนดประกายเวทเปลี่ยนเป็นพลังเวทด้วยเปอร์เซ็นต์เดิม ระบบสวมใส่แนะนำจัดจอมเวทเข้ากลุ่มพลังเวท
- bump encounter version ทุกชุดที่ใช้ resolver ร่วมกัน

## เซฟ v41

ย้าย Attack affix ของอาวุธจอมเวทเก่าเป็นพลังเวท ทั้งในคลัง ของที่สวม ของในรัน overflow และสำเนา profile/run โดยไม่เปลี่ยน uid, คุณภาพ, ระดับ, plus, investment, locked หรือทรัพยากร ทำก่อน migration อุปกรณ์ v21 เพื่อไม่ให้ stat เก่าถูกแทนด้วย affix อื่น

ศึกที่ค้างจาก v40 หรือต่ำกว่าเริ่มจาก entry HP เดิมเมื่อคำสั่งของจอมเวทได้รับผลจากอาวุธ/โหนดที่เปลี่ยน หรือเป็นคำสั่งดาเมจเวทที่มีโบนัสกายภาพและเวทต่างกัน ไม่ replay คำสั่งเหล่านั้นด้วยสูตรใหม่ ไม่ให้รางวัลเพิ่ม ศึกที่ค่าสูตรไม่เปลี่ยนยังเก็บคำสั่งเดิม เซฟ v41 replay ตามปกติ

## ตรวจสมดุล

รายงานจาก `npm run sim` อยู่ใน `docs/validation/balance-sim/` และ `docs/validation/formation-sim/` ใช้ทุกอาชีพ ต้นไม้สกิล แคมเปญและ hard mode ไม่มีการเพิ่ม SPD/จำนวนเทิร์นหรือแก้พลังฐานของสกิลเพื่อชดเชย รายงานแสดงผลของการทำให้ stat ตรงกับสกิลจริง เช่น จอมเวทสายปืนใหญ่ยังชนะ 10/10 และนักปรุงยาสวมอุปกรณ์สายหลักยังชนะ 10/10; ค่าพลังเวทเริ่มเพิ่มดาเมจจริง จึงมีผลต่อจำนวนรอบและ HP ที่เหลือ
