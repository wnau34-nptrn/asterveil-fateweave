# P09-01 — บัญชีและเซฟคลาวด์ (ภาพรวม + ข้อที่เจ้าของต้องเลือก)

11 พฤศจิกายน 2026 · เจ้าของอนุมัติให้เริ่มส่วนที่ไม่ต้องใช้ฐานข้อมูลจริง (“อนุมัติ ทำตามที่แนะนำ”) · ไม่ deploy ไม่สร้าง D1 ไม่ใช้ secret ไม่แก้กฎต่อสู้/สมดุล/รูปแบบเซฟ v58

## สรุป

- ผู้เล่นทุกคนเล่น offline ได้เหมือนเดิม เซฟคลาวด์เป็นทางเลือก: local → guest → ผูกบัญชี → กู้คืน/ย้ายเครื่อง
- เซฟคลาวด์ = สตริงเซฟ local ตรงตัว + envelope (revision, requestId, ขนาด, SHA-256) server ตรวจด้วย `parseGame` ชุดเดียวกับเกม
- เซฟขัดกัน: ไม่รวมอัตโนมัติ ผู้เล่นเลือกทั้งก้อน อีกก้อนเก็บสำรอง
- เส้นแบ่งความเชื่อถือ: ความคืบหน้า PvE เชื่อเครื่อง; สกุล/รางวัล/เวลา/seed ออนไลน์เป็นของ server; ยอดในเซฟไม่กลายเป็นเงินสุ่ม
