# P09 — บัญชีรางวัล (reward ledger) ของกวาดล้างและบอร์ดภารกิจ

15 พฤศจิกายน 2026 · ลำดับ OD-13 ข้อ "server-authoritative rewards" · ไม่แก้ตัวเลขรางวัล/กฎกวาดล้าง/บอร์ด ไม่แก้รูปแบบเซฟ (v63) ไม่สร้าง D1 migration

## ทำอะไร

- **server เป็นเจ้าของปฏิทิน**: บน dev API คำสั่ง `sweep`, `claimBoard`, `depart` ใช้ "วันเกม" ของ server (`CommandContext.clock`) แทนวันของเครื่อง
  คำสั่งที่ส่ง `day` มาเองถูกปฏิเสธ `client_day` (ใช้เลข seq เหมือนคำสั่งที่ถูกปฏิเสธอื่น) — ตั้งนาฬิกาเครื่องเดินหน้า/ถอยหลังไม่มีผล
- **วันเกมเริ่มเที่ยงคืนเวลาไทย** (`GAME_DAY_OFFSET_MINUTES = 420`, UTC+7 ไม่มี DST; ร่าง เจ้าของเปลี่ยนได้) สัปดาห์เริ่มวันจันทร์ (`weekOf` เดิม)
- **บัญชีรางวัล** ตาราง `reward_ledger` ใน SQLite ของ Durable Object ของบัญชีนั้น (ไม่ใช่ D1 จึงไม่ต้องใช้ token D1 Edit):
  หนึ่งแถวต่อการจ่ายหนึ่งครั้ง `receipt` เป็น primary key บันทึกใน transaction เดียวกับเกม/log
  - กวาดล้าง `sweep:<ลำดับครั้งที่>` งวด `d<วัน>` ref `<map>:normal|hard`
  - บอร์ด `board:<daily|weekly|contract>:<d<วัน>|w<สัปดาห์>>:<id>`
  - คำตอบที่ apply แล้วมี `receipts` (เก็บใน book จึงส่งซ้ำได้ไบต์เดิม)
- **ส่งซ้ำ (retry)**: requestId เดิมได้คำตอบเดิมแม้ข้ามเที่ยงคืน ไม่จ่ายซ้ำ ไม่ย้ายวัน
- **กันจ่ายซ้ำชั้นที่สอง**: กฎเดิมกันอยู่แล้ว (`claimed`, `serial`) ถ้ากฎจ่ายแต่ receipt มีอยู่แล้ว server ปฏิเสธ `duplicate_receipt` ไม่เปลี่ยนเกม log เก็บ `refused: 'receipt'`
- **replay/verify**: log เก็บ `day` ที่ server ประทับ `replayLog` ส่ง `clock` ตามนั้น (log เก่าไม่มี `day` = คำสั่งพก `day` ของเครื่องอยู่แล้ว เล่นซ้ำได้เหมือนเดิม) คอลัมน์ `day`/`refused` เพิ่มให้ตาราง log เดิมอัตโนมัติ
- **เครื่อง**: `ServerClient` ตัด `day` ออกจากคำสั่งสามแบบนี้ และอ่าน `clock {day,next,now}` จาก `/v1/session`, `/v1/state` เพื่อแสดงวันของ server (เดินต่อเองเมื่อถึง `next` ตามเวลาที่ผ่านไปในเครื่อง ไม่ใช้นาฬิกาเครื่องตรง ๆ) คำตอบคำสั่งไม่มี clock เพื่อให้ retry ได้ไบต์เดิม
- **ออฟไลน์**: ไม่มี `clock` → ใช้ `day` ของเครื่องเหมือนเดิม (ไม่มี `day` → `day`)

## ไม่ได้ทำ (ตามขอบเขต)

- ~~ไม่มีเศษกลาง~~ → ทำแล้วใน P09 ตอน 2: เศษกลางรายสัปดาห์ 10 จากงานรายสัปดาห์สามงาน ใช้ receipt `board:weekly:w<สัปดาห์>:<id>` เดิม ([ผล](../../validation/p09-shards-2026-11-15/README_TH.md)) · ยังไม่มี gacha/ตั๋วฟรี

- ตัวเลขรางวัล/เพดาน P04-06 ไม่เปลี่ยน (เจ้าของยังไม่ตอบเรื่อง target share / login-only)
