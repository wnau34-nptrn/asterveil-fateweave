# P09-01 — บัญชี guest → ผูกบัญชี → กู้คืน → ย้ายเครื่อง

11 พฤศจิกายน 2026 · อัปเดตตาม D10 = ค (server ตัดสินทั้งหมด) · **เอกสารออกแบบ ยังไม่มีโค้ดบัญชีในเกมหรือ Worker** · **[โค้ด]** = ข้อเท็จจริง; **[เสนอ]** = ข้อเสนอ

## 1. สภาพปัจจุบัน [โค้ด]

- เซฟอยู่ใน localStorage คีย์เดียว `asterveil.fateweave.expedition.v1` เขียนทั้งก้อน `{version:58, profile, run}` (`saveGame`) ผ่าน `StoragePort`
- โหลดด้วย `parseGame` (ตรวจรูปแบบ เพดาน replay ศึกที่ค้าง); โหลดไม่ผ่านไม่ลบคีย์เดิม
- ไม่มี account ID, token หรือ device ID; Worker `asterveil-api-dev` ตอบแค่ `GET/HEAD /health`

## 2. สถานะบัญชี [เสนอ]

| สถานะ | ความหมาย | เล่นได้ |
|---|---|---|
| `guest` | server สร้างให้อัตโนมัติตอนเปิดเกมครั้งแรก มี device credential ยังไม่มีตัวตนภายนอก | ได้ (ออนไลน์) |
| `linked` | ผูกตัวตนภายนอกแล้ว (D1 แนะนำ Google) | ได้ กู้/ย้ายเครื่องได้ |
| `deleting` | ขอลบบัญชีแล้ว รอช่วงยกเลิก (ร่าง 14 วัน) | ได้ ยกเลิกการลบได้ |
| `suspended` | admin ระงับ | ไม่ได้ (แสดงเหตุผล/ช่องติดต่อ) |

| จาก → ไป | ทริกเกอร์ | เงื่อนไข/ผล |
|---|---|---|
| (ไม่มี) → guest | เปิดเกมครั้งแรกบนเครื่องที่ไม่มี credential | `POST /v1/guest` + `requestId`; retry ได้บัญชีเดิม; ถ้าเครื่องมีเซฟ v1–58 เดิม → เสนอนำเข้า (D11) |
| guest → linked | “ผูกบัญชี” (ชวนหลังเคลียร์ MAP1 และก่อนใช้ของมีค่า) | ตรวจ id token บน server; ตัวตนผูกบัญชีอื่นอยู่แล้ว → ไม่รวมบัญชี ให้เลือก “สลับไปบัญชีนั้น” หรือยกเลิก |
| guest บนเครื่องใหม่ | รหัสกู้คืน | ใช้ครั้งเดียว ออกใหม่ทุกครั้ง |
| linked บนเครื่องใหม่ | เข้าสู่ระบบด้วยตัวตนเดิม | ออก credential ใหม่; สถานะเกมอยู่บน server อยู่แล้ว ไม่มีอะไรต้องย้าย |
| ใด ๆ → ออกจากระบบ | ผู้เล่นสั่ง | ลบ credential ในเครื่อง; guest ที่ไม่ได้ผูก/ไม่มีรหัสกู้คืนจะเข้าบัญชีเดิมไม่ได้ → เตือนก่อน |
| → deleting → ลบ | ขอลบ + ยืนยันซ้ำ | ลบสถานะเกม/ตัวตน; ledger ที่ต้องเก็บตามกฎหมายเก็บแบบไม่ระบุตัวตน (นโยบายความเป็นส่วนตัวต้องมีก่อนเปิดคนนอก) |

credential: access token อายุสั้น (ร่าง 15 นาที) + refresh token หมุนเวียน (ร่าง 30 วัน, server เก็บแค่ hash); ล้างข้อมูลเบราว์เซอร์ = guest ที่ไม่ได้ผูกหาย → จึงต้องชวนผูกบัญชี

## 3. การเชื่อมต่อระหว่างเล่น [เสนอ]

| สถานการณ์ | ผล |
|---|---|
| ออฟไลน์ตอนเปิดเกม | หน้ารอเชื่อมต่อ ไม่มีโหมดเล่นในเครื่อง |
| หลุดกลางเกม/กลางศึก | ล็อกปุ่ม แสดง “กำลังเชื่อมต่อใหม่”; สถานะบน server คงเดิม กลับมาเล่นต่อจุดเดิม |
| หมดเวลาหลังส่งคำสั่ง | ส่งซ้ำ `requestId`+`seq` เดิม → server ตอบผลเดิม (`replayed`) ไม่ทำซ้ำ |
| กดซ้ำ/ส่งคำสั่งซ้ำ | requestId เดิมคำสั่งเดิม → ผลเดิม; requestId เดิมคำสั่งต่าง → ปฏิเสธ |
| คำสั่งหายระหว่างทาง | server ตอบ `gap` → ส่งใหม่ตั้งแต่ลำดับที่ขาด |
| เครื่องตามไม่ทัน (`stale`) | ดึงสถานะล่าสุดจาก server แล้วแสดงใหม่ |
| สองเครื่อง (D12 แนะนำทีละเครื่อง) | เครื่องที่เข้าใหม่ได้สิทธิ์ เครื่องเก่าแสดง “กำลังเล่นบนอุปกรณ์อื่น” |
| server ปฏิเสธเพราะกฎ | แสดงเหตุผลแบบเดียวกับปุ่มที่ใช้ไม่ได้ในเกมวันนี้ |

ไม่มีการรวมเซฟหรือเลือกเซฟเมื่อขัดกันอีก เพราะมีสถานะเดียวบน server (ข้อเสนอเดิมเรื่องหน้าเลือกเซฟถูกแทนด้วย D10)
