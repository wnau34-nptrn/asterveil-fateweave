# P09-01 — Trust boundary: เซฟ offline เก่า กับระบบ online

11 พฤศจิกายน 2026 · อัปเดตตาม D10 = ค (เจ้าของ “เลือก ค.”: server ตัดสินทั้งหมด) · ต่อยอด [GACHA_G01_MIGRATION_TH.md](../GACHA_G01_MIGRATION_TH.md) · **[โค้ด]** = ข้อเท็จจริง; **[เสนอ]** = ข้อเสนอ · ตัวเลขเป็นร่าง

## 1. ทำไมเชื่อเครื่องไม่ได้ [โค้ด]

- เซฟอยู่ในเครื่องทั้งหมด แก้ด้วย devtools ได้; `parseGame` ตรวจรูปแบบ เพดาน (`BANK_CAP` ทอง/แร่/ฝุ่น 9,999,999 ตรา 99,999) ความสอดคล้องของต้นไม้/ของ และ replay ศึกที่ค้าง **แต่ไม่ตรวจว่ารายได้ได้มาจริง** — เซฟที่ตั้ง bank เป็นเพดานผ่าน (เทสต์ `tests/cloud-save-envelope.test.ts`)
- seed สร้างบนเครื่อง (`freshSeed()` ใน `src/ui/game-shell.ts`) และกำหนดศัตรูบนแผนที่ กระดานจ้าง และผลหลอม จึงเลือกผลสุ่มได้
- ดังนั้น “ผ่าน replay” = เล่นต่อได้ตามกฎ ไม่ใช่หลักฐานว่าได้มาจริง

## 2. เส้นแบ่งหลังเลือก ค [เสนอ]

**server เป็นเจ้าของทุกอย่าง**: account/ตัวตน/credential, สถานะเกมทั้งก้อน (profile, การเดินทาง, ศึก), seed ทุกตัว, เวลาจริง, ledger/ตั๋ว/แต้ม/entitlement, ผลกาชา, ผลศึก/World Boss/อันดับ, receipt ซื้อในอนาคต

**เครื่องเชื่อได้แค่**: “ผู้เล่นตั้งใจทำคำสั่งอะไร” (ซึ่ง server ตรวจซ้ำทุกครั้ง) และการแสดงผล/preview

สิ่งที่ยังกันไม่ได้ด้วยเส้นแบ่งนี้: บอทกดแทนคน, บั๊กในกฎ, แชร์บัญชี → rate limit, telemetry, admin/ledger ย้อนได้ (SERVER_AUTHORITY §4)

## 3. เซฟเก่าในเครื่อง (D11) [เสนอ]

แนะนำ: **นำเข้าครั้งเดียวต่อบัญชี เฉพาะช่วงก่อนเปิดทดสอบคนนอก**

- ตรวจด้วย envelope + `parseGame` (รูปแบบ เพดาน replay) แล้วใช้เป็นสถานะเริ่มต้นบน server, `origin=legacy`, เก็บก้อนดิบ + fingerprint
- ตอนนี้ยังไม่มีผู้เล่นภายนอก (OD-13) ผู้มีเซฟคือเจ้าของ/ทดสอบภายใน → สิทธิ์ผู้เล่นเดิมไม่หาย (ตาราง G01 §2 ใช้ได้ครบ: ดาว ของ ต้นไม้ ตำรา thiran/wila ฯลฯ)
- หลังเปิดคนนอก ปิดการนำเข้า บัญชีใหม่เริ่มบน server — เพราะเซฟที่แก้ก่อนนำเข้าคือช่องโหว่เดียวที่เหลือ
- fingerprint เดียวกันนำเข้าได้บัญชีเดียว; บัญชีที่นำเข้าแล้วนำเข้าซ้ำไม่ได้ (เปลี่ยนก้อนผ่าน admin เท่านั้น)
- ยอดในเซฟเก่า (ทอง แร่ ตรา ฯลฯ) **ไม่แปลงเป็นตั๋ว/แต้มกาชา** ตามหลักเดิม; wallet ออนไลน์เริ่มจาก grant ของ server
- เซฟที่นำเข้าไม่ผ่าน: ไม่ลบในเครื่อง แจ้งเหตุผล และให้ support ตรวจ
