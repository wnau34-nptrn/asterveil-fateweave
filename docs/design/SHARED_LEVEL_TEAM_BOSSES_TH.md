# เลเวลร่วมทั้งค่าย การสลับทีม และบอสที่ทดสอบกลไก

วันที่ 25 ตุลาคม 2026 (Asia/Bangkok)

สถานะ: เจ้าของขอปรับแนวทางให้ตัวละครมีเลเวลเท่ากันเพื่อสลับเล่นอิสระ และขอความเห็นเรื่องบอสที่ต้องใช้กลไกเฉพาะ เอกสารนี้ปรับฐานออกแบบตามเจตนานั้น พร้อมคำแนะนำรายละเอียด ยังไม่ใช่การแก้ runtime/save หรือยืนยันผลทดสอบความสนุก

อ้างอิง [ฐานพัฒนาตัวละคร](PROGRESSION_RECOMMENDED_BASELINE_TH.md) และ [Game Detail ของระบบที่มีอยู่](../GAME_DETAIL_TH.md) ทีมสูงสุดห้าคนเป็นทิศทางต้นแบบจากบทสนทนาก่อนหน้า เกมปัจจุบันยังสี่คน ต้องทดสอบ UI/สมดุลก่อนเปลี่ยนจริง

## 1. ข้อแนะนำหลัก

**ใช้เลเวลร่วมทั้งค่ายทหารรับจ้าง ครอบคลุมตัวที่ลงสนาม ตัวสำรอง และตัวที่ถือครองทั้งหมด** ไม่จำกัดเฉพาะสมาชิกห้าคนที่เลือกอยู่ เพราะถ้าตัวนอกทีมยังเลเวลต่ำ เป้าหมายการสลับเล่นจะยังไม่สำเร็จ

EXP จากกิจกรรมเข้าแถบเลเวลค่ายหนึ่งครั้ง ไม่แบ่งตามจำนวนสมาชิก ไม่คูณตามจำนวนตัวที่ถือครอง ตัวละครที่เข้าค่ายใหม่ใช้เลเวลค่ายทันที ไม่ต้องส่งฝึกไล่เลเวล ไม่มีช่องซิงก์จำกัดหรือค่าเปลี่ยนตัวเพื่อรับเลเวล

เลเวลค่ายกำหนดความก้าวหน้าฐานและเพดานที่ปลดตามเนื้อเรื่อง ตัวละครยังใช้ค่าสถานะพื้นฐาน/การเติบโตตามอาชีพ จึงเลเวลเท่ากันแต่ HP/ATK ไม่เท่ากัน ไม่ใช้ค่าเฉลี่ยห้าคนและไม่อิงตัวที่เลเวลสูงสุดแบบเคลื่อนไหวระหว่างเล่น

## 2. สิ่งที่ร่วมและสิ่งที่ยังเป็นรายตัว

| ร่วมทั้งค่าย | รายตัว/ตามบิลด์ |
|---|---|
| Lv และ EXP | ดาวและขั้นอาชีพ |
| งบแต้มต้นไม้ตาม Lv และขั้นฝึกถาวรของค่าย | การลงแต้ม a/b/c/p และสามสกิลที่ติดตั้ง |
| สิทธิ์เข้าชั้นต้นไม้ตาม Lv | บุคลิก กิ่งประจำตัว และ Bond |
| เพดานเนื้อหา/ระบบที่บัญชีปลดแล้ว | อุปกรณ์และเลเวลสกิลที่ลงทุนตามระบบที่ออกแบบต่อ |

แต้มเป็นสิทธิ์เต็มจำนวนให้แต่ละคน ไม่เป็นถังรวมที่ต้องแย่งกันใช้ การฝึกสี่ขั้นในข้อเสนอก่อนหน้าปรับเป็น milestone ค่าย ทำครั้งเดียว ทุกคนรวมคนใหม่ได้งบเท่ากัน แต่ยังเลือกโหนดเอง ค่า 16 แต้มที่ Lv20 เป็นเพียงค่าต้นแบบเดิม ไม่ใช่ตัวเลขที่ตรวจแล้ว

เมื่อค่ายถึง Lv15 ทุกคนผ่านเงื่อนไขเลเวลของข้อเสนอเลื่อนขั้น แต่ยังต้องมีพื้นฐาน ★5 และผ่านบททดสอบของตน เมื่อค่ายถึง Lv20 ตัวที่เลื่อนขั้นแล้วเข้าถึงตัวเลือกขั้นสูงคู่สองได้ทันที การผ่าน milestone ไม่แจกดาวหรือเลื่อนขั้นทุกคนอัตโนมัติ

ระบบช่วยฝึกไล่ Lv 1–3 ครั้งเล่นในเอกสารก่อนหน้าถูกแทนด้วยการได้ Lv ร่วมทันที เหลือเพียงการจัดบิลด์/ของ/ตำราให้พร้อม ไม่สร้างกิจกรรมไล่ EXP รายตัวซ้ำอีก

## 3. ทำให้สลับเล่นได้จริง

- จัดทีมทั้งค่ายที่ค่ายหลัก และสลับสมาชิกที่นำมาได้ที่จุดพักปลอดภัยในแผนที่ ห้ามเปลี่ยนตัวกลางศึก รุ่นแรกยังไม่เพิ่มการเรียกตัวทั้งค่ายเข้ากลางเที่ยวโดยอัตโนมัติ
- รีเซ็ตแต้มและย้ายอุปกรณ์ที่เข้ากันได้ฟรีที่ค่าย บันทึกชุดทีมและชุดบิลด์ได้ในสเปก UI ต่อไป การเรียกชุดต้องย้ายชิ้นจริงและตรวจชนิดอุปกรณ์ ไม่ทำสำเนาของชิ้นเดียวให้ใช้พร้อมกัน
- สกิลที่จำเป็นต่อบทบาทต้องทำงานในระดับเริ่มต้นของสกิล การลงแต้มเพื่อเลือกท่าใช้สิทธิ์ร่วมที่ได้รับทันที ตำราควรเพิ่มประสิทธิภาพ ไม่เปิดสิทธิ์แก้กลไกบอสที่บังคับใช้
- ดาวและเลเวลสกิลยังทำให้พลังต่างกัน ต้องเทียบตัวสลับเข้าทีมที่ดาวต่ำ/ตำราน้อยกับตัวหลักที่ลงทุนสูง ถ้าตัวสลับทำหน้าที่ไม่ได้เพราะช่องว่างนี้ ให้แก้ช่องว่าง ไม่อ้างว่าแค่ Lv เท่ากันก็สลับอิสระแล้ว
- ศึกเนื้อเรื่องหลักต้องไม่บังคับดาวขั้นสูงหรือการเลื่อนอาชีพเพื่อได้เครื่องมือรับมือที่จำเป็น การลงทุนช่วยเพิ่มความเผื่อผิดพลาดและประสิทธิภาพ

## 4. บอสควรทดสอบกลไก ไม่ล็อกชื่อคน

แนะนำบอสบางตัวมีโจทย์ที่การเลือกท่า/ทีมช่วยได้ชัด เช่น รับมือท่าชาร์จ ตัดวงจรรักษา หรือจัดการเป้าหมายหลายตัว กลไกที่จำเป็นจริงต้องมีทางตอบจากการเล่นที่รับประกันได้ก่อนถึงบอส ไม่ผูกกับการสุ่มได้คนหนึ่งคน

เกณฑ์ออกแบบ: บอสเนื้อเรื่องแต่ละตัวมีแนวตอบที่ใช้งานได้อย่างน้อยสองแบบ และอย่างน้อยหนึ่งแบบใช้สมาชิก/อุปกรณ์/คำสั่งที่บัญชีได้รับแน่นอน รวมตรวจตัวเลือกการรับสมัครที่ผู้เล่นอาจเลือกต่างกัน ไม่ถือว่าอยู่ในตู้หรือเปิดขายแบบสุ่มเท่ากับได้รับแน่นอน

| ตัวอย่างโจทย์สำหรับออกแบบต่อ | แนวตอบแรก | แนวตอบอีกแบบ |
|---|---|---|
| ประกาศชาร์จท่ารุนแรงล่วงหน้า | ขัดจังหวะภายในหน้าต่างที่บอก | เตรียมป้องกัน/โล่และรักษาให้รอด โดยความเสียหายไม่สูงจนทางนี้เป็นเพียงทฤษฎี |
| บอสได้โล่จากผู้คุ้มกัน | จัดการผู้คุ้มกันก่อน | ใช้การล้างโล่ที่มีคำอธิบายว่าล้างได้จริง แล้วโจมตีในจังหวะเปิด |
| บอสฟื้นตัวจากลูกน้องสนับสนุน | เลือกกำจัดตัวสนับสนุน | หยุดหรือล้างผลฟื้นตัวตามกฎที่ออกแบบให้เข้าถึงได้ |
| หลายเป้าหมายร่วมกันกดดัน | ใช้ท่าหมู่ลดแรงกดดัน | ควบคุมบางตัวและโฟกัสกำจัดทีละตัว |

ตารางเป็นตัวอย่างแนวคิด ไม่อ้างว่าแต่ละบอส/ผลล้าง/การควบคุมทำงานตามนี้ใน runtime แล้ว ต้องตรวจความสามารถจริงและการเข้าถึงก่อนสร้าง encounter ห้ามถือว่าล้างบัฟได้จึงล้างโล่ทุกชนิดได้

ไม่เพิ่มภูมิคุ้มกันเพื่อปิดทางตอบทั้งหมดของอาชีพนั้นโดยไม่แจ้ง ถ้าบอสต้านการขัดจังหวะบางช่วง ให้ระบุหน้าต่างที่ทำงานได้และทางตอบอื่น ไม่สร้างเงื่อนไขใช้ตัวใหม่จากตู้เดือนนั้นจึงผ่าน

## 5. ความยากและการสื่อสาร

บอสหลักช่วงแรกเน้นหนึ่งกลไกที่อ่านง่าย ช่วงกลางผสมกลไกหลักกับแรงกดดันรอง ส่วนโหมดยากเพิ่มการประสานจังหวะ/ข้อจำกัดที่ประกาศชัด ไม่ใช้การเพิ่ม HP อย่างเดียว

ก่อนเข้าศึกแจ้งลักษณะภัยและหมวดเครื่องมือที่ช่วยได้ ไม่สั่งชื่อฮีโร่ตายตัว ในศึกแสดงเจตนา เป้าหมาย และผลที่ผู้เล่นควรรู้ผ่าน preview ที่ใช้กฎเดียวกับผลจริง เมื่อแพ้สรุปสาเหตุที่ตรวจได้จากศึก เช่น ปล่อยการรักษาซ้ำหลายรอบ ไม่สร้างคำแนะนำจากการเดา

การแพ้และการถอยยังต้องเคารพนโยบาย expedition ที่มีอยู่ การเปลี่ยนเป็นเลเวลร่วมไม่แอบเปลี่ยนค่าปรับทรัพยากรหรือมอบ retry รางวัลซ้ำ EXP ค่ายคงอยู่ตามแนวเดิมที่เก็บความก้าวหน้าเลเวลไว้

## 6. ทีมสูงสุดห้าคน

เลเวลร่วมช่วยลดภาระเตรียมสมาชิกคนที่ห้า จึงสนับสนุนทิศทางทีมสูงสุดห้าคน ศัตรูหนึ่งถึงห้า แนวละไม่เกินสาม และสกิลสามช่อง แต่ไม่ได้แก้ความหนาแน่นจอ/ความยาวศึก/สกิลหมู่ให้เอง ต้องทำต้นแบบ 390px และเทียบเวลาตัดสินใจ จำนวนรอบ และความหลากหลายของทีม

ปรับแบบจำลองเศรษฐกิจจากทีมหลักสี่เป็นห้าคนในงานถัดไป แยกรายได้ดาว ตำรา และอุปกรณ์จาก EXP ร่วม ไม่คูณต้นทุนเลเวลห้าคน และไม่อ้างว่าเวลาเดิม 20–30 ครั้งเล่นจะรองรับห้าคนได้แล้ว

## 7. การย้ายเซฟและหลักฐานที่ต้องได้ก่อนลงจริง

- เก็บสมาชิก ดาว ขั้นอาชีพ อุปกรณ์ ตำรา กิ่งที่ลงทุนและ legacy grants พร้อม snapshot ก่อนย้าย
- ฐานเลเวลค่ายสำหรับเซฟเก่าแนะนำใช้ความก้าวหน้า Lv/EXP ที่มากที่สุดของสมาชิกที่ถือครอง โดยเปรียบเทียบบนเส้น EXP เดียวกัน ไม่บวก EXP ทุกคน และไม่ยึดเพียงตัวในทีมปัจจุบัน ตรวจกรณี cap/EXP ค้างก่อนแปลง
- ข้อนี้เป็นวิธีตั้งค่าแรกจากเซฟเก่าเท่านั้น หลังย้ายมี EXP ค่ายแหล่งเดียว ไม่คำนวณ max สมาชิกซ้ำ
- เครดิตแต้มดาวเก่าของข้อเสนอก่อนหน้าต้องปรับให้สอดคล้องกับการฝึกร่วม: ใช้เครดิตสูงสุดที่เคยมีในค่ายเป็นค่าพื้น ไม่รวมแต้มดาวทุกคน เพิ่มสิทธิ์ให้คนอื่นได้แต่ไม่ลดของผู้มีแต้มมากที่สุด รวมไม่เกินเพดานสี่ขั้นฝึก; ต้องตรวจ grants และ gates จริงอีกครั้ง
- การมอบ EXP ต้องเกิดหนึ่งครั้งต่อเหตุการณ์และไม่ซ้ำเมื่อโหลดเซฟ รับสมาชิก หรือสลับทีม เซฟศึกที่ค้างต้องรักษากฎ/ค่าสถานะตอนเริ่มศึก หรือมี migration boundary ที่ประกาศชัด ไม่แก้ replay กลางทาง
- ตรวจบัญชีใหม่/เก่า/กลับมาเล่น ตัวใหม่ ดาวต่ำ ทีมไม่มีตัวโฟกัสกาชา ทุกทางเลือก starter ที่เข้าถึงได้ และชุดทีมหลายแบบที่ทุนเท่ากัน

ไม่มี runtime หรือ save change ในงานเอกสารนี้ ยังไม่ได้รัน sim/ทดสอบการเล่น การเปลี่ยนระบบจริงต้องมีสเปก EXP ร่วม การถือครอง 30+ ตัว กฎทีมสูงสุดห้าและ migration ที่ตรวจร่วมกัน
