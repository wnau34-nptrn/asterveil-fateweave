# รอบออกแบบ 1 — ดาว เลื่อนอาชีพ และต้นไม้สกิล

> คำแนะนำหลักหลังเจ้าของขอให้เลือกแนวทางให้: [ฐานออกแบบที่แนะนำ](PROGRESSION_RECOMMENDED_BASELINE_TH.md) รวมเงื่อนไขเลื่อนขั้น แต้ม ดาว และเป้าระยะเวลาปั้น ตัวเลขเป็นค่าต้นแบบที่ยังต้องพิสูจน์

วันที่ 25 ตุลาคม 2026 (Asia/Bangkok)

สถานะ: **ข้อเสนอหลักเพื่อทบทวนร่วมกับเจ้าของ** ตามคำขอให้ดำเนินการรอบถัดไป หลัง [งาน research](../GAME_RESEARCH_RECOMMENDATIONS_TH.md) ครอบคลุม D06–D10 และผลกระทบ D03–D05/D14–D15/D22/D35–D36 ยังไม่ใช่สเปกตัวเลขที่พร้อมลงเกม ไม่แก้ runtime, save หรือแผน C12 โดยอัตโนมัติ

## 1. ข้อเสนอหลัก

คง 15 อาชีพพื้นฐาน แต่ละอาชีพมีขั้นสูงหนึ่งทางในรุ่นแรก ตัวละครคนเดิมพัฒนาจากอาชีพพื้นฐาน ★1–★5 ไปอาชีพขั้นสูง ★1–★5 สกิลเดิมและกิ่งประจำตัวคงตัวตนไว้ การเลื่อนขั้นเปิดส่วนต่อขยายเล็ก ๆ สำหรับปรับวิธีใช้ท่าเดิม

กาชาช่วยให้ได้คนและเร่งทรัพยากรพัฒนา แต่เส้นทางถึงดาวสูงและเลื่อนอาชีพต้องทำได้จากการเล่นโดยไม่บังคับได้ตัวซ้ำ ID เดิม การเลือก ★5 เป็นประตูเลื่อนอาชีพจึงต้องมาพร้อมทางฟาร์มดาวที่เชื่อถือได้

## 2. เส้นทางตัวละครและการนับดาว

```text
ได้ตัวละครพื้นฐาน ★1
    ↓ เล่น/ฝึก/เรียนสกิล และสะสมทรัพยากรดาว
พื้นฐาน ★2 → ★3 → ★4 → ★5
    ↓ ผ่านเงื่อนไขความพร้อมและบททดสอบอาชีพ
ขั้นสูง ★1
    ↓ พัฒนาสกิลเดิมในต้นไม้ส่วนต่อขยาย
ขั้นสูง ★2 → ★3 → ★4 → ★5
```

นิยามที่แนะนำ: **สองขั้นอาชีพ ขั้นละห้าดาว รวมสิบตำแหน่งความก้าวหน้า** เริ่มต้นได้ตำแหน่งแรกแล้ว มีอัปดาวปกติสี่ครั้งก่อนเลื่อนขั้น เลื่อนขั้นหนึ่งครั้ง และอัปดาวอีกสี่ครั้งหลังเลื่อนขั้น รวมเก้าการเปลี่ยนสถานะ ไม่เรียกว่า “อัปดาวสิบครั้ง”

หากเจ้าของหมายถึงต้องกดเพิ่มดาวห้าครั้งหลังเลื่อนขั้น จะเป็นอีกโครงที่เริ่มขั้นสูงศูนย์ดาว เอกสารนี้แนะนำเริ่มขั้นสูง ★1 เพื่อให้อ่านสอดคล้องกับตัวละครเริ่มต้น แต่ยังรอเจ้าของเลือกรับนิยามนี้

หน้า UI แสดง “อาชีพพื้นฐาน / อาชีพขั้นสูง” คู่กับดาว ใช้กรอบ/สัญลักษณ์ขั้นเพื่อแยก โดยไม่พึ่งสีอย่างเดียว ดาวขั้นสูงดวงแรกไม่ใช่การลดระดับกลับไปเริ่มใหม่

## 3. แบ่งหน้าที่ระบบพัฒนา

| ระบบ | หน้าที่ในข้อเสนอ | สิ่งที่ไม่ควรซ้อนหน้าที่ |
|---|---|---|
| เลเวล | ความพร้อมพื้นฐานและสิทธิ์เข้าชั้นพัฒนา | ไม่ให้แต้มไม่จำกัดจนเลือกทุกบิลด์พร้อมกัน |
| ตำรา/เลเวลสกิล | เพิ่มประสิทธิภาพพื้นฐานของท่า ตามชนิดสกิล | ไม่เป็นประตูให้ตัวละครเริ่มทำบทบาทหลักได้ |
| ต้นไม้อาชีพ a/b/c | สกิลและแนวเล่นของอาชีพ รวมตัวเลือกที่เลือกพร้อมกันไม่ได้ | ไม่ผูกการได้แต้มใหม่กับการสุ่มตัวซ้ำ |
| กิ่งประจำตัว p | บุคลิกในการเล่นของตัวละครแต่ละคน | ไม่ถูกแทนด้วยต้นไม้อาชีพขั้นสูงที่ทำให้คู่เหมือนกัน |
| เลื่อนอาชีพ | เปิดวิธีพัฒนาท่าเดิมและรูปลักษณ์ขั้นใหม่ | ไม่สร้างชุดคำสั่งใหม่ทั้งชุดหรือช่องสกิลเพิ่ม |
| ดาว | เพิ่มประสิทธิภาพในกรอบที่กำหนด | ไม่เพิ่ม SPD/เทิร์น และไม่แจกกลไกใหม่เฉพาะดาวสูงอีกชุด |
| Bond | เรื่อง ความผูกพัน และของแสดงความสัมพันธ์ | ไม่เป็นข้อบังคับเพื่อให้ท่าหลักทำงาน |

ทิศนี้เปลี่ยนจากแผนเดิมที่ให้ดาวเฉพาะตัวเสริม p1–p4 ทุกช่วง: เสนอให้ความลึกเชิงบิลด์อยู่ในต้นไม้และการเลื่อนขั้น ส่วนดาวเป็นการพัฒนาเชิงประสิทธิภาพ ไม่ลบแนวคิดเก่าออกจากเอกสารจนเจ้าของเลือก

## 4. ต้นไม้ขั้นสูงขนาดเล็ก

เสนอรูปแบบต้นแบบ: **ส่วนต่อขยายสี่ตัวเลือก แบ่งสองคู่ เลือกได้หนึ่งตัวเลือกต่อคู่** อยู่ในหน้าต้นไม้เดิม สืบเนื่องจากท่าที่เรียนแล้ว เปลี่ยนทางที่ค่ายได้ตามสิทธิ์รีเซ็ต

- คู่แรกกำหนดว่าจะเน้นท่าเดิมส่วนใดให้เข้ากับบทบาทที่เลือก
- คู่ที่สองช่วยปรับการใช้งานตามสภาพทีม/สถานการณ์ โดยไม่ทับกิ่งประจำตัว
- มีสิทธิ์เลือกคู่แรกเมื่อเลื่อนขั้น ส่วนคู่ที่สองมาจากความก้าวหน้าหลังเลื่อนขั้นที่เล่นหาได้ ไม่ผูกกับจำนวนครั้งสุ่ม
- ทุกคนในอาชีพเดียวกันใช้ส่วนต่อขยายอาชีพร่วมกัน แต่ p ของแต่ละคนยังต่างกัน
- ยังใช้โจมตีปกติ + สกิลติดตั้งสามช่อง และหนึ่งการกระทำหลักต่อเทิร์น

จำนวนสี่ตัวเลือกเป็นขนาดที่เสนอสำหรับต้นแบบ ไม่ใช่สรุปว่าต้องบังคับทุกอาชีพให้เท่ากันแม้ไม่เหมาะ รายการ effect รายท่า/เปอร์เซ็นต์/คูลดาวน์จะทำหลังเลือกโครง

**งบแต้ม:** แนะนำแยกสิทธิ์เรียนรู้จากดาว ใช้เลเวล/เหตุการณ์พัฒนาที่มีเพดานต่อช่วง การปลดคู่ตัวเลือกขั้นสูงเป็นสิทธิ์ความก้าวหน้า ไม่ต้องเพิ่มสกุลเงินอีกชนิด สูตรแต้มเดิม `(level−1)+(stars−1)` ต้องจำลองใหม่ร่วมกับเพดาน Lv30 ก่อนเปลี่ยนจริง เพราะยังไม่มีจำนวนแต้มที่ผ่านการตรวจว่ารักษาบิลด์เดิมและเหลือทางเลือกได้

**ของเก่า:** ไม่ย้ายท่าและ p ที่มีอยู่ไปซ่อนหลังการเลื่อนอาชีพย้อนหลัง ชั้นเดิมที่ต้อง Lv15 ยังเรียนได้ตามเงื่อนไขเดิมจนมีสเปกแก้เฉพาะ ไม่ถือว่า “ชั้น4” ของต้นไม้เดิมคืออาชีพขั้นสูงอยู่แล้ว

## 5. ดาวควรให้ผลอะไร

พื้นฐานและขั้นสูงมีดาวเพื่อให้สะสมความชำนาญต่อ แต่เสนอให้ผลเป็นประสิทธิภาพที่มีเพดาน เช่น กลุ่ม HP/พลังโจมตี/พลังสนับสนุนที่สัมพันธ์กับอาชีพ โดยไม่เพิ่มกฎพฤติกรรมใหม่ทุกดาว

ยังไม่เลือกสูตรโบนัส ไม่คัดลอก +8% ของเกมเดิมไปคูณต่อทุกดาวอีกห้าขั้นทันที และไม่ทบโบนัสสองขั้นโดยไม่คุมพลังรวม ต้องประเมินพร้อมอุปกรณ์ เลเวล ตำรา p และส่วนต่อขยาย

สำหรับอาชีพประโยชน์อย่างนักเต้นรำ การเพิ่ม ATK อย่างเดียวอาจไม่น่าพัฒนา แต่การเพิ่มจำนวนคูลดาวน์ที่คืนทุกดาวก็อาจเปลี่ยนวงจรศึกมาก จึงต้องวัดคุณค่าของดาวแยกตามบทบาท ไม่กำหนดล่วงหน้าว่าใช้อัตราเดียวกับสายทำดาเมจแล้วจะเท่ากัน

หลักไม่ถอยหลัง: ตัวเดิมหลังเลื่อนขั้นต้องไม่เสียค่าสถานะหรือท่าที่ใช้อยู่เพียงเพราะหน้าจอกลับไปแสดง ★1 หากมีการปรับสมดุลสูตรทั้งเกม เป็นงานอีกส่วนที่ต้องแสดงผลก่อน/หลังและการชดเชย ไม่ซ่อนอยู่ในปุ่มเลื่อนอาชีพ

## 6. เงื่อนไขเลื่อนอาชีพ

ข้อเสนอหลักคงแนวเจ้าของ: พื้นฐาน ★5 + ถึงช่วงเลเวล/บทที่เหมาะสม + ผ่านบททดสอบอาชีพ แล้วเปิดขั้นสูง ★1

บททดสอบควรทดสอบความเข้าใจบทบาท เช่น การเลือกช่วยเพื่อนตามเจตนาศัตรู มากกว่าบังคับทำดาเมจสูงในเวลาสั้น เงื่อนไขต้องบอกก่อนเข้า ลองใหม่ได้ และไม่มีสุ่มสอบผ่าน

ยังไม่ล็อก Lv/แมพที่ปลดและวัตถุดิบ เนื่องจากเกมจริงยังเพดาน Lv10 การเลื่อนขั้นควรมาพร้อมเนื้อหาที่ใช้ประโยชน์ ไม่เปิดต้นไม้สูงแล้วไม่มีศึกให้ใช้

ไม่เพิ่มโทเคนเฉพาะอาชีพใหม่สิบห้าชนิดโดยอัตโนมัติ ต้นทุนเลือกจากระบบทรัพยากรที่ตกลงในรอบเศรษฐกิจ ไม่กำหนดให้ต้องซื้อแพ็กหรือได้คนซ้ำเพื่อเข้าสอบ

## 7. ตัวอย่างกับคู่ที่มีแล้ว: เมตตา / ธีรัน

เลือกนักบุญรบเป็นตัวอย่างตรวจโครงเพราะมีคู่และ p จริงแล้ว ไม่ใช่ยืนยันว่าต้นแบบลงโค้ดต้องเป็นอาชีพนี้

| ช่วง | สิ่งที่เหมือนกัน | สิ่งที่ทำให้ยังเป็นคนละตัว |
|---|---|---|
| ก่อนเลื่อนขั้น | กลุ่มสกิลนักบุญรบและการแปลงความเสียหายจริงเป็นการรักษา | p ของเมตตาและธีรันต่างกัน โดยผลทำงานเฉพาะเมื่อเรียนโหนดที่เกี่ยวข้อง |
| เมตตาฝึกแนวที่เลือก | เลือกสกิลสามท่าจากที่เรียนและลงทุนต้นไม้อาชีพ | p ของเมตตาเสริมการใช้บางท่าและการจัดสัดส่วนรักษาตามโหนดจริง |
| ธีรันฝึกแนวที่เลือก | ใช้ชุดท่าอาชีพเดียวกันได้ | p ของธีรันให้เงื่อนไขแนวหน้าและรูปแบบแปลงรักษาตามโหนดจริง |
| หลังเลื่อนขั้น | ทั้งสองเข้าถึงส่วนต่อขยายอาชีพร่วมเพื่อพัฒนาท่าที่เลือก | ยังใช้ p ของแต่ละคน ทำให้การเลือกคู่ตัวดัดแปลงเหมาะต่างกัน |
| ดาวขั้นสูงเพิ่ม | ประสิทธิภาพเพิ่มตามสูตรที่จะจำลอง | ไม่มอบชุดกลไกเดียวกันที่ลบความต่างของทั้งสอง |

ขอบเขตที่ต้องเก็บ: รักษาจาก HP ที่ศัตรูเสียจริง ไม่รวม overkill/การสวนกลับ ไม่รักษาตัวเองด้วยการแปลงพื้นฐาน และไม่ขยายเป็นชุบหรือรักษาโดยไม่โจมตี

ต้องตรวจเพิ่มเป็นพิเศษ: ผลต่อขยายไม่ทำซ้ำ `communionRatio`, `shareThree`, `sharePriority` หรือ p3/p4 ที่มีอยู่แบบเปลี่ยนชื่อแล้วคิดแต้มอีกรอบ การยก “แบ่งรักษาสองคน” มาเป็นของใหม่โดยไม่ตรวจนี้จะซ้ำกับธีรันที่มีแล้ว

## 8. ผลต่อกาชาและการออกตัวใหม่

- ได้ตัวใหม่เริ่มขั้นพื้นฐาน แต่ต้องมีทางฝึกตามทีมปัจจุบันได้ ไม่ให้คนที่สุ่มได้ช่วงท้ายเกมต้องกลับไปวนทุกแมพจากศูนย์
- อัปดาวด้วยทรัพยากรที่หาได้จากการเล่น ตัวซ้ำช่วยเร่ง ไม่เป็นเงื่อนไขเฉพาะคน
- รุ่นแรกไม่สร้าง “ร่างขั้นสูง” เป็นตัวละครอีก ID ในตู้ เพราะจะทำให้ผู้เล่นต้องได้คนเดิมซ้ำเป็นคนใหม่และเพิ่มภาระถือครอง
- คนใหม่ในอาชีพเดิมใช้ชุดต้นไม้อาชีพ/ขั้นสูงร่วมกัน แต่ต้องมีกิ่ง p และบุคลิกที่ต่างจริง
- บิลด์ตัวใหม่ต้องทดสอบกับตัวเก่าที่ขั้นอาชีพ ดาว เลเวล และทุนอุปกรณ์เท่ากัน ไม่เปรียบตัวใหม่พร้อมของกับตัวเก่าพื้นฐานแล้วสรุปว่าสนุกกว่า
- เป้าระยะเวลาปั้นต้องนับทั้งคนใหม่พร้อมเล่น ทีมหลักสี่คน และขั้นสูงของคนโปรด; ร่าง 200 เศษ/ห้าดาวก่อนหน้ายังใช้ปิดต้นทุนนี้ไม่ได้

## 9. ผลกระทบกับของเดิมและ migration

| ของเดิม | ข้อกำหนดสำหรับสเปกลงโค้ดภายหลัง |
|---|---|
| ID/การถือครอง | คนเดิมคนเดียว เปลี่ยนขั้นอาชีพโดยไม่สร้างสมาชิกซ้ำหรือกินช่องค่ายเพิ่ม |
| เลเวล/EXP | เก็บไว้ ไม่รีเซ็ตเมื่อเลื่อนขั้น |
| อุปกรณ์ | ใช้ต่อได้ตามประเภทเดิม ทุนตีบวก/Lv/ค่าพิเศษ/การันตีฟาร์มไม่หาย |
| ท่าที่เรียน/ตำรา | เก็บเลเวลสกิลและสิทธิ์ท่าเดิม ส่วนต่อขยายตรวจว่าผู้เล่นมีท่านั้นจริง |
| p / grants จากเซฟเก่า | รักษาสิทธิ์เดิม ไม่ลบเพราะนำระบบใหม่มาแทน |
| แต้มที่ได้จากดาว | ต้องแปลงเป็นสิทธิ์ความก้าวหน้าหรือเครดิตแต้มที่มีทางมาตรฐานเทียบเท่า และป้องกันรับซ้ำ ไม่ทิ้งแต้มเก่า; สูตรยังเปิด |
| ดาว/ตัวซ้ำ/ตรา | แปลงตามตารางมูลค่าที่ต้องออกแบบในรอบเศรษฐกิจ พร้อมหน้าสรุป ไม่กำหนดอัตราแลกในรอบนี้ |
| ศึก/เที่ยวที่กำลังค้าง | ต้องเลือกนโยบาย migration ตามความเปลี่ยนแปลงกฎ และรักษาของผู้เล่น ไม่แก้ replay เก่าเงียบ ๆ |

ไม่รับประกันว่าบิลด์จะมีดาเมจเท่าเดิมทุกค่าเมื่อเปลี่ยนสูตรทั้งระบบ แต่ต้องรายงานความต่าง ทดสอบเนื้อหาที่เคยผ่าน และรักษามูลค่าการลงทุนอย่างตรวจสอบได้

## 10. เกณฑ์พิสูจน์ต้นแบบก่อนขยาย

1. ผู้เล่นอธิบายได้ว่าตำรา ดาว ต้นไม้ และเลื่อนอาชีพต่างกันอย่างไร
2. หลังเลื่อนขั้นมีการตัดสินใจใช้ท่าต่างขึ้น ไม่ใช่เพียงศึกจบเร็วขึ้นจากค่าสถานะ
3. คู่สองคนในอาชีพเดียวกันยังมีสถานการณ์ที่เหมาะต่างกัน
4. มีบิลด์ให้เลือกจริง แต้มไม่พอเรียนทุกทางพร้อมกัน และรีเซ็ตแล้วจัดใหม่ได้
5. ไม่มีเพิ่ม SPD/เทิร์น ไม่วนคืน CD/รักษา/สวนกลับ ไม่เกินขอบเขตกลไกอาชีพ
6. เนื้อเรื่องช่วงก่อนปลดขั้นสูงผ่านได้ด้วยทีมพื้นฐานและทรัพยากรจากการเล่น
7. นักเต้นรำ/นักบวชและสายประโยชน์อื่นมีคุณค่าจากการพัฒนาโดยไม่ทำลายจังหวะศึก
8. เซฟก่อนและหลังย้ายเก็บสมาชิก ของลงทุน สิทธิ์ท่า และของรางวัลได้ครบ

เทสต์เชิงระบบใช้ preview/replay และ sim คู่ก่อน/หลังที่ทุนเท่ากัน ส่วนความเข้าใจ/ความสนุกต้องใช้ playtest ไม่อ้างว่าผ่านจาก unit test อย่างเดียว งานรอบนี้ยังไม่ได้ทำต้นแบบหรือรัน sim เหล่านี้

## 11. ข้อที่อยากให้เจ้าของเลือกจากรอบนี้

ข้อเสนอหลักที่พร้อมนำไปหารือ:

1. สองขั้นอาชีพ แต่ละขั้นเริ่ม ★1 ถึง ★5; เลื่อนขั้นเป็นการเปลี่ยนสถานะระหว่างสองช่วง
2. หนึ่งเส้นทางขั้นสูงต่ออาชีพก่อน แล้วเลือกแนวเล่นในต้นไม้ส่วนต่อขยาย
3. เลื่อนขั้นเน้นท่าเดิม กิ่ง p เก็บเอกลักษณ์รายคน ไม่เพิ่มสกิลติดตั้งเกินสามช่อง
4. ดาวเพิ่มประสิทธิภาพ ส่วนแต้มและตัวเลือกเชิงบิลด์มาจากความก้าวหน้าที่เล่นหาได้
5. คง ★5 เป็นเงื่อนไขเลื่อนขั้นได้เมื่อมีทางฟาร์มดาวที่ไม่พึ่งได้ตัวซ้ำเฉพาะคน
6. ร่างขั้นสูงเป็นการพัฒนาตัวเดิม ไม่อยู่ในตู้เป็นอีก ID

รายละเอียดที่ตั้งใจเว้นไว้รอบนี้: ชื่อคลาสขั้นสูงทั้ง15, effectรายท่า, สูตรแต้ม/ชดเชย, โบนัสดาว, Lv/บทที่ปลด, ค่าใช้จ่าย, แหล่งและจำนวนแจกเศษดาว, อัตรากาชา ทั้งหมดต้องต่อจากโครงที่เจ้าของเลือก

รอบถัดไปที่เสนอหลังเลือกโครง: จัดเส้นเวลาพัฒนาหนึ่งคนและทีมสี่คน → เลือกชุดต้นทุน/รายได้หลายแบบเพื่อจำลอง → ทำต้นแบบหนึ่งอาชีพสองคน โดยยังไม่เปลี่ยน C12 ทั้งแค็ตตาล็อกพร้อมกัน
