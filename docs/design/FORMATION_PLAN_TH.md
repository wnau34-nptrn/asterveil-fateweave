# แผนจัดแผนการยืนฝั่งเรา (Formation) — เจ้าของอนุมัติ 2026-10-22

ต่อจาก A7 ขั้นที่ 3 (สนาม 8 ตัว) เจ้าของขอ: สนามแต่ละฝั่งเป็น 2 คอลัมน์ × 3 ช่อง (บน/กลาง/ล่าง) ลงได้ 4 ตัว และ "ฝั่งเราก็ยืนได้ เปิดให้จัดแผนได้"

## การตัดสินใจของเจ้าของ (2026-10-22)

1. **ย้ายหน้า/หลังได้จริง** — แนวที่ยืน (คอลัมน์) คือแนวหน้า/หลังในกติกา ไม่ใช่อาชีพอีกต่อไป
   - ศัตรูท่ากายภาพตีแนวหน้าก่อน (เหมือนเดิม แต่ดูจากแนวที่ยืน)
   - กติกาแถวหน้าศัตรูบัง: ฮีโร่ที่ **ยืนแนวหน้า** ตีเป้าเดี่ยวได้แค่แถวหน้า (ยกเว้นสกิลตีทะลุ) ฮีโร่ที่ **ยืนแนวหลัง** ตีได้ทุกช่อง
   - ตั้งหลัก/กำแพงหอก (brace/spearwall) ดูแนวที่ยืน
   - `lane` ในข้อมูลอาชีพกลายเป็น "แนวแนะนำ" (ค่าเริ่มต้นของแผน + คำแนะนำในหน้าจัดแผน)
2. **จัดได้ที่หน้าทีมในค่าย + กระเป๋าบนแผนที่** (นอกศึก) แผนบันทึกไว้และใช้ทุกศึก ห้ามเปลี่ยนระหว่างศึก
3. **คอลัมน์ละสูงสุด 3 ตัว** — จัดได้ 2/2, 3 หน้า 1 หลัง, 1 หน้า 3 หลัง; คอลัมน์ที่มีตัวเดียวยืนช่องกลาง (เหมือนศัตรู, `slotPlan`)
4. **ไม่ย่อตัวเหลือ 80%** (เจ้าของ 2026-10-22, แทนร่างเดิม): คงขนาดตัวเต็ม หาที่ด้วยการบีบ HUD บน/ล่างแทน — ทำแล้ว สนามสูง 513px ที่ 390×844 (เดิม 455) ให้ `field-layout` วาง 3 แถวขนาดเต็ม ถ้าแถบ HP/ตัวเกยกันเล็กน้อยให้เยื้องตัวกลางเข้าหากลางสนามแทนการย่อ
5. **คง 4 ต่อ 4** (ไม่ทำ 5 ต่อ 5) — **สัตว์เลี้ยงมายืนในสนาม** ในช่องว่างของฝั่งเรา (ระบบสัตว์เลี้ยงตามแผนใหญ่: ตัวช่วยท้ายรอบ ไม่อยู่ในคิว SPD ไม่เป็นเป้า) ตอนทำแผนให้เว้นช่องว่างที่สัตว์เลี้ยงจะยืนได้ (ฝั่งเรามี 6 ช่อง ฮีโร่ 4 ตัว)

## ทำอย่างไร (ร่าง ให้แชตที่ทำงานนี้ตัดสินรายละเอียดเอง)

- **ตัวคิดผล:** แทบไม่ต้องแก้ — `engine.ts` อ่าน `data.heroes[].lane` อยู่แล้ว (screened, เป้ากายภาพ, brace) งานจริงคือให้ `lane` มาจากแผน: world (`withParty`/`memberDef`) ใส่ `lane` ตามแผนของสมาชิก เทสต์: ฮีโร่แนวหลังโดนกายภาพเมื่อแนวหน้าล้มหมด, นักเวทยืนหน้าถูกบัง, อัศวินยืนหลังไม่โดนกายภาพ, 3/1 และ 1/3, preview = resolve, replay
- **ลำดับเป้าศัตรู (`targetSlot`):** ยังตามลำดับ `roster.deployed` เหมือนเดิม (แผนไม่เปลี่ยนว่าศัตรูเล็งใคร นอกจากผลของแนว)
- **เซฟ v36:** เก็บแผน (เช่น `roster.lanes: Record<id, 'front'|'back'>` หรือตำแหน่งต่อช่อง) ตรวจ: คอลัมน์ละ ≤3, ทุกตัวที่ลงสนามมีแนว; เซฟ v35 ใช้แนวแนะนำของอาชีพ (ผลเท่าเดิม); ศึกที่ค้างอยู่ replay ด้วยแนวที่ใช้ตอนเข้าศึก — ถ้าแผนเปลี่ยนได้แค่นอกศึก ให้บันทึกแนวไว้ใน `ActiveBattle` ตอนเริ่มศึก
- **สนาม (`field-layout.ts`):** `slotPlan` รับแนวจากแผน; คอลัมน์ 3 ตัว: บน/กลาง/ล่าง ขนาด ~80% ไม่ให้แถบ HP ทับตัว (ขยายเทสต์ `tests/field-layout.test.ts`)
- **UI จัดแผน:** หน้าทีมในค่าย + กระเป๋าบนแผนที่: ตาราง 2×3 ของฝั่งเรา แตะตัว → แตะช่อง (ไม่ใช้ลากอย่างเดียว ปุ่ม ≥44px คีย์บอร์ดได้) บอกผล: "แนวหน้ารับการโจมตีกายภาพ · แนวหน้าตีแถวหลังศัตรูไม่ได้ขณะถูกบัง" และเตือนเมื่ออาชีพยืนนอกแนวแนะนำ
- **ตัวช่วยแนะนำ (advisor) และตัวจำลอง:** advisor ใช้แนวที่ยืนจริง; `npm run sim` รันเทียบแผนแนะนำกับ 3/1, 1/3 และสลับอัศวิน/นักเวท — รายงานถ้าแผนใดเหนือกว่าชัดเกิน (เช่น 1/3 ทำให้ไม่มีใครโดนกายภาพ) แล้วเสนอปรับ (เช่น ศัตรูกายภาพตีแนวหลังได้ถ้าแนวหน้ามีตัวเดียว — ต้องถามเจ้าของก่อนเพิ่มกติกาใหม่)
- bump `EncounterDefinition.version` ไม่จำเป็น (ข้อมูลศึกไม่เปลี่ยน) แต่เซฟต้อง v36

## ลำดับ

1. ตัวคิดผล/world + เซฟ v36 + เทสต์ → 2. `field-layout` 3 ตัวต่อคอลัมน์ → 3. UI จัดแผน (ค่าย + กระเป๋า) → 4. ตัวจำลอง + รายงานเจ้าของ → ภาพ 390px → push

## สถานะ — ทำเสร็จ 2026-10-22 (เซฟ v36)

- **กติกา:** `core/world/formation.ts` — แนวที่ยืน = แผนที่ตั้งไว้ (`roster.lanes`) ไม่ตั้ง = แนวแนะนำของอาชีพ; คอลัมน์ละ ≤3 (ตัวที่ 4 ของคอลัมน์เดียวกันถูกย้ายไปอีกคอลัมน์ตามลำดับช่อง); ตัวคิดผลไม่ต้องแก้ — `battleData` ส่งทีมที่ใส่แนวที่ยืนแล้ว (`placed`) กายภาพ/การบัง/ตั้งหลักจึงดูแนวที่ยืนเอง ลำดับเป้าศัตรูยังตาม `roster.deployed`
- **เซฟ v36:** `Roster.lanes` (ไม่มี = แนวอาชีพ; คีย์เป็นฮีโร่ใดก็ได้ในแคตตาล็อก ตัวที่ถูกพักในค่ายจำแนวเดิมไว้), `ActiveBattle.lanes` บันทึกแนวที่ตั้งไว้ตอนเริ่มศึก (ศึกที่ค้างจาก v35 ไม่มี → ทุกตัวยืนแนวอาชีพแบบเดิม ไม่จำกัด 3) เปลี่ยนแผนได้นอกศึกเท่านั้น (`setPartyLane` ในค่าย, `setLane` บนแผนที่)
- **UI:** `ui/formation-grid.ts` ตาราง 2×3 (แนวหลังซ้าย แนวหน้าขวา เหมือนในสนาม) ในหน้าทีมของค่าย และแท็บทีมของกระเป๋า/แคมป์ แตะตัว → แตะช่องว่างหรือคนในอีกแนว (สลับ) ปุ่ม ≥44px ใช้คีย์บอร์ดได้; บอกผลของแนว + เตือนเมื่ออาชีพยืนนอกแนวแนะนำ; การ์ดทีมและหน้าตัวละครแสดงแนวที่ยืนจริง; แผนที่ตั้งบนแผนที่ใช้เฉพาะรอบนั้น (เหมือนการสลับตัวในกระเป๋า) แผนในค่ายติดตัวทุกการเดินทาง
- **สนาม:** คอลัมน์ 3 ตัวยืน บน/กลาง/ล่าง **ขนาดเต็ม** (ช่อง 8/9): สนามสูงพอ (390×844 หลังบีบ HUD = 513px) เรียงตรง 3 แถวเท่ากัน และคอลัมน์ฮีโร่อีกคอลัมน์ยืนแถวเดียวกัน (ตัวเดียว = แถวกลาง) แถบ HP อยู่ระดับเดียวกัน; สนามเตี้ยกว่านั้นใช้แบบเยื้องตัวกลางเข้ากลางสนาม (แถบ HP ตัวบนอยู่เหนือหัว)
- **เทสต์:** `tests/formation.test.ts` (กติกา, นักเวทยืนหน้าถูกบัง, อัศวินยืนหลังไม่โดนกายภาพจนแนวหน้าล้ม, 3/1, 1/3, ตั้งหลัก, preview = resolve, replay, เซฟ v36/v35), `tests/browser/formation.spec.ts` (ค่าย: แตะ+คีย์บอร์ด, เต็ม 3 แล้วได้แค่สลับ; กระเป๋า; สนาม 3/1) ภาพรีวิว: `FORMATION_SHOTS=<โฟลเดอร์> npx playwright test tests/browser/formation.spec.ts`
- **ตัวจำลอง** (`npm run sim` → `docs/validation/formation-sim/REPORT.md`): แผนที่ 1 ทั้งบท (12 seed × 2 แบบ × 4 รอบ) ทุกแผนจบได้ 98–99% แพ้ยกทีม 1–2%; ศึกเดี่ยว Lv11 (10 ชุดศึก) ผู้ช่วยแนะนำชนะ 10/10 ทุกแผน เลือดเหลือ 91–97% — **ไม่มีแผนใดเหนือกว่าจนต้องแก้กติกา** ข้อสังเกต: ถ้ากดโจมตีอย่างเดียว 1/3 (นักดาบถอยหลัง) ชนะ 9/10 เทียบ 2/2 ชนะ 6/10 เพราะนักดาบแนวหลังตีแถวหลังศัตรูได้และอัศวินรับกายภาพคนเดียว — ยังไม่เสนอกติกาใหม่ (ถ้าเจ้าของอยากให้แนวหน้าตัวเดียวรับไม่ไหว ค่อยคุยเรื่อง "กายภาพทะลุถึงแนวหลังเมื่อแนวหน้ามีตัวเดียว")
