# ข้อเสนอ: ศัตรูเลือกเป้าตามกติกา (ร่าง รอเจ้าของเลือก)

19 พ.ย. 2026 · สาขา `claude/enemy-aim-proposal` (ยังไม่ merge) · ผลจำลองดิบ [campaign.md](../validation/enemy-aim-2026-11-19/campaign.md)

## ตอนนี้

ทุกท่าของศัตรูเขียนช่องเป้าไว้ตายตัว (`IntentDefinition.targetSlot`) ไม่มีการดู HP, อาชีพ หรือเป้าของศัตรูตัวอื่น กฎที่เปลี่ยนเป้าได้มีแค่: ท่ากายภาพต้องตีแนวหน้าก่อน, เป้าล้มแล้วให้ตีคนแรกที่ยืน, และยั่วยุ/ท้าดวล/ปฐพีสั่น/ศิลาดึง

## สิ่งที่สร้างในสาขานี้ (ยังไม่มีศัตรูใช้)

`IntentDefinition.aim` เป็นช่องที่ไม่บังคับใส่ทีละท่า ถ้าไม่ใส่ก็เป็นแบบเดิม

| aim | เลือกเป้า | เสมอกัน |
|---|---|---|
| `weakest` | คนที่ HP เหลือเป็น % ต่ำสุดในบรรดาคนที่ท่านั้นตีถึง | ใช้ช่องที่เขียนไว้ |
| `support` | สายสนับสนุนคนแรก (Priest, Saint, Bard, Dancer, Alchemist, Seer) | ไม่มีให้ใช้ช่องเดิม |
| `pack` | ตีตามเป้าของศัตรูตัวแรกที่ยังยืน | ใช้ช่องเดิม |

- กฎเดิมยังมาก่อน: กายภาพตีแนวหน้าก่อน, ยั่วยุ/ท้าดวล/ปฐพีสั่น/ศิลาดึงยังดึงเป้าได้, ท่าตีทั้งทีมและท่าชาร์จไม่เปลี่ยน
- ยังประกาศล่วงหน้าเหมือนเดิม: เป้าคำนวณจากสถานะตอนนั้นแล้วล็อกตอนศัตรูเริ่มเทิร์น ผลแน่นอนทุกครั้ง พรีวิวเท่ากับผลจริง และเล่นซ้ำได้ (`tests/enemy-aim.test.ts`)

## ผลจำลองทั้งแคมเปญ

แต่ละแบบเล่น 120 ค่าย (advisor 12 × rush/explorer, casual 48 × rush/explorer) แมพ 1→2→3 แล้วโหมดยาก ใช้ตัวคำนวณจริง ซ้ำได้ด้วย `AIM_OUT=<dir> npx vitest run tests/probe/enemy-aim.test.ts` (~33 นาที)

| แบบ | กติกา | casual ผ่านครั้งแรก แมพ 1 / 2 / 3 | casual ยากครั้งแรก | เที่ยวที่ไม่ผ่าน/ค่าย | advisor แมพ 2 |
|---|---|---|---|---|---|
| ปัจจุบัน | ช่องตายตัว | 97% / 91% / 98% | 99% | 0.16 | 100% |
| A นักล่า | ศัตรูแถวหลังเล็ง HP% ต่ำสุด | 90% / **75%** / **85%** | 97% | 0.58 | 92% |
| B ไล่ฮีล | ท่าพลังงานแถวหลังเล็งสายสนับสนุน | 99% / 83% / 92% | 96% | 0.27 | 100% |
| C ฝูง | แถวหน้าตีตามตัวแรก | 99% / 88% / 99% | 99% | 0.16 | 96% |
| D บอสฉลาด | บอสเล็ง HP% ต่ำสุดทุกท่าที่สอง | 98% / 92% / 96% | 99% | 0.17 | 100% |
| E ผสม A + C | | 88% / **70%** / **81%** | 98% | 0.75 | 92% |
| F สุดทาง | ทุกตัวเล็ง HP% ต่ำสุดทุกท่า | 86% / **69%** / **67%** | **79%** | 1.10 | 92% |

ผู้เล่นที่ทำตามคำแนะนำทุกเทิร์น (advisor) ยังผ่านทุกแมพได้ในทุกแบบ ต่างกันที่ผู้เล่นทั่วไป (casual) ศัตรูสุ่มยังชนะเกือบ 100% ทุกแบบ ส่วนที่ยากขึ้นคืออีลีทและบอส ซึ่งเสียคนกลางทาง

## อ่านผล

- **D บอสฉลาด** แทบไม่เปลี่ยนความยาก (casual ต่างไม่เกิน 2 จุด) แต่ทำให้บอสดูมีความคิด ผู้เล่นต้องดูว่าบอสจะตีใครแล้วกันคนนั้น
- **C ฝูง** แทบไม่เปลี่ยนความยาก (แมพ 2 ลด 3 จุด) เหมาะกับฝูงลูกน้อง ให้การตั้งรับแทนหรือโล่คุ้มค่าขึ้น
- **B ไล่ฮีล** ยากขึ้นปานกลางที่แมพ 2 (91→83%) ทำให้ต้องปกป้องสายฮีล
- **A นักล่า / E / F** ยากขึ้นชัดเจน (แมพ 2 casual เหลือ 69–75%) ถ้าใช้ต้องลดดาเมจหรือ HP ศัตรูกลับมาชดเชย

## ข้อแนะนำ

1. ใช้ **D กับบอส** และ **C กับศัตรูฝูง** เป็นค่าตั้งต้น ความยากเกือบเท่าเดิมแต่ศัตรูดูฉลาดขึ้น
2. ใช้ **B (ไล่ฮีล)** เฉพาะศัตรูบางชนิดที่ออกแบบเป็น "นักลอบสังหาร" เช่นภูตแถวหลังหนึ่งชนิดต่อแมพ ไม่ใช่ทุกตัวแถวหลัง แล้วจำลองซ้ำ
3. ยังไม่ใช้ A/E/F จนกว่าจะมีโหมดยากที่ต้องการความยากเพิ่ม
4. หน้าจอต้องบอกกติกาตรง ๆ ในป้ายท่า เช่น "เล็ง: HP ต่ำสุด" / "เล็ง: สายฮีล" / "ตามฝูง" เพื่อให้ผู้เล่นวางแผนได้ (ตอนนี้ยังไม่ได้ทำ UI)
