# แชท: แถบในค่าย, mute/report และช่อง 1:1 / กิลด์ (เตรียมไว้) — 2026-11-19

เจ้าของ 2026-11-19: "เริ่มทำตามข้อเสนอได้เลย ค่าเริ่มต้นปิด เพิ่ม ระบบ mute/report / ระบบ Chat 1:1 / Chat Guild เตรียมไว้" (OD-55) ต่อจาก [CHAT_P11_TH.md](CHAT_P11_TH.md) ไม่แตะกติกา เซฟ หรือรางวัล

## 1. ทำแล้ว (ใช้งานได้)

- **แถบแชทใสบนหน้าค่าย** `#chat-feed`: ปิดเป็นค่าเริ่มต้น (ต่ออุปกรณ์ ใน localStorage `asterveil.fateweave.chatfeed.v1`) เปิด/ปิดได้ 3 ที่ — ปุ่ม `#chat-feed-camp` บนค่าย, ปุ่มในหน้าต่างแชท, Setup บนหน้าเริ่ม (`#chat-feed-setup`) เฉพาะเล่นออนไลน์
  - แสดงข้อความล่าสุดไม่เกิน 3 บรรทัด แต่ละบรรทัดอยู่ 45 วินาทีนับจากที่เครื่องได้รับ (อ่านครั้งแรกของเซสชันแสดงเฉพาะที่เซิร์ฟเวอร์ประทับเวลาในรอบ 45 วินาที ประวัติเก่าไม่เด้งขึ้น)
  - อ่านทุก 10 วินาที **เฉพาะ** ตอนแถบเปิด + เห็นหน้าค่าย + แท็บมองเห็น + หน้าต่างแชทปิด ปิดแถบ/ออกจากค่ายแล้วหยุดทันที แตะแถบเพื่อเปิดแชทเต็ม
  - ข้อความตั้งด้วย `textContent` ค่ายที่ซ่อนไว้ไม่ขึ้นในแถบ
- **mute / report**: ของเดิมมีอยู่แล้วในแชทเต็ม — แจ้ง 4 เหตุผล (แจ้ง 3 ค่ายข้อความถูกซ่อน), ผู้ดูแลซ่อนข้อความและระงับการพิมพ์ 1 นาที–30 วัน (บันทึก `admin_audit`), ซ่อนค่ายบนเครื่องนี้ ที่เพิ่ม: **รายการ "ค่ายที่ซ่อนไว้" พร้อมปุ่มเลิกซ่อน/เลิกซ่อนทั้งหมด** (เดิมเลิกซ่อนไม่ได้) การซ่อนยังอยู่ในเครื่องนี้เท่านั้น ไม่ผูกบัญชี
- **ช่องแชท (เตรียมไว้)**: ทะเบียนช่อง `src/core/chat/channels.ts` (`world` เปิด; `dm`, `guild` ปิด), รูปแบบ id ที่เก็บ (`dm:<บัญชีเรียงลำดับ>:<บัญชี>`, `guild:<id 16 hex>`), `mayRead`; DO แชท `read/post` รับ channel; Worker รับ `?channel=` / `channel` เป็น **ชนิดช่อง** (ไม่ใช่ id) ช่องปิดตอบ 403 `chat_channel_closed` ชนิดแปลกตอบ 400 หน้าต่างแชทมีแท็บ แชทโลก / แชทส่วนตัว / แชทกิลด์ สองแท็บหลังกดไม่ได้ ติดป้าย "เร็ว ๆ นี้"

## 2. ยังไม่เปิด และต้องให้เจ้าของตัดสินก่อน

### แชท 1:1 (`dm`)
- ต้องมีวิธีหาคน: รหัสเพื่อน/คำเชิญ (ตอนนี้ผู้เล่นเห็นแค่ชื่อแฝง `ค่าย-XXXXX` ที่ย้อนกลับไม่ได้ ไม่มีวิธีส่งหาใคร) และรายชื่อเพื่อน
- แนะนำ: เริ่มได้เมื่อ **สองฝ่ายยอมรับ** เท่านั้น (ไม่รับข้อความจากคนแปลกหน้า), บล็อกคนระดับบัญชี (ฝั่งเซิร์ฟเวอร์ ไม่ใช่แค่ในเครื่อง), เก็บ 7 วัน/200 ข้อความต่อห้อง, อัตราส่งเข้มกว่าแชทโลก, รายงานแนบข้อความรอบข้าง, ผู้ดูแลอ่านได้เฉพาะห้องที่ถูกรายงาน (บันทึก audit)
- ตัวกรองเดิมใช้ต่อได้ (ห้ามลิงก์/อีเมล/เบอร์)

### แชทกิลด์ (`guild`)
- **เกมยังไม่มีกิลด์** ต้องออกแบบก่อน: สร้าง/เข้าร่วม/ออก, ขนาดสูงสุด, บทบาท (หัวหน้า/ผู้ดูแล), ใครเชิญ, ความเกี่ยวข้องกับ World Boss/ภารกิจ และการลบกิลด์ (ลบข้อความ)
- `mayRead` รอรายชื่อสมาชิกจากระบบกิลด์ (กิลด์ที่ไม่รู้จักไม่รับใครเลย)
- ผู้ดูแลกิลด์ควรซ่อนข้อความในกิลด์ตัวเองได้ ส่วนการแบน/mute ระดับแพลตฟอร์มยังเป็นของผู้ดูแลเกม

### คำถามให้เจ้าของ
1. เปิดช่องไหนก่อน: 1:1 (ต้องมีเพื่อน) หรือกิลด์ (ต้องมีกิลด์) — แนะนำเริ่มจากระบบเพื่อน/รหัสเพื่อน
2. การซ่อนค่ายให้ผูกบัญชี (ข้ามเครื่อง) หรือคงบนเครื่องนี้
3. ค่าเริ่มต้นของแถบแชทหลังผ่านด่านแรกยังคงปิดไหม (ตอนนี้ปิดเสมอ)
4. ช่วงทดสอบภายนอก ยังไม่เปิด 1:1/กิลด์ (แนะนำ) หรือจะเปิดด้วย
