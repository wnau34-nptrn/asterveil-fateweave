# ตรวจความน่าใช้และความซ้ำซ้อนของทุกสกิล (ร่าง 2026-10-23 — เจ้าของอนุมัติ 2026-10-24, ส่ง Codex ลงโค้ดเป็น C11)

ที่มา: เจ้าของเห็นว่าบางสกิลไม่น่าใช้ (เช่นยาเร่ง) และสกิลบางตัวทับกัน หลักที่ใช้ตรวจ (`docs/MASTER_PLAN_TH.md` A6b): **ทุกตัวลงเล่นได้, แต่ละกลุ่มกลไกมีอาชีพเจ้าของเดียว, ตัวใหม่ต่างไม่ใช่แรงกว่า** ไม่มีระบบธาตุ

ผลตรวจนี้มาจากการไล่กฎในโค้ดทีละสกิล ตัวเลขการใช้งานจริงต่อสกิล (ใช้บ่อยแค่ไหน ช่วยชนะ/เหลือเลือดแค่ไหน) ต้องวัดด้วยตัวจำลองตอนลงโค้ด (Claude หลัง Usage รีเซ็ต) — สัญญาณที่มีแล้ว: บิลด์เงาล่อของเซฟาใช้สกิลต้นไม้แค่ 2 ครั้งใน 10 ศึก (`docs/validation/balance-sim/TREES.md`)

## 1. เจ้าของกลไก (เสนอ)

| กลุ่มกลไก | เจ้าของ | หมายเหตุ |
|---|---|---|
| ดึงท่าศัตรูเข้าหาตัว | **ผู้คุมค้อน** (ทั้งหมด) · **อัศวิน** (ทีละท่า/รับแทน) | ทวน สอดแนม ต้องเลิกดึง |
| ยกเลิกท่า | อัศวิน (กายภาพ) · นักเวท (พลังงาน) | คู่กันอยู่แล้ว ✅ |
| ลดท่าถัดไป % | **นักเล่นแร่** (ควัน) | สอดแนม ผู้คุมค้อน กวี (โน้ตสะกด) ธนู (ยิงสกัดหนัก) ต้องเลิก |
| เลื่อนคิวศัตรู | **ธนู** | ทวน นักเวท ผู้คุมค้อน ต้องเลิก |
| เร่งคิวเพื่อน | **นักเล่นแร่** (ยาเร่ง — แก้แล้ว v40) | |
| ดาเมจเพิ่มบนเป้า | นักดาบ (ตรา) · นักเล่นแร่ (กร่อน) | สองแบบต่างกัน (ใช้หมด vs ค้างหลายรอบ) ✅ |
| บัฟพลังโจมตีเพื่อน | **กวี** (เพลง) · นักเล่นแร่ (ยาคลั่ง มีราคาต้องจ่าย) | นักบวช ทวน อัศวิน ต้องเลิก |
| รักษาเลือด | **นักบวช** | อัศวิน (ปลุกพล) ต้องเลิก; กวีเพลงฟื้นเป็นรักษาเบาต่อเนื่อง ยอมรับ |
| โล่ให้เพื่อน | **นักเวท** | ของอาชีพอื่นที่เป็นตัวดัดแปลงเล็กๆ ยอมรับได้ |
| หลบ | **สอดแนม** | ธนู (ถอยยิง) ต้องเลิก |
| โต้กลับ | **ทวน** | นักดาบ/อัศวิน/ผู้คุมค้อน/สอดแนม มีโต้เฉพาะเงื่อนไขตัวเอง ยอมรับ |
| ตีหมู่ | หลายอาชีพ คนละรูปแบบ | ยอมรับ ✅ |

## 2. ผลตรวจรายสกิล

✅ ดี · ⚠ ใช้ได้แต่ควรปรับ · ❌ ต้องแก้ (ทับซ้อนหรือไม่น่าใช้)

### อัศวิน
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|
| ตั้งรับแทน, กระแทกโล่ | ✅ | | |
| ตั้งรับหมู่ | ✅ | | |
| ท้าดวล | ✅ | เป็นเจ้าของ "ดึงทีละท่า" | |
| ปราการหิน | ❌ | ≈ ยั่วยุของผู้คุมค้อน (โค้ดเดียวกัน) | **กำแพงโล่:** เพื่อนแนวหน้าทั้งแถวรับความเสียหายลดลงจนถึงเทิร์นถัดไปของอัศวิน ไม่ดึงเป้า |
| ปลุกพล | ❌ | รักษาทั้งทีม ทับพรฟื้นฟู | **ยืนเคียงข้าง:** เพื่อนที่เลือดต่ำสุดได้รับการรับแทนอัตโนมัติจากอัศวินจนถึงเทิร์นถัดไป (ครอบครัวรับแทนของอัศวินเอง) |
| ตัวดัดแปลง ธงขวัญกล้า | ❌ | บัฟพลังโจมตี | **ธงรวมพล:** ตั้งรับหมู่ครอบคลุม 2 ครั้งต่อคน |

### นักดาบ
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|
| ติดตรา, ฟันเจาะจุด, ปลิดชีพ, พุ่งตัด | ✅ | | |
| ปัดดาบ | ✅ | โต้เฉพาะตัวเอง | |
| ฟันกวาด | ⚠ | ตีหมู่ธรรมดา | ฟันกวาดติดตราเป้าที่เลือดน้อยสุดในแถว (ผูกกับกลไกตรา) |

### นักเวท
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|
| ศรเวท, โล่เวท, ตรึงเวท, พายุเวท, เกราะผลึก | ✅ | | |
| สลายเวท | ❌ | ใช้ได้แค่โหมดยาก (เกราะพลังงาน) | ปิด "ไม่หวั่นไหว" ของบอสด้วย → ใช้กับบอสทุกโหมด |
| ตัวดัดแปลง ผนึกถ่วง | ❌ | เลื่อนคิว (ของธนู) | **ผนึกต่อ:** ถ้ายกเลิกได้ ท่าพลังงานถัดไปของมันเบาลงด้วย — หรือเปลี่ยนเป็นโล่ให้เป้าที่ถูกเล็ง |

### นักบวช
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|
| รักษา, พรฟื้นฟู, พรคุ้มภัย, ฟื้นคืน, วงแสงคุ้มกัน | ✅ | | |
| พรกล้า | ❌ | บัฟพลังโจมตี (ของกวี) | **พรต่อเนื่อง:** เพื่อน 1 คนฟื้นเลือดตอนต้นรอบ 2 รอบ (รักษาต่อเนื่องเฉพาะคน — ต่างจากเพลงฟื้นที่ทั้งทีม) |

### ทวน
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|
| ตั้งทวน, แทงทะลวง, กำแพงทวน | ✅ | | |
| ปักหลัก | ❌ | ดึงท่า (ของผู้คุมค้อน/อัศวิน) | **ทวนคุ้มหลัง:** ทุกท่ากายภาพที่โดนเพื่อนแนวหลังจนถึงเทิร์นถัดไป ทวนโต้กลับ (ครอบครัวโต้กลับของทวน) |
| แทงหยุดยั้ง | ❌ | เลื่อนคิว (ของธนู) | **แทงสวนจังหวะ:** ถ้าท่าถัดไปของเป้าเป็นกายภาพ แทงแรงขึ้น 50% |
| เสียงศึกทวน | ❌ | บัฟพลังโจมตี | **เสียงศึก:** เพื่อนแนวหน้าทุกคนโต้กลับท่ากายภาพครั้งแรกที่โดนจนถึงเทิร์นถัดไป |

### ธนู
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|
| ยิงสกัด, ห่าธนู, ศรจุดอ่อน, ศรตรึงแถว, ศรตามรอย | ✅ | เจ้าของเลื่อนคิว | |
| ถอยยิง | ❌ | หลบ (ของสอดแนม) | **ยิงถอยคิว:** ยิงแล้วเป้าไปท้ายคิวรอบนี้ถ้ายังไม่ได้ลงมือ (เข้ากลุ่มเลื่อนคิว) |
| ตัวดัดแปลง ยิงสกัดหนัก | ❌ | ลดท่าถัดไป (ของนักเล่นแร่) | ยิงสกัดแล้วเป้าไปท้ายคิว 2 รอบ |

### นักเล่นแร่
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|

| ยาคลั่ง | ✅ | บัฟที่มีราคา (รับดาเมจเพิ่ม) แยกจากเพลงกล้า | |

### สอดแนม

|---|---|---|---|

| ล่อเงา | ❌ | ดึงท่า + แทบไม่ถูกใช้ (2/10) | **เงาคุ้มกัน:** ให้ก้าวเงาแก่เพื่อน 1 คน (เจ้าของกลไกหลบ) |

| ตัวดัดแปลง ค้อนสะท้านฟ้า | ❌ | เลื่อนคิว | ทุบปฐพีที่ได้โบนัสฟื้นเลือดแบรนน์ |

### กวี
| สกิล | ผล | ปัญหา | ข้อเสนอ |
|---|---|---|---|
| เพลงกล้า, เพลงฟื้น, บทสุดท้าย, เพลงเดี่ยว | ✅ | เจ้าของบัฟพลังโจมตี | |
| เพลงสะท้าน | ⚠ | ลด 10% ทุกท่า — อ่อน | ลด 15% และบทสุดท้ายของเพลงนี้ให้โล่ทั้งทีม (ไม่ใช้ "ลดท่าถัดไป") |
| โน้ตคม | ⚠ | ดาเมจธรรมดา | แรงขึ้นตามจำนวนรอบที่เพลงเล่นต่อเนื่อง |
| ตัวดัดแปลง โน้ตสะกด | ❌ | ลดท่าถัดไป | โน้ตคมยืดเพลงที่เล่นอยู่ (ไม่หยุดเมื่อกวีโดนขัด) |

## 3. สรุป

- ต้องแก้ ❌: **ปราการหิน, ปลุกพล, ธงขวัญกล้า, สลายเวท, ผนึกถ่วง, พรกล้า, ปักหลัก, แทงหยุดยั้ง, เสียงศึกทวน, ถอยยิง, ยิงสกัดหนัก, ล่อเงา, ปลดอาวุธ, ปฐพีสั่น, ค้อนสะท้านฟ้า, โน้ตสะกด** (16 จุด)
- ควรปรับ ⚠: ฟันกวาด, ขวดระเบิด (คำอธิบาย), ลอบแทง, ทุบค้อนรูน, ศิลาคุ้มกัน, เพลงสะท้าน, โน้ตคม (7 จุด)
- ลงโค้ด: Opus หลัง Usage รีเซ็ต — เซฟเวอร์ชันใหม่คืนแต้มต้นไม้ของอาชีพที่โหนดเปลี่ยน, ขึ้น `EncounterDefinition.version` ถ้ากฎเปลี่ยน, เทสต์ทุกสกิลที่แก้, วัดความน่าใช้ทุกสกิลด้วยตัวจำลอง (นับการใช้ + ผลชนะ/เลือด) และรายงานก่อน/หลัง
- ไอคอนวาด (Codex C1) ใช้ id สกิลเดิม — สกิลที่เปลี่ยนความหมายมากอาจต้องวาดใหม่ภายหลัง
