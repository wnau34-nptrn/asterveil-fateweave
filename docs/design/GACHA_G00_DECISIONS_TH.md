## สถานะที่ใช้

- **Approved** = ข้อตัดสินเจ้าของที่มีอยู่ใน OWNER_DECISIONS หรือคำสั่งรอบนี้ ไม่ใช่การอนุมัติตัวเลขจากผลจำลอง
- **Draft** = ฐาน/ทางเลือกในแบบจำลอง ปรับได้ก่อนตกลงสเปก ไม่มีผลต่อเซฟหรือผู้เล่น
- **Open** = ต้องตัดสินหรือมีหลักฐานเพิ่มก่อน implementation; คำแนะนำในคอลัมน์ท้ายเป็นของผู้วิเคราะห์

## ข้อเสนอสำหรับรอบทดลองฟรีที่ยังต้องตรวจ

เริ่มชุด **80แต้ม/80ตั๋วต่อ28วัน/เรต7.5%/เศษ1–2** และคู่เทียบ100แต้ม/96ตั๋ว โดยใช้ทางรับคนฟรีและแร่ทองร่วมด้วย. ยังไม่ควรล็อกเรตหรือเริ่ม G05: เป้าเลือกคนโปรดที่ไม่ได้เริ่มด้วยกับเป้า7–10ครั้งยังมีช่องว่าง; ฟาร์มและงบจากโหมดที่ยังไม่มีต้องออกแบบเป็นแหล่งจริงก่อน

ไม่เสนอขึ้นเรตเพื่อชดเชยทางรับคนโปรดโดยทันที เพราะเพิ่มเศษทั้ง15คนและเร่งช่วงหลังพร้อมกัน. ทางเลือกที่ควรศึกษาต่อคือสิทธิ์เลือกคนโปรดเร็วหนึ่งครั้ง/สัญญาบอร์ดที่มีความคืบหน้าคงอยู่ เทียบกับการนับ7–10ครั้งหลังได้ตัว ซึ่งอย่างหลังทำให้ผู้เล่นยังอาจรอนานตั้งแต่เริ่มบัญชี

## คำถามที่ต้องเลือกหลังอ่านหลักฐาน

1. ยืนยัน **80เป็นค่าทดลอง** หรือเลือก100? แนะนำ80; ไม่ใช่การอนุมัติ production จากการ merge เอกสาร
2. เป้า7–10ครั้งให้นับจากเริ่มบัญชีสำหรับคนโปรดทุกคน หรือหลังได้ตัว? แนะนำวัดตั้งแต่เริ่มด้วยและออกแบบทางเลือกตัวเร็ว แทนปรับนิยามให้ตัวเลขผ่าน
3. ช่วงยังไม่มี Tower/PvP/WB จะจัดงบทดแทนก้อนใดและรับอย่างไรใน3ครั้ง/สัปดาห์? แนะนำ80รวมทั้งหมด ไม่มีภารกิจจากโหมดที่ยังไม่เปิด
4. ยอมรับเศษกลางทดแทน100%/ชดเชยเรื่องซ้ำ20/overflowหรือเก็บเศษขั้นสูงอย่างไร? ต้องอนุมัติเป็นชุดเดียวกับ P04 และ dry-runเซฟ ไม่เลือกแยกจนทำสิทธิ์ลด
5. เซฟofflineเดิมจะรับเป็นlegacyที่ใช้เล่นต่อได้แต่แยกสิทธิ์ออนไลน์, รับผ่านsnapshotตรวจครั้งเดียว, หรือสร้างonlineใหม่พร้อมชดเชยคงที่? แนะนำข้อแรกพร้อมทางsupport; ไม่เปิดตลาด/แข่งขัน/เงินจริงโดยเชื่อยอดlocal

G00 ส่งมอบ decision sheetแล้ว แต่ยัง **ไม่ใช่สเปกที่ sign-off**. G01 ส่งหลักฐานและข้อจำกัดแล้ว แต่ยัง **ไม่ผ่านเศรษฐกิจสำหรับเปิดจริง**. ขั้นถัดไปที่เหมาะสมคือทบทวนคำถามนี้และศึกษา targeted-acquisition/ภาระเที่ยวเล่นเพิ่ม; G02ทำได้เมื่อเจ้าของเลือกขอบเขตต้นแบบ, G03/G04/G05ยังติด P09/P04 และนโยบายสิทธิ์
