## 1. Chapters (ต่อจากที่ทำแล้ว)

ทำแล้ว: เฟส A (กฎร่วม, รายการแมพ, เซฟ v28), B1 (แมพ 1 ซากชายแดน, บอสหัวหน้ากองหน้า, อุปกรณ์ชิ้นแรก), ปุ่มเลือกแผนที่

1. **แก้ระบบ Codex ให้รองรับหลายแมพ**
   - เพดานเลเวลไอเทมนับเฉพาะจบแนวรอยแยก ไม่ใช่จบแมพไหนก็ได้
   - บอสแมพ 1 ใช้ตารางดรอปเบา (หายาก–มหากาพย์) เซ็ตเฉพาะโซน
   - ข้อความคู่มือของดรอป/ฟาร์ม/ช่างใช้ชื่อบอสของแมพ ซ่อนเครื่องรางบอสจนกว่าจะเปิดแนวรอยแยก
   - บอสทุกตัวได้จังหวะค้างตอนจบศึกแบบบอส
2. **เริ่มด้วยทหาร 1 คน** อัศวินคนเดียว ศึกแรกมีพันธมิตรชั่วคราว 3 คน แล้วเข้าร่วมถาวรทีละคนในแมพ 1 (หลังศึกแรก / ถึงแคมป์ / ชนะบอส) คนที่ 5 ขึ้นไปจากเควส NPC เนื้อเรื่องแมพ 2 และบอร์ดจ้าง
3. **ช่วยตัวใหม่ไล่ตาม** ตัวใหม่เข้าร่วมที่เลเวล (สูงสุดของบริษัท − 2), ตัวที่ต่ำกว่าค่าเฉลี่ยได้ EXP เพิ่ม, ตัวสำรองได้ EXP ครึ่งหนึ่ง
4. **ปลดล็อกระบบตามบท**
   - ผ่านแมพ 1: ช่าง (ตีบวก ล็อก), ต้นไม้, ยา, คลัง
   - ผ่านแมพ 2: จ้าง, ทีม 4+4, อัปดาว, ตลาด, หลอม, อัปเลเวลไอเทม, ตีอาวุธ, ฟาร์มเจาะจง
   - เปิดแนวรอยแยก: ย้ายค่าพิเศษ, เลือกเครื่องรางบอส
   - บริษัทเก่าเห็นครบเหมือนเดิม
5. **ภารกิจนำทาง** NPC ละ 1 ภารกิจ ข้ามได้ รางวัลเล็ก สอนตามลำดับข้อ 4
6. **แมพ 2 "เส้นทางป่าทึบ"** (Lv3–6) เหตุการณ์ อีลิท ปริศนา 1 อย่าง สลับตัวสำรอง เดินทางระหว่างแคมป์ สมุนไพร
7. **เพดานเลเวล 15** แนวรอยแยกเป็น Lv6–15 เพิ่มขั้นเพดานไอเทมต่อท้าย (เก็บ 3/6/9/10 เดิม) จำลองทั้ง 3 แมพ

## 2. ต้นไม้ใหญ่: สกิล active + พาสซีฟ

**เป้าหมาย** ผู้เล่นสร้างบิลด์ของแต่ละตัวได้จริง สองคนที่มีอาชีพเดียวกันเล่นต่างกันได้

**โครง (ต่ออาชีพ)**
- 3 กิ่งตามบทบาท เช่น อัศวิน: *ปราการ* (รับแทน ลดดาเมจ) / *ลงทัณฑ์* (โต้กลับ ทุบ) / *ธงนำ* (ปลุกขวัญ ช่วยทีม)
- แต่ละกิ่ง 4 ชั้น: ชั้นแรกเปิดตั้งแต่ Lv1, ชั้น 2 ที่ Lv5, ชั้น 3 ที่ Lv10, ยอดกิ่งที่ Lv15
- ชนิดโหนด
  - **สกิล** ปลดสกิล active ใหม่ (ประมาณ 6 สกิลต่ออาชีพ รวมของเดิม 3)
  - **ดัดแปลง** เปลี่ยนการทำงานของสกิล เช่น ศรเวทแยก 2 เป้า, ศรเวทติดไหม้ เลือกได้ 1 ใน 2 ต่อสกิล
  - **พาสซีฟ** ค่าสถานะหรือกฎ (ของเดิมย้ายมาที่นี่)
  - **ยอดกิ่ง** กลไกเด่น 1 อย่าง (พาสซีฟ ★5 เดิมย้ายมาเป็นยอดกิ่ง)
- แต้ม: 1 แต้มต่อเลเวล + แต้มจากเควส ประมาณ 18 แต้มที่ Lv15 จากโหนดรวมประมาณ 30 แต้ม จึงเลือกได้ราว 60% ของต้น
- **ช่องสกิลติดตัว 3 ช่อง** + โจมตีปกติ (ปุ่มในศึกยัง 4 ปุ่มเหมือนเดิม) เปลี่ยนชุดสกิลได้ที่ค่ายและบนแผนที่นอกศึก
- รีเซ็ตฟรีที่ค่าย (รักษาความอยากลองบิลด์)

**ดาวเปลี่ยนบทบาท** ดาวไม่ปลดสกิลอีกต่อไป (★3/★5 เดิมย้ายเข้าต้น) ดาวให้ค่าสถานะ + แต้มต้นไม้ +1 ต่อดาว ตัวซ้ำยังมีค่าแต่ไม่ล็อกสกิลหลัก ตรงกับข้อเสนอกาชาของ Codex

**ผลต่อโค้ด**
- `talents.ts` เป็นโครงต้นใหม่ `starred` แปลงโหนดเป็น actions + ตัวดัดแปลง resolver อ่านจาก HeroDefinition เหมือนเดิม ไม่อ่านโปรไฟล์
- เซฟใหม่: คืนแต้มทั้งหมดให้จัดใหม่ สกิลที่เคยได้จากดาวยังได้ฟรีเป็นโหนดเริ่มต้น
- ปรับกฎใน CLAUDE.md ("passive nodes only, no new battle buttons") ตามการตัดสินใจของเจ้าของ
- ทำทีละอาชีพ: อัศวิน → นักดาบ → นักเวท → นักบวช → อาชีพทหารรับจ้าง 6 อาชีพ แต่ละอาชีพมีเทสต์ resolver + ผู้แนะนำ + ชนะได้

**ภาพที่ต้องการ** ไอคอนสกิลแบบวาด (ART-SKILL-ICON-001) กรอบโหนดและพื้นหลังต้นไม้ (รวมใน ART-UI-MODERN-001)

## 3. สัตว์เลี้ยง

**แนวคิด** บริษัทเลี้ยงสัตว์ได้หลายตัว พาไปได้ 1 ตัวต่อการเดินทาง ไม่ใช่ตัวละครในคิว SPD (รักษากฎหนึ่งเทิร์นต่อหนึ่งตัว)

| ส่วน | กฎตั้งต้น |
|---|---|
| บนแผนที่ | พรสวรรค์ 1 อย่างต่อชนิด เช่น ส่องไกล (รัศมีหมอก +1), จมูกไว (โอกาสเจอหีบ/สมุนไพร), ฟื้นฟูระหว่างเดิน, ลดโอกาสเจอศัตรูเล็กน้อย, โชค |
| ในศึก | "ช่วยเหลือ" ตอนจบรอบทุก 3 รอบแบบแน่นอน (ไม่สุ่ม) เช่น โล่เล็กให้คนเลือดน้อยสุด, ฮีลเล็ก, ตีศัตรูที่มี Mark, ลดคูลดาวน์ 1 |
| เติบโต | เลเวลสัตว์ 1–10 ด้วยวัตถุดิบ/อาหาร (ใช้แร่และสมุนไพร) ไม่เพิ่ม SPD |
| ได้มาจาก | ไข่จากบอส/อีลิท/เควส ฟักที่ค่าย (NPC ผู้ดูแลคลังหรือนักปรุงยา) |
| เริ่มต้น | 6 ชนิดตามโซน: ทุ่ง, พงหนาม, รอยแผล, ซากป้อม, ป่าทึบ, ประตูรอยแยก |

ผลต่อโค้ด: `core/world/pets.ts` + เซฟ (profile.pets, run.pet) + resolver รับ `entry.pet` เป็นกฎตอนจบรอบ + เทสต์ผลซ้ำและ replay

ภาพที่ต้องการ: ART-PET-001 (concept → อนุมัติ → sprite)

## 4. UI/UX ทันสมัย

**ปัญหาที่เห็นจากภาพหน้าจอปัจจุบัน** หน้าตัวละคร/อุปกรณ์/ช่างเป็นตารางและบรรทัดข้อความ มี dropdown แบบเว็บ ปุ่มกับป้ายข้อความแย่งกันเด่น ข้อมูลสำคัญ (พลัง อุปกรณ์ที่ใส่) ไม่เด่นกว่ารายละเอียดรอง

**หลัก**
1. ไอคอน + ตัวเลข แทนประโยค (เลือด ❤ 102, เกราะ 🛡 3%) คำอธิบายยาวย้ายไปปุ่ม (i) หรือแตะค้าง
2. ภาพก่อนตัวหนังสือ: ตัวละครเต็มตัวกลางหน้าจอ ช่องอุปกรณ์ล้อมตัว (paper doll)
3. เปรียบเทียบด้วยสี: ▲ เขียว / ▼ แดง ข้างตัวเลข ไม่ใช่ตารางก่อน/หลัง
4. การ์ดไอเทมเรืองแสงตามความหายาก (โค้ดวาด ไม่ฝังในภาพ) แตะแล้วเปิดการ์ดรายละเอียด
5. ใช้ชุด component เดียวทั้งเกม: ปุ่ม, การ์ด, แท็บไอคอน, ชิปค่าสถานะ, ไทล์ไอเทม, bottom sheet, toast
6. การเคลื่อนไหวสั้นและมีความหมาย (กดแล้วยุบ, ของใหม่เด้ง, ตัวเลขนับขึ้น) และรองรับ reduced-motion
7. ข้อความ: แต่ละปุ่ม ≤ 2 คำ, คำอธิบายสกิล ≤ 1 บรรทัด + ตัวเลขสำคัญ, ใช้คำศัพท์ชุดเดียว (ทำ glossary) ลบคำอธิบายซ้ำ

**ลำดับหน้า**
1. ตัวละคร + อุปกรณ์ (paper doll, กริดไอเทม, การ์ดเปรียบเทียบ, ตัวกรองเป็นชิปแทน dropdown)
2. ช่างตีเหล็ก (ไอเทมกลางจอ, ชิปก่อน→หลัง, ปุ่มใหญ่ 1 ปุ่ม, ค่าใช้จ่ายเป็นไอคอน)
3. ต้นไม้ใหญ่ (กราฟโหนดเลื่อนได้ จิ้มดูรายละเอียด)
4. รางวัล/สรุปการเดินทาง (เปิดรางวัลทีละชิ้น)
5. HUD แผนที่และศึก (ปุ่มสกิลแบบวาด, แถบคิว SPD, intent ของศัตรู)
6. Lobby เมนูล่าง, หน้าจ้าง, ตลาด, ยา

**วิธีทำ** Codex ทำ mockup ทั้งชุดก่อน (ART-UI-MODERN-001) → เจ้าของเลือก → Claude ทำ component library + หน้าแรก (อุปกรณ์) → เจ้าของตรวจภาพจริงบนมือถือ → หน้าถัดไป UI ยังเป็น DOM ทั้งหมด (ตามกฎเดิม) ปุ่ม ≥ 44px

## 6. สมดุลรอบใหญ่

**เป้าความยาก (ตั้งต้น)**

| สถานการณ์ | เป้า |
|---|---|
| ผู้แนะนำ (เล่นดี) ที่เลเวลแนะนำ ศึกปกติ | ชนะ 90–95% เสียเลือดทีม 20–40% |
| ผู้แนะนำ อีลิท | ชนะ 70–85% |
| ผู้แนะนำ บอส ครั้งแรก | ชนะ 55–70% ต้องใช้กลไก (Guard/Ward/ขัดจังหวะ) |
| ตีปกติอย่างเดียว | แพ้อีลิทและบอสเสมอ |
| ต่ำกว่าเลเวลแนะนำ 2 | บอสชนะ < 30% |

**สิ่งที่ตรวจ**
- อาชีพ: ดาเมจ/ฮีล/การรับดาเมจต่อรอบต้องอยู่ในกรอบบทบาท ±15% ไม่มีอาชีพที่ดีกว่าทุกด้าน
- ต้นไม้: ทุกกิ่งต้องมีบิลด์ที่ชนะได้ ไม่มีกิ่งที่ห้ามเลือก
- ชุด 2/4 ชิ้นและ special ระดับตำนาน: มูลค่าใกล้กัน
- อุปกรณ์: เลเวล/ความหายาก/ตีบวกเพิ่มพลังตามเส้นที่วางไว้ ไม่ทำให้ศึกง่ายเกินเป้า
- สัตว์เลี้ยง: ช่วยประมาณ 3–5% ของพลังทีม
- ศัตรู: เพิ่มคุณสมบัติและชนิดดาเมจ, อีลิทมีค่าพิเศษ, บอสมีช่วงเปลี่ยนท่า
- เศรษฐกิจ: รายรับ/รายจ่ายแร่ ทอง ฝุ่น ต่อแมพ

**เครื่องมือ** ขยาย `npm run sim` ให้วนทุกอาชีพ × กิ่งต้นไม้ × ชุด × สัตว์ × แมพ ออกรายงานใน `docs/validation/balance-sim/` พร้อมรายการค่าที่หลุดเป้า เทสต์ guard ใน `npm test`

ทำ 2 รอบ: รอบเล็กตอนเพดานเลเวล 15 (สาย 1) และรอบใหญ่หลังต้นไม้ + สัตว์เลี้ยงเข้า (สาย 2–3)
