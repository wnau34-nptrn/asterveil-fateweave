# Execute "Rose-Gold Edge" และ Ward "Luminous Aegis" (A8)

วันที่ 22 ตุลาคม 2026 · **สถานะ: ลงเกมแล้ว รอเจ้าของดูคลิปก่อนขยายไปสกิลอื่น** ใช้ภาพวาด Codex ART-VFX-EXEC-WARD-001 (`public/assets/fx/execute_fx.*`, `ward_fx.*`) ภาษาเดียวกับ Bolt (`src/game/visuals/exec-ward-fx.ts`, ต่อใน `BattleScene.prepare/play`) จังหวะ contact/end เดิมจาก `stageTiming` ผลลัพธ์ทั้งหมดมาจาก event จริง (ผู้รับ ความเสียหาย โล่ ตรา)

## Execute

| จังหวะ | ที่เห็น | เวลา (ปกติ) |
|---|---|---|
| ก่อนปะทะ | ประกายที่คมดาบ แล้วรอยฟันโค้งเสี้ยวเดียวรอบเป้า (เปิดด้านผู้ฟัน) จบตรง contact | 0–150ms ประกาย, 150–298ms รอยฟัน |
| ปะทะ | ดาวสว่างที่ตัวเป้าจริง + เงาบางรอง ตัวเป้าติดสีชมพูอ่อน 90ms; ถ้ามีตราจริงบนเป้ามีวงชีพจรกุหลาบเล็กๆ ลอยเหนือหัว (ไม่แทนไอคอนตรา) | ที่ 298ms ตรงกับตอนเลือดลด |
| ตกลง | ประกายตกเบาๆ | ถึง ~850ms |

- โล่รับเต็ม: ดาวเล็กลง สีมุก ไม่มีแฟลชที่ร่าง/ไม่มีวงตรา · หลบ: ประกายคมดาบ แล้วเศษประกายผ่านเท่านั้น ไม่มีรอยฟัน/ดาว
- ความเข้มลดลง: ไม่มีวงตรา/ประกายตก · OS ลดการเคลื่อนไหว: ภาพนิ่ง `static_impact` จางๆ ที่ตัวเป้าทันที

## Ward

| จังหวะ | ที่เห็น | เวลา (ปกติ) |
|---|---|---|
| ก่อนผลลัพธ์ | เส้นด้ายถักที่ผู้รับโล่จริง (รวมร่ายใส่ตัวเอง) แล้วม่านโค้งปิดรอบตัว (เห็นหน้าและรูปร่าง) | จบตรง contact |
| contact | ม่านลงตัว (ไม่ใช่การปะทะ), เสี้ยวขอบ + รูนประกาย (ความเข้มลดลงตัดออก) | ตั้งแต่ contact |
| สลาย | ม่านค่อยจางเป็นขอบเรืองเบา | ถึง ~850ms |

- โล่แท้จริงยังเห็นที่ป้ายโล่/HUD เดิม ภาพนี้ไม่ใช่ตัวบอกค่า · OS ลดการเคลื่อนไหว: ภาพนิ่ง settle จางๆ ทันที

สองสกิลนี้เลิกใช้รูปทรงชั่วคราวเก่า (โล่ห้าเหลี่ยม/เส้นฟัน/วงขยาย) ออกเฉพาะสกิลนี้ สกิลอื่นยังใช้ของเดิม

## สิ่งที่ยังไม่ได้ทำ / อยากให้เจ้าของตัดสิน

1. ภาพ Execute ค่อนข้างบางบนศัตรูสีม่วงเข้ม (ขยายขนาดขึ้นแล้วเทียบ Codex ที่แนะนำและเติมเงาบางรอง) — พอไหม หรืออยากให้เข้มขึ้น
2. **Ward ขอบเรืองค้าง (`quiet_rim`)** ตามที่ Codex แนะนำ ต้องวาดตามโล่ที่ยังเหลือตลอดหลายเทิร์น (ต้องมี state ต่อฮีโร่ในสนาม) ยังไม่ทำ — ตอนนี้โล่มีแค่ม่านชั่วคราวแล้วสลาย ต้องการให้ทำไหม
3. ถ้าผ่าน จะขยายภาษานี้ไปสกิลอื่นตามคิว (Heal, Mark, Guard ฯลฯ)
