## ผูกกับ event จริง (ไม่แก้ rules)

ทุกเลเยอร์มาจาก event ที่ resolver ปล่อยจริงของเทิร์นฮีโร่เอง (`songPlan` ฟังก์ชันบริสุทธิ์ ทดสอบใน node) ส่วนที่ภาพของ Codex บรรยายต่างจากกติกาจริง ผูกตามกติกาจริง:

| ท่า | สิ่งที่วาด | หมายเหตุเทียบกับกติกาจริง |
| --- | --- | --- |
| `valor` | วงแหวนที่เท้าลิโอ แล้วประกายลอยไปเท้าพันธมิตรที่ยืนอยู่ | บัฟระดับทีมไม่มี event ต่อคน จึงใช้พันธมิตรที่ hp>0 หลังเทิร์น; ไม่มีแฟลชโจมตี |
| `note` | ใบมีดโน้ตเดียวจากมือไปเอวเป้าจริง + สัมผัสเล็กหนึ่งครั้งต่อ event ดาเมจจริง | twin note มีสัมผัสเพิ่มเฉพาะเป้าที่โดนจริง; หลบ = ไม่มีสัมผัส เลเยอร์จาง |
| `finale` (เพลงกล้า) | คลื่นเดียวจากมือไปทางศัตรูที่โดน + สัมผัสหนึ่งครั้งต่อศัตรูที่โดนจริง | |
| `finale` (เพลงฟื้นฟู/สะท้าน) | รวมพลัง (prepare) เท่านั้น | ไม่ได้ตีศัตรู จึงไม่วาดคลื่น/สัมผัส; heal/barrier เดิมแสดงตามเดิม |
| `dread` | คลื่นจากมือไปทางศัตรู + รอยสั่นข้างเอวศัตรูที่ยังยืน | **กติกาจริงเป็นเพลงที่ลดทุกท่าศัตรู ไม่มีดาเมจ/เป้าเดียว** จึงไม่มีสัมผัสโจมตี |
| `solo` | สระแสงที่เท้า + เสาแสงแคบที่พันธมิตรที่ได้รับบัฟจริง | กติกาจริงให้พันธมิตรหนึ่งคน (ไม่ใช่ลิโอเอง) |
| `evade` | ควัน/ประกายต่ำที่เท้าเซฟา | |
| `decoy` | เงาหนึ่งตัวข้างพันธมิตรที่ถูกคุ้มกันจริง | ไม่ซ้ำทั้งสองข้าง ไม่ทับป้าย |

ท่าที่ถูกยกเลิก/ไม่มี event จะไม่วาดอะไร เลเยอร์ที่วาดแล้วกันวงกลม generic ซ้ำบน event นั้น คำบรรยาย/HP/ตัวเลขดาเมจจากเดิมไม่ถูกบัง

## การวาง

- เลเยอร์บนตัว (มือ/เอว) อยู่หน้าตัว; **เลเยอร์พื้น (วงแหวน/สระ/ควัน/เงา) อยู่ใน body ของยูนิต เหนือเงาพื้นและใต้สไปรต์** เพราะชั้นหลังสุดของฉากถูกพื้นฉากทับมิดทั้งหมด (พบตอนตรวจคลิป)
- วงแหวนของ valor และควันของ evade มีสำเนาจางด้านหน้าเป็น “ขอบบาง” และขยายกว้างกว่าที่ Codex แนะนำ (valor ×1.9, solo ×1.6, evade ×1.7) เพราะที่ขนาดแนะนำถูกตัวบังจนมองไม่เห็น — **จุดให้เจ้าของดู**: evade/solo ยังบางมากเมื่อเทียบฉาก
- Reduced motion/OS reduce: ไม่เดินทาง ไม่มี settle แสดงภาพนิ่งที่ปลายทางแล้วจาง; fast ใช้เวลาเดิมตาม stageTiming
