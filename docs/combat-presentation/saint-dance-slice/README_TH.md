## การเลือก R1/R2 (สมมติฐานที่ต้องยืนยัน)

เจ้าของยังไม่เลือก และ NOTES ของ Codex **ไม่แนะนำ R1 หรือ R2** ตามแนวที่เจ้าของใช้ (“ใช้ตาม codex แนะนำ”) จึงเลือก **R1 ทั้งสองครอบครัว** เพราะอ่านง่ายกว่าที่ 390px: เส้นทองบางกับริบบิ้นชมพูที่ยังเห็นสีเมื่อซ้อนกัน (NOTES เตือนว่า additive อาจทำให้ขาว) และภาพ peak ของ R1 ถูกตัดขอบจากเซลล์ต้นฉบับน้อยกว่า R2 (R2 echofoot/closingstep ขอบเป็นเส้นตรงชัดเจนในกระดาน) R2 ยังอยู่ในโฟลเดอร์ สลับได้ที่ `REV` ใน atlas.py ถ้าเจ้าของเลือก R2

แพ็ก **30 เลเยอร์** เป็น atlas lossless เดียว `public/assets/fx/saint_dance_fx.webp` (792×3168 decoded ≈10 MiB, ดาวน์โหลด ≈1.73 MB; ขนาดไม่เกิน forge_strike/earth) พิกเซลไม่ถูกแก้ ไม่ตัดขอบ (sourceSize 256 จึงใช้ pivot จาก `layers.json` ตรงๆ) เลเยอร์ที่ **ไม่ใช้** เพราะ resolver ไม่มี event รองรับ: `communion_peak` (วาดสองพันธมิตร), `sharewound_peak/settle` (สองกิ่งจากผู้ร่าย), `lastlight_settle` (พัดสามกิ่งตายตัว), `saintarc_settle`, `rounddance_peak` (ขอบซ้าย/ขวาถูกตัดจากเซลล์ต้นฉบับ เห็นเป็นกรอบสี่เหลี่ยมในคลิปทดลอง จึงใช้วงแหวน settle ที่สะอาดแทน)

## ผูกกับ event จริง (ไม่แก้ rules)

`sdPlan(turn)` ใน `src/game/visuals/saint-dance-fx.ts` เป็นฟังก์ชันบริสุทธิ์ (ไม่ import Phaser ตอนรัน) วางแผนจาก event ของเทิร์นฮีโร่เองเท่านั้น ไม่มีการสร้าง heal/hit/barrier/โจมตีเพิ่ม ท่าที่ถูกยกเลิก (`cancel`) หรือไม่มี event ที่ต้องใช้ → ไม่วาดอะไร

## การวาง/การทำงาน

- ใช้จุดยึด `songAnchor` (มือ/เอว/เท้าตามสไปรต์ที่แสดงจริง) วงแหวนพื้น (rounddance, deepbeat) อยู่หลังตัวใน body ของยูนิตพร้อมขอบหน้าบาง `.55`; ริบบิ้น/ดอกไม้/เส้นด้าย/สัมผัสอยู่หน้าตัวแต่ยึดที่เอวหรือเท้า ไม่ขึ้นไปบังหน้าและป้าย HP (ตรวจในเฟรมจริง)
- **แก้บั๊กร่วม:** `songAnchor` เลือก “Image แรกใน body” เป็นสไปรต์ ซึ่งหลังมีเลเยอร์พื้นแทรกอยู่ จะอ่านพิกัดจากเลเยอร์นั้นแทน (พบตอนวงแหวน rounddance ไปโผล่ผิดที่) ตอนนี้ข้ามภาพที่ติดธง `songLocal` (กระทบเฉพาะการหาจุดยึดของ song/shadow ซึ่งเทสต์เดิมยังผ่าน)
- ใช้เส้นทาง tint แบบ multiply (ไม่ใช่แฟลชขาว FILL) และเอาวงกลม/รอยฟัน generic ออกจาก event ที่ภาพครอบคลุม; ถ้า atlas โหลดไม่ได้ (`textures.exists`) ใช้ fallback เดิม
- normal/fast ใช้เวลาเดิมตาม `stageTiming` (ไม่แตะ `battle-playback.ts`); `ctx.quiet` ลดขนาด 10% และความทึบ; OS reduced motion/reduced effects: ไม่เดินทาง ไม่มี prepare/pop มีภาพนิ่งที่ปลายทาง (รวมเส้นด้ายสั้นที่อธิบาย heal จริง) แล้วจาง
