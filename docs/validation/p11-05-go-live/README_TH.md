# P11-05 เปิดบอสโลกสามตัวแทนผู้คุม (OD-52)

18 พฤศจิกายน 2026 · PR #301

## สิ่งที่เปลี่ยน

- `WorldBossTrioRules.from = 2969` = จันทร์ 23 พ.ย. 2026 06:00 กรุงเทพ ซึ่งเป็นรีเซ็ตสัปดาห์แรกหลังปล่อย (`serverDay` เลื่อน +1 ชม. จาก UTC และ `weekOf` เริ่มวันจันทร์) สัปดาห์ 2968 ยังเป็นของผู้คุม และรับรางวัล `s-50`/`s-100` ของผู้คุมย้อนหลังได้หนึ่งสัปดาห์ตามเดิม
- ตัวเลขร่างไม่เปลี่ยน (400 HP/ครั้ง ขั้นต่ำ 1500, Call the Court, รางวัล/เศษ/ของ) เซฟยังเป็น v65 และ encounter version เดิม แต่ content version เปลี่ยนเพราะ `rules.ts` เปลี่ยน ทั้ง `cloudflare-dev.yml` และ `pages.yml` deploy เองเมื่อ push เข้าสาขาเกม จึงขึ้น server กับเกมพร้อมกัน เครื่องที่ยังเปิดรุ่นเก่าจะได้ 409 content_version และต้องโหลดใหม่ ซึ่งเป็นพฤติกรรมเดิม
- Server ไม่ต้องแก้โค้ด สัปดาห์ 2969 เปิดสามแถบ HP แต่ละแถบ = ครั้งที่เล่นผู้คุมในสัปดาห์ 2968 ÷ 3 × 400 (ขั้นต่ำ 1500) ส่วนแถบผู้คุมของสัปดาห์ 2968 ยังอ่านได้เพื่อรับรางวัลย้อนหลัง มีเทสต์ใหม่ใน `tests/world-boss-trio-server.test.ts` ที่ใช้กฎจริง
- `cloudflare-load.yml` เพิ่ม input `trio` ถ้าใส่ `now` จะเลื่อน `from` เป็นสัปดาห์ปัจจุบันในสำเนา staging เท่านั้น โดยคำนวณ content version หลังแก้ ส่วนกฎที่จัดส่งไม่ถูกแตะ

## ผลจำลองด้วยกฎจริง

ใช้ `npm run sim` (8 ไฟล์, 29 ผ่าน) และ probe `tests/probe/p1105-world-boss-trio.test.ts` ผลตรงกับ [หลักฐาน coach](../p11-05-morvane-coach/README_TH.md): ที่ 400 HP/ครั้ง เมื่อครึ่งกลุ่มใช้ coach กลุ่ม 10 คน Morvane ถึง 50% ใน 86–94% ของสัปดาห์และล้มใน 47–50% กลุ่ม 20 คนถึง 50% ใน 98% และล้มใน 47–48% กลุ่ม 200 คนถึง 50% ทุกสัปดาห์และล้มใน 56–57% ส่วน Kragmor และ Valdrakk ถึง 50% ใน 97–100% ของสัปดาห์ เป้าร่างคือถึง 50% เกือบทุกสัปดาห์และล้มราวหนึ่งในสาม ซึ่งผ่าน จึงไม่ปรับ HP และ Call the Court
