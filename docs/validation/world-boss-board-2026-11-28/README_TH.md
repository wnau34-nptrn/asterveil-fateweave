# บอสโลกเปิดหลังแผนที่ 3 + อันดับดาเมจ (Leaderboard) — 2026-11-28

เจ้าของ: “บอสโลกเปิดหลัง Map 3 และเพิ่ม Leader board”

## สิ่งที่ทำ

- **ปลดล็อก:** บอสโลกมี feature ของตัวเอง `worldBoss` (`unlocks.worldBoss: 3` ใน `content/world/rules.ts`) แทนที่จะเปิดพร้อมกระดานภารกิจหลังแผนที่ 1 · ตรวจทั้งฝั่งกติกา (`wbAttemptReason`/`wbClaimReason` → `locked`, เซิร์ฟเวอร์ใช้กติกาเดียวกัน) และหน้าค่าย (แบนเนอร์ไม่ขึ้นก่อนผ่านแผนที่ 3) · บทสอน `open:wboss` ย้ายไปหลังแผนที่ 3 · บริษัท veteran เปิดอยู่แล้ว
- **อันดับ:** แท็บใหม่ “อันดับ” ในหน้าบอสโลก
  - จัดอันดับค่ายตามดาเมจรวมของทุกครั้งที่ลงในสัปดาห์ (ดาเมจที่ทำจริง ไม่ใช่เฉพาะที่หลอดเหลือ) เท่ากันให้ค่ายที่ลงก่อนอยู่สูงกว่า
  - เลือกสัปดาห์นี้/สัปดาห์ก่อน และรวมทุกบอส/รายบอส (เฉพาะสัปดาห์บอสสามตัว)
  - แสดง 20 อันดับแรก แถวของผู้เล่นมีกรอบทองและ “(คุณ)” ถ้าอยู่นอก 20 อันดับ จะแสดง “อันดับของคุณ X / ผู้เล่นทั้งหมด” ไว้เหนือรายการ
  - ชื่อเป็นรหัสค่ายนิรนาม `ค่าย-XXXXX` แบบเดียวกับแชท (ไม่ส่งรหัสบัญชีออกไป)
  - ออฟไลน์: แท็บบอกว่าต้องเชื่อมต่อเซิร์ฟเวอร์
  - **ทีมที่ใช้** (เจ้าของ “เพิ่มให้ leader board เห็นรายละเอียดของทีมที่ใช้ เลเวลทีม”): ทุกแถวแสดงเลเวลค่าย (`Lv`) และฮีโร่ที่ลงสนามพร้อมดาว ของครั้งที่ดาเมจสูงสุดในขอบเขตที่เลือก · บันทึกตอนลงบอส (`team` ใน hit: บัญชี → `wb_hits.team` → Durable Object บอส `hits.team`, ตรวจรูปแบบด้วย `isTeam`) · ครั้งที่ลงก่อนอัปเดตนี้ไม่มีข้อมูลทีม แถวจะบอก “ไม่มีข้อมูลทีม”
- **เซิร์ฟเวอร์:** `GET /v1/worldboss/board?boss=all|warden|kragmor|valdrakk|morvane&last=1` (ต้องล็อกอิน) → Durable Object บอสโลก `GET /board` อ่านจากตาราง `hits` ที่มีอยู่แล้ว · เพิ่มคอลัมน์ `team` (ALTER ตอน object เริ่ม ทั้ง `hits` ของบอสและ `wb_hits` ของบัญชี) ไม่แตะเซฟ
- ไม่มีรางวัลตามอันดับ (เจ้าของยังไม่ได้ขอ)
