| เรื่อง | ก่อน | หลัง |

| แต้มผัง | (Lv ค่าย − 1) + (★ − 1) ต่อคน | **Lv ค่าย 2–10 = 9 แต้ม + ผ่านแมพครั้งแรก (ปกติ) แมพละ 1** เท่ากันทุกคน |

## ย้ายเซฟ v59 → v60

- ตัวที่ใช้แต้มเกินสิทธิ์ใหม่ (เช่น ★5 Lv10 ที่ใช้ 13) → **คืนผังทั้งต้นฟรี** ล้างชุดสกิลที่ถือกลับเป็นค่าเริ่ม และขึ้นข้อความในหน้าผังของคนนั้นจนกว่าจะลงแต้มใหม่ (`profile.treeReset`)
- ตัวที่ไม่เกินสิทธิ์ **คงบิลด์เดิมทุกโหนด**
- เที่ยวที่ค้างอยู่: เล่นต่อด้วยผังเดิมจนกลับค่าย แล้วใช้กฎเดียวกันตอนสรุปเที่ยว (ไม่ตัดเที่ยว ไม่เริ่มศึกใหม่)
- เกมที่เก็บบนเซิร์ฟเวอร์แปลงแบบเดียวกันตอนอ่าน (`upgradeStoredGame` ทำซ้ำได้ ไม่เปลี่ยนเกมที่เป็นปัจจุบันแล้ว)
- เซฟ v60 ที่ใช้แต้มเกินถูกปฏิเสธตามปกติ

- ตัวอย่างบิลด์ในตัวจำลองผังใช้ 11 แต้มเท่าเดิม (Lv10 + ผ่าน 2 แมพ แทน ★3 Lv10) ผลชุดผัง/อาชีพ/ตัวละคร/ตั้งแถวผ่านตามเดิม
