# Campaign simulation (A10)

C12 selective deployed-duplicate policy, paired against the same policy on base 5a613a5. Generated by `npm run sim` (tests/campaign-sim.test.ts, tests/sim/balance-sim.ts). A new company (the Knight alone, story recruits) plays ซากชายแดน → เส้นทางป่าทึบ → แนวรอยแยก, replays แนวรอยแยก three times and plays it twice on hard. Between expeditions it hires, upgrades, follows the first example tree build of each class (tests/sim/tree-sim.ts) with its skills equipped, raises equipped skills with tomes (main skill first, trading up when a bigger tome is needed, keeping 20 gold) before the market, and equips the best gear. Class lanes are the formation. Rows `<battle>:attack` replay the same elite or boss fight with blind basic attacks, `boss:under2` with the party two levels lower (advisor); neither changes the run.
