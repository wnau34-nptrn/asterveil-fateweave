## 2. สิ่งที่เปลี่ยน (ร่าง)

| สกิล | ก่อน | หลัง |
|---|---|---|
| cadence คืนจังหวะ (Cerise) | power 0, ลดคูลดาวน์สกิลเพื่อนที่รอนานสุด 1 รอบ, ต้องมีสกิลรอ | **โล่ 8** (สเกลด้วย Support, ไม่ซ้อน ใช้ค่าที่มากกว่า) + ลดคูลดาวน์เดิม; ใช้ได้กับเพื่อนที่ยืนอยู่คนอื่นเสมอ; เลเวลสกิลเพิ่มพลัง 8%/ขั้น แทนโล่ให้ตัวเอง |
| duet รำประสาน (Cerise) | power 0, สองสกิลเพื่อน −1 รอบ, ต้องมีสกิลรอ | **ดาเมจเพื่อน +20% ถึงจบรอบถัดไป** (ช่องเดียวกับยาคลั่ง ใช้ค่าที่มากกว่า ไม่มีโทษรับดาเมจเพิ่ม) + ลดคูลดาวน์เดิม; ใช้ได้เสมอ; เลเวลสกิล +2 แต้ม%/ขั้น |
| turncycle หมุนวงดาว (Astrid) | power 0 | **พลังงาน 8** ใส่เป้าก่อนหมุนวง (สเกลด้วย Magic Power) |

คงไว้: คูลดาวน์ทุกสกิล, โหนดต้นไม้/กิ่ง p ทุกอัน, รูปแบบคำสั่ง (cadence/duet ที่มี lalin2 แต่ไม่มีสกิลรอ = ไม่ต้องเลือกสกิล), ภาพ VFX วาดของนักเต้นยังขึ้นเฉพาะคนที่คืนคูลดาวน์จริง ส่วนโล่/บัฟใช้การแสดงผลโล่/บัฟทั่วไป (ตามเหตุการณ์จริง)
