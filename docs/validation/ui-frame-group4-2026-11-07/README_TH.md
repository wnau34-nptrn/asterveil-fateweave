# UI frame กลุ่ม 4 — หน้าสรุปเดินทาง + รางวัลการต่อสู้ (2026-11-07)

กลุ่มสุดท้ายของงานกรอบ UI เฉพาะ CSS ต่อท้าย `src/ui/sheet-frame.css` ไม่เปลี่ยนเนื้อหา/ลำดับ/ขนาดตัวอักษร/กฎ/เซฟ
- สรุปเดินทาง: หัวชิดซ้าย + เส้นคั่นใต้หัว (สี `--hud-edge`), ปุ่ม "กลับค่าย" = แผ่นทองเดียวกับแผ่นบริการ (ยังสูง 52px)
- รางวัลการต่อสู้: เส้นคั่นใต้หัว ขอบหน้าต่าง `--hud-edge` ปุ่ม "ไปต่อ" = แผ่นทอง/มุม/ความสูงจาก token
- คงไว้: วงเลเวล/แถบ EXP/ภาพไอเทม/ชิปไอคอน, ปุ่มกลับค่ายติดล่าง

ผลวัด (`ui-language-audit`, Chromium headless ไม่ใช่เครื่องจริง): ชุดขนาดตัวอักษรและจำนวนข้อความ <12px เท่าเดิมทั้ง 3 ขนาด; ไม่มีเลื่อนแนวนอน; ตำแหน่งเนื้อหาลง ~4–9px ตามเส้นคั่น/ช่องไฟหัว
