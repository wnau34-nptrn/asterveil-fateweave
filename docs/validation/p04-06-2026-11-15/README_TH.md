# P04-06 — งบฟาร์มและเควสต์ต่อสัปดาห์

15 พฤศจิกายน 2026 · Opus · ตาม [แผน §P04-06](../../DEVELOPMENT_PLAN_TH.md), [แชต/ตลาด/กระดาน §4/§6](../../design/CHAT_MARKET_QUEST_BOARD_TH.md), OD-06/07/17 · เจ้าของยังไม่ได้ตอบสมมติฐานกวาดล้าง (PR #254) และกระดาน (PR #255) จึงคงกติกาเดิมทั้งหมด (โควตารวมปกติ/ยาก, ไม่มี EXP/ของ, สัญญาตรวจเอง, ช่วงค้าง/ช่วงรับ) และปรับเฉพาะตัวเลขรางวัล/เสบียงด้วย simulation

## วิธีวัด

`tests/sim/week-sim.ts` รับค่ายที่จบแคมเปญจาก `simulateCampaign` (แมพ 1→3, ซ้ำปกติ 2, ยาก 1) แล้วเล่นเป็นสัปดาห์บนกฎจริง: วันที่มีครั้งเล่น = แวะค่าย (ใช้จ่ายแบบ sim เดิม) + เดินทางแมพ 3 หนึ่งเที่ยว (OD-06) ประทับวันให้กระดานนับ, กวาดล้างจนเสบียง/โควตาหมด (แมพรางวัลสูงก่อน) และกดรับทุกงานที่รับได้ · วันล็อกอินอย่างเดียว = กวาดล้าง + รับ · ค่ายละ 3 สัปดาห์ เฉลี่ยสัปดาห์ 2–3 · 4 ค่าย × rush/explorer, casual
คำสั่ง: `BUDGET_OUT=<ไฟล์> BUDGET_N=4 npx vitest run tests/probe/p0406-budget.test.ts` (ราว 3 นาที) · ตารางเต็ม: [ก่อน](budget-before.md) · [หลัง](budget-after.md)

“ของตก” = มูลค่าย่อยของอุปกรณ์ที่นำกลับ (ศักยภาพ ไม่ได้ย่อยทั้งหมด) · “ใช้ในค่าย” = ที่ห้องรับรองจ่ายสุทธิ (สกิล ตลาด จ้าง ดาว ตีบวก ยา หักที่ได้คืนจากย่อย)

## ผล: ตัวเลขร่างเดิมใหญ่เกิน

| ผู้เล่น (ต่อสัปดาห์) | แบบ | เล่นจริง+ของตก แร่ | กวาดล้าง แร่ | กระดาน แร่ | กวาด+กระดาน % แร่ (ก่อน → หลัง) |
|---|---|---|---|---|---|
| 3 ครั้ง | rush | 596 | 702 → 320 | 570 → 340 | 68% → **53%** |
| 4 ครั้ง | rush | 799 | 936 → 360 | 610 → 370 | 66% → **48%** |
| 5 ครั้ง | rush | 1009 | 1125 → 360 | 610 → 370 | 63% → **42%** |
| 3 ครั้ง | explorer | 1793 | 702 → 320 | 755 → 451 | 45% → **30%** |
| 4 ครั้ง | explorer | 2379 | 936 → 360 | 755 → 451 | 42% → **25%** |
| 5 ครั้ง | explorer | 2959 | 1125 → 360 | 755 → 451 | 39% → **22%** |
| 5 ครั้ง + ล็อกอินอีก 2 วัน | explorer | 2959 | 1323 → 420 | 755 → 451 | 41% → **23%** |
| ล็อกอินทุกวัน ไม่เล่นเลย | – | 0 | 1323 → 420 | 200 → 110 | แร่รวม 1523 → **530** |

- ก่อนปรับ คนที่แค่เปิดเกมกวาดล้างทุกวันได้แร่ 1523/สัปดาห์ > การเล่นจริง 3 ครั้งแบบ rush (596) — ขัด “กวาด+กระดานเป็นส่วนเล็กข้างการเล่นจริง” และกลายเป็นแรงจูงใจให้เข้าเกมทุกวัน
- หลังปรับ ผู้เล่นเป้าหมาย (เที่ยวเต็ม 20–30 นาที 3–5 ครั้ง) ได้จากกวาด+กระดาน 22–30% ของแร่ · rush สูงกว่า (42–53%) เพราะเที่ยว rush สั้น (~53 ก้าว) ได้น้อยต่อเที่ยว และในเวลา 20–30 นาทีเล่นได้มากกว่าหนึ่งเที่ยว
- ไม่บังคับเข้าทุกวัน: เล่น 3 ครั้งได้กวาดล้าง 14 ครั้งเท่าคนเข้าทุกวัน (เสบียงเก็บได้ 3 วัน); คนเข้าทุกวันได้มากกว่าคนเล่น 5 ครั้งแค่ +60 แร่ (+2%)
- ทองเป็นตัวจำกัด: sim ใช้ทองที่ได้เกือบหมดทุกแบบ (ตลาด/จ้าง/สกิล) · ฝุ่นเหลือ (ของตกให้ฝุ่นมาก) จึงลดฝุ่นในกวาด/กระดาน
- ความคืบหน้า 3 สัปดาห์ (ผลรวมทีม 5): rush 3 ครั้ง ★ 21.0 (ไม่ใช้กวาด/กระดาน) → 21.5, ตีบวก 105 → 171 · explorer ★ เต็ม 25 อยู่แล้ว ตีบวก 267 → 288 · เลเวลสกิลเท่าเดิม (ตำราไม่ใช่คอขวด) — กวาด/กระดานช่วยแต่ไม่แทนการเล่น

## ข้อเปิดให้เจ้าของ

1. เป้า “กวาด+กระดาน ≈ 20–30% ของแร่” สำหรับผู้เล่นเที่ยวเต็ม — ถ้าอยากให้กวาดล้างคุ้มกว่านี้ เพิ่มเสบียงต่อวันก่อนเพิ่มรางวัลต่อครั้ง
2. คนล็อกอินอย่างเดียวยังได้แร่ 530/สัปดาห์ (≈ 90% ของ rush 3 ครั้ง แต่ไม่มี EXP/ของ/ดาว) — ทางเลือก: นับกวาดล้างเฉพาะวันที่มีการเดินทาง หรือตัดทาง “กวาดล้าง” ของงานลาดตระเวน
3. รางวัลกระดานรวมกับ World Boss (P11) และเศษกลางรายสัปดาห์ (หลัง ledger P09) ต้องอยู่ในงบเดียวกันนี้ โดยไม่เพิ่มงบรวม (OD-17)
