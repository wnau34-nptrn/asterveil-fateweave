# แถบ HP และข้อมูลยูนิตด้านบน

## แบบล่าสุด: แถบตรง ตัวเลข HP และบัฟ/ดีบัฟบนป้าย

เจ้าของอนุมัตินำ mockup เส้นตรงมาใช้จริงหลังปรับภาพ: ทั้งสองฝั่งแสดง HP ปัจจุบัน/สูงสุดซ้อนกลางเส้นตรงใต้เท้า เส้นยังหนา 4px ตัวเลขสีขาวมีเงาขอบเข้ม ไม่มีแผ่นป้ายรอง และยึดกลาง track เต็มเสมอ ไม่เลื่อนตามปริมาณเลือดที่เหลือ

- คงสีเขียว >40%, ส้ม >25–40%, แดง ≤25%; ตัวเลขเล็กลงเฉพาะจำนวนหลักมาก ไม่ขยายความสูงของเส้นเพื่อใส่ข้อความ
- คงไอคอนสถานะในสนามและการ์ด HP ฝ่ายเราด้านล่างเดิม ขยายเฉพาะพื้นที่แผง HP แนวนอนขั้นต่ำ 64→72px และ clamp ในสนาม เพื่อให้ตัวเลขยังพอดีข้างไอคอนบนจอ 320px ไม่ขยับตัวละครหรือจังหวะต่อสู้
- ป้ายบนแสดงไอคอนสถานะจริงจาก `unitStatuses(displayState)` ของยูนิตที่กำลังดู: บัฟเขียว/ดีบัฟแดง แสดงอย่างละประเภทเมื่อมีทั้งคู่ สูงสุด 2 ไอคอนและ +จำนวนที่เหลือ ไม่ใช้ไอคอนตัวอย่างจาก mockup เป็นข้อมูลจริง
- แตะป้าย/ไอคอนเพื่อเปิดรายละเอียดเดิม รายการครบและชื่อ/ระยะเวลามี accessible label/title; ป้ายยังสูง 44px และมีพื้นที่ให้ชื่อกับ HP ไม่ทับไอคอน
- คงการติดตามเจ้าของเทิร์น → ศัตรูที่แตะ → เจ้าของเทิร์นถัดไป และการเลือกดูเองตาม #217; HP/ไอคอนอ่านจาก snapshot ที่แสดง ไม่เปิดเผยผลลัพธ์ล่วงหน้าก่อน contact
- Local: typecheck/lint/build, full unit 123 files/1662 tests ผ่าน (6 skipped), focused HP/layout/status unit 12 เคสผ่าน; HUD/status/keyboard/5v5 browser 16 เคสผ่าน รวม buff+debuff+overflow และตัวเลข 9999/9999 ที่ 320/390px, read-only inspection, staged expiration, normal/reduced motion และ 5v5/keyboard regression
- ภาพจริง 390px ตรวจในเซสชัน (fixture แยกสำหรับค่าขนาดใหญ่/หลายสถานะ ไม่ใช่ปรับสมดุลเกม); Browser tool ไม่พร้อม จึงใช้ Playwright/system Chromium ไม่ใช่เครื่องจริง
- ไม่เปลี่ยน resolver, save schema, runtime encounters, balance, assets หรือ playback timing; [PR #218](https://github.com/wnau34-nptrn/asterveil-fateweave/pull/218) ผ่าน required quality/browser ก่อน merge `2ac1105`

## ประวัติ: ปรับตามเจ้าของเทิร์นและเพิ่มความหนา (2026-11-10)

- ก่อนลงมือ แถบบนแสดงเจ้าของเทิร์นเป็นค่าเริ่มต้น เมื่อกดโจมตีศัตรูจะแสดงชื่อ/HP ของศัตรูที่แตะ และตามค่า HP ที่เห็นจริงระหว่าง contact จากนั้นกลับไปแสดงเจ้าของเทิร์นคนถัดไป
- การกดรูปในคิวหรือเลือกยูนิตในแท็บสถานะยังทำได้เอง การเลือกเองคงอยู่ตลอดเทิร์นปัจจุบัน ไม่ถูก contact/resize รีเซ็ต แต่เริ่มตามอัตโนมัติใหม่เมื่อเปลี่ยนเทิร์น รวมทั้ง Skip/จบ playback
- แยกยูนิตที่อ่านในหน้ารายละเอียดสถานะออกจากแถบบน จึงไม่แย่งการเลือกใน dialog ระหว่างที่กำลังอ่านหลายเทิร์น
- ท่าหมู่คงเป้าหมายคำสั่ง `enemies` ตามเดิม แต่แถบบนแสดงยูนิตจริงที่แตะ; ไม่เปลี่ยนคำสั่งเป็นการโจมตีเดี่ยว
- เพิ่ม stroke จาก 2.5px เป็น **4px** ทั้ง track/fill ของเส้นหน้าเท้าทั้งสองฝั่ง รูปร่างเปิดและสี 40%/25% เดิม การ์ด HP ล่างคงเดิม
- ตรวจจริง: เจ้าของเทิร์น → ศัตรูที่ตี → ศัตรูที่ได้เทิร์น → ฮีโร่ถัดไป; เลือกดูเองระหว่างทุกช่วง, ไม่มีคำสั่งเพิ่ม, HP เปลี่ยนเฉพาะ contact, Skip และท่าหมู่ ทั้ง normal/reduced motion
- Local: typecheck/lint/build; full unit 123 files/1662 tests ผ่าน (6 skipped); browser HUD/status/keyboard/5v5 14 เคสผ่าน และเฉพาะ interaction ล่าสุด 3 เคสผ่านซ้ำ ภาพ 390px ตรวจในเซสชัน; Browser tool ไม่พร้อมจึงใช้ Playwright/system Chromium
- [PR #217](https://github.com/wnau34-nptrn/asterveil-fateweave/pull/217) ผ่าน required quality + browser CI ก่อน merge `6bcfa5c`

## แบบฐานจาก PR #216

นำแบบที่เจ้าของเลือกไปใช้จริงกับทั้งสองฝั่ง: เส้นโค้งตื้นเฉพาะหน้าเท้า ไม่มีครึ่งวงหลัง ไม่มีป้ายชื่อหรือตัวเลขลอยในสนาม แสดงชื่อ/HP ใน inspector ใต้คิวเทิร์น แตะรูปในคิวเพื่อเลือกดูข้อมูล และแตะแถบข้อมูลเพื่อเปิดสถานะเต็ม การเลือกดูไม่เปลี่ยนผู้ถือเทิร์นหรือสกิลที่เลือก ไม่สร้างคำสั่งและไม่เขียนเซฟ

- เขียว: HP > 40%; ส้ม: 25% < HP ≤ 40%; แดง: HP ≤ 25% ใช้เกณฑ์เดียวกันกับแถบ HP ในการ์ดฝ่ายเรา
- HUD ล่างยังเป็นการ์ดเดิม 5 ใบ มีชื่อ ตัวเลข HP แถบตรง และจุดสถานะความล้า ไม่เปลี่ยนเป็นแถวรูปอย่างเดียว
- บอสอยู่กลางแถวหน้าระหว่างลูกน้องบน/ล่าง พร้อมมงกุฎ ขยายได้ถึง 1.5× ตามพื้นที่จริง จอเตี้ยลดขนาดสนาม/จำกัดสเกลบอส โดยไม่ตัดข้อมูลการ์ดล่าง
- ระยะระหว่างแถวอิงส่วนที่วาดจริง + idle breathing และจองแถบ HP/status ไว้ต่างหาก จองช่องของตัวที่จะถูกเรียกใน phase ไว้ล่วงหน้า เลื่อนภาพบอสไปทางช่องหลังกลางได้เฉพาะเมื่อช่องนั้นว่าง; tactical IDs/กติกา/การเล็งเดิม
- บัฟ/ดีบัฟยังมีไอคอนและ +จำนวน ข้างแถบ HP รายละเอียดทั้งหมดอยู่แท็บสถานะ เส้นเป็น SVG เปิด มี stroke 4px (เพิ่มจาก 2.5px ตามคำขอภายหลัง) ไม่ใส่ตัวเลขในเส้น
- ค่า HP ใช้ `displayState` เดียวกับจังหวะ playback จึงไม่เปิดเผย HP สุดท้ายก่อน contact

ภาพฐานก่อนเพิ่ม stroke เป็น 4px ต่อไปนี้เป็นการจับภาพ **BattleUI/BattleScene จริง** ผ่าน fixture แยกที่ใช้ resolver/playback จริง เพื่อจัด 5v5 + บอสกลางหน้า ค่าใน fixture ใช้ทดสอบ UI เท่านั้น ไม่ใช่การปรับสมดุลหรือเซฟเจ้าของ และไม่ถูกรวมใน production entry:
