# ต่อสู้อัตโนมัติ (AUTO) — OD-62, 2026-11-26

เจ้าของเพิ่มภายหลังในวันเดียวกัน “ให้บอสโลก มี Auto ด้วย”: ปุ่ม AUTO มีในการต่อสู้สุ่ม**และบอสโลก**

## สิ่งที่ทำ

- `src/core/battle/auto.ts` (pure, ไม่มีสุ่มหรือนาฬิกา): ให้คะแนนทุกคำสั่งที่ถูกกติกาของฮีโร่เจ้าของเทิร์น ด้วย resolver ตัวเดียวกับผู้เล่น และดูเฉพาะผลของเทิร์นฮีโร่นั้น ได้แก่ ดาเมจ การล้มศัตรู ฮีลที่ไม่ล้น โล่ การชุบ และสถานะ แล้วเลือกคำสั่งคะแนนสูงสุด
- จุดที่ด้อยกว่าคนโดยตั้งใจ:
  - ไม่อ่านท่าที่ศัตรูประกาศ และไม่มองเทิร์นถัดไป จึงไม่ตั้งรับหรือใส่โล่รอท่าใหญ่ ไม่ขัดจังหวะ เลื่อน หรือเบี่ยงท่าโดยตั้งใจ (การขัด เลื่อน และเบี่ยงได้ 0 คะแนน)
  - ไม่วางคอมโบข้ามเทิร์น สถานะล้วนได้คะแนนน้อย และไม่ใช้ท่าเดิมซ้ำติดกัน
  - ราว 30% ของเทิร์นแค่โจมตีพื้นฐาน (`AUTO_LAPSE`) ผลมาจาก hash ของ encounter, beat และฮีโร่ จึงได้ผลเดิมทุกครั้งและ replay ไม่เปลี่ยน
  - ท่า Seer ที่ต้องเลือกเป้าที่สอง (`deflectfate`) ให้ผู้เล่นทำเอง
- คำสั่งผ่าน `resolveCommand` และ `session.commit` เดิม บันทึกทุกเทิร์น ใช้ replay และ server ตามเดิม ไม่เปลี่ยนเซฟ กติกา หรือ encounter
- `BattleUI`:
  - ปุ่ม AUTO 52×44px ข้าง ⓘ แสดงเฉพาะ `kind === 'random'` และ `'worldBoss'` ปุ่ม “ดูผลทันที” ย้ายไปทางซ้ายของ AUTO ระหว่างแสดงท่า
  - ออโต้รอก่อนสั่ง 0.5 วินาที (0.25 วินาทีเมื่อตั้งความเร็วเร็ว) และไม่ทำงานระหว่างแสดงท่า มี dialog เปิด แท็บซ่อน มองไม่เห็นวิว หรือขึ้นคำเตือนหมุนจอ
  - ยังต้องกดเริ่มการต่อสู้เอง
- ตั้งค่าที่ ⓘ → ตั้งค่า → ต่อสู้อัตโนมัติ เก็บในเครื่อง (`asterveil.fateweave.auto-battle.v1`, ไม่อยู่ในเซฟ):
  - HP ที่หยุด: ไม่หยุด/30/50/70% (ค่าเริ่มต้น 50%)
  - ปิดสกิลรายท่า (โจมตีพื้นฐานปิดไม่ได้)
  - ค่าเปิดหรือปิด AUTO จำไว้ข้ามการต่อสู้
- การหยุด: ฮีโร่ที่ยืนอยู่ตอนออโต้เริ่มล้ม หรือเลือดต่ำกว่าเกณฑ์ ข้อความจะขึ้นบนสนามแล้วคืนการควบคุมให้ผู้เล่น แตะ AUTO อีกครั้งเพื่อทำต่อ ฮีโร่ที่ต่ำกว่าเกณฑ์อยู่แล้วตอนเริ่มหรือตอนกดทำต่อจะหยุดออโต้ได้เฉพาะตอนล้ม
- sim: `Style 'auto'` ใน `tests/sim/balance-sim.ts` ให้ออโต้เล่นเฉพาะการต่อสู้สุ่ม ส่วนที่เหลือให้ advisor เล่น · `tests/auto-battle-sim.test.ts` อยู่ใน `npm run sim` และเขียน [SIM.md](SIM.md)

## ผลจำลอง (12 บริษัท แผนที่ 1→5 ไม่เล่นซ้ำ)

ดูตารางเต็มใน [SIM.md](SIM.md)

- **การต่อสู้สุ่ม:** ออโต้ชนะ 100% ทุกแผนที่ (advisor 98–100%) HP หลังชนะใกล้ advisor: แผนที่ 3 88 vs 89, แผนที่ 4 91 vs 99, แผนที่ 5 96 vs 98
- **เทียบโจมตีพื้นฐานอย่างเดียว:** ในรอบทดลองเดียวกัน HP หลังชนะ 71% และแผนที่ 3 ชนะ 89%
- **บอสโลก (8 รอบ ทีมหลังแผนที่ 5):** ดาเมจเฉลี่ยของออโต้เทียบกับคำแนะนำ: Warden 105%, Kragmor 99%, Valdrakk 114%, Morvane 81% (โจมตีพื้นฐานอย่างเดียว 43–83%) คำแนะนำในตารางเป็นตัวสอนเล่น ไม่ใช่ผู้เล่นเก่ง บอสโลกส่วนใหญ่เป็นการแข่งทำดาเมจ ออโต้ที่เลือกท่าจากผลจริงจึงตามทันตัวสอน ยกเว้น Morvane ที่ต้องตอบท่าที่ประกาศไว้
- **บอสแผนที่เมื่อให้ออโต้เล่นทุกเทิร์น:** แผนที่ 1–3 ชนะ 100%, แผนที่ 4 85%, แผนที่ 5 42% (advisor 100%) เกมไม่เปิด AUTO ในบอส ตัวเลขนี้แสดงว่าออโต้ด้อยตรงที่ต้องอ่านท่า

### ที่พบระหว่างทำ

- รุ่นแรกที่ไม่มี lapse เก่งเท่าหรือเก่งกว่า advisor (ตัวสอนในศึกแรก) ในการต่อสู้สุ่ม และชนะบอส 97% เพราะการเลือกท่าจากผลจริงของ resolver แม่นกว่ากฎสอนเล่น
- ลอง lapse 30% และ 50% (50%: HP แผนที่ 3 = 83, บอสแผนที่ 4 = 58%) แล้วเลือก 30% ตามผู้เล่น casual ของ sim เดิม (ทำตามคำแนะนำ 70%) ปรับได้ที่ค่าเดียว `AUTO_LAPSE`
- การต่อสู้สุ่มในเกมตอนนี้ง่าย ช่องว่าง HP ระหว่างออโต้กับ advisor จึงเล็ก ความด้อยของออโต้เห็นชัดในศึกที่ต้องอ่านท่า

## ยังเปิด

- บอสโลก: ออโต้ทำดาเมจได้ใกล้หรือเกินตัวสอนเล่น ถ้าอยากให้คนที่เล่นเองได้เปรียบชัดกว่านี้ ทางเลือกคือเพิ่ม lapse เฉพาะบอสโลก

- ตัวเลข `AUTO_LAPSE` และคะแนนเป็นค่าร่าง หากเจ้าของอยากให้ด้อยกว่านี้ ปรับค่า lapse แล้วรัน `npm run sim`
- ยังไม่มีการเปิด AUTO อัตโนมัติตอนเข้าศึก ผู้เล่นต้องกดเริ่มเองทุกครั้ง
