# P04-05/06 — จังหวะเลเวล ไฟแคมป์ ความล้า และการสลับสำรอง (OD-34)

14 พฤศจิกายน 2026 · สาขา `claude/p04-05-pacing` · ตัวเลขเป็นร่าง · ไม่แตะบอส เซฟ ดาว หรือแต้มผัง

## สรุป

1. **วัดก่อน** (`tests/probe/p0405-pacing.test.ts`, hook ใหม่ `hooks.battle/run` ใน `tests/sim/balance-sim.ts`): ค่าย casual rush เข้าแนวรอยแยกที่ **Lv ค่าย 4–5** (ทุ่ง Lv6–7, พงหนาม 7–9, แผลรอยแยก 9–10, บอส 11) จบที่ Lv8 ค่ายที่ไม่ผ่าน 8/48 เกือบทั้งหมดมีรูปเดียวกัน: ชนะมินิบอส (16,6) แล้ว **เดินกลับแคมป์ด้วยเลือด 30–60%** แพ้ศึกสุ่มกลางทาง (ทีมต่ำกว่ามอนสเตอร์ 2–3 Lv) จากนั้นเหลือสำรอง 2 คนไปตีบอสแล้วล้มหมด
2. **ไม่ใช่คอขวด:** ความล้า (ขั้นที่ 7 ลดโจมตี 10%; เลื่อนเป็น 9/12 ได้ +1 ค่าย), ฟื้นสำรอง 25→50% (ไม่เปลี่ยนเลย สำรองไม่ได้บาดเจ็บ), จุดไฟใหม่ 3→2 ศึก (−1) และ **สลับสำรองกลางแผนที่** (กติกาให้ทำได้อยู่แล้ว) ทำให้ rush แย่ลง 40→34–37/48 เพราะทีมเดินหน้าต่อแทนกลับไปพักที่แคมป์ จึงไม่เพิ่มลงในนโยบาย sim
3. **แก้ (ร่าง):**
   - **EXP ไล่ตาม** (`expPercent`): ต่ำกว่ามอนสเตอร์ 2 Lv ได้ 115% (เดิม 100), 3 Lv ขึ้นไป 130% (เดิม 110) — ค่าย rush ถึงบอสแนวรอยแยกที่ Lv ~9 (เดิม 8.2); explorer ที่เลเวลทันแมพไม่เปลี่ยน
   - **ไฟแคมป์ฟื้น 70%** (`camp.restHealPercent`, เดิม 50) ข้อความในเกมอ่านค่านี้อยู่แล้ว
4. **ผลแคมเปญเต็ม** (`npm run sim`, casual 48 / advisor 12 ค่าย): casual rush แนวรอยแยก #1 **83 → 96%**, advisor rush **92 → 100%**, casual explorer ป่าทึบ #1 **71 → 81%**, advisor explorer ป่าทึบ #1 92 → 100%, casual rush ป่าทึบ #1 92 → 94%; ยาก #1 casual rush 100 → 98% (1 ค่าย, ในเกณฑ์) campaign gate ผ่านโดยไม่ตั้งฐานใหม่

## ราคาที่จ่าย (OD-09)

ค่าย rush มาถึงใกล้เลเวลแมพขึ้น การกดโจมตี (เล่นศึกเดิมซ้ำ) จึงชนะบอสป่าทึบบ่อยขึ้น: advisor rush 0 → 25%, casual rush 12 → 34%, advisor explorer 42 → 58% (12 ศึก); บอสแนวรอยแยก casual rush 69 → 75% ส่วนอื่นเท่าเดิม ±2 เทสต์ "plain attacks lose bosses/forced elites of maps 2–3 more often than not" ยังผ่าน ไม่ได้แก้บอสตาม OD-34
