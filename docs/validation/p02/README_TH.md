### ความเหนื่อยล้าและการสลับตัวใน sim

- นโยบาย sim (`tests/sim/balance-sim.ts` `rotate`): ที่จุดรวมพล คนลงสนามที่ถึงขั้นเหนื่อยแล้วสลับกับสำรองแนวเดียวกันที่ยืน >50% เลือด ขั้นต่ำกว่า และแรงไม่น้อยกว่าหลังหักการลด (MaxHP×Attack); ก่อนบอสส่งคนแรงสุดของแต่ละแนว; ไม่ถอดผู้รักษาคนเดียว; ใช้ยาฟื้นความเหนื่อยเมื่อถึงขั้น 2; `SIM_NO_ROTATE=1` ปิดการสลับเพื่อเทียบ
- ค่าที่ทดลอง (12 seed × 4 นโยบาย): ขั้นที่ 4/6/8 −10% ต่อขั้น พัก −3 → แผนที่ 3/ยาก ตกหนัก (rush/advisor แผนที่ 3 ครั้งแรก 25%) เพราะความเหนื่อยสะสมเร็วกว่าการพัก; ปิดความเหนื่อยทั้งหมด → ง่ายกว่า P01 ทุกเซลล์; ค่าที่เลือก 7/11 พัก −5 อยู่ระหว่าง
- การสลับแบบง่าย (สลับเมื่อถึงขั้นโดยไม่ดูความแรง) **แย่กว่าไม่สลับ** เพราะ sim ลงทุน (ของ ตำรา ตัวซ้ำ) เฉพาะคนลงสนาม ตัวสำรองจึงอ่อนกว่า — ข้อสังเกตสำหรับ P04: ถ้าต้องการให้การหมุนเวียนคุ้ม ต้องทำให้การลงทุนสำรองไม่แพง (เลเวลค่ายร่วมช่วยแล้ว แต่ของ/ตำรายังเป็นรายคน)
