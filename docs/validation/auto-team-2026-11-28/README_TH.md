# ปุ่มจัดทีมอัตโนมัติ — 2026-11-28

เจ้าของ: “เพิ่มปุ่มจัดทีมอัตโนมัติ ที่หน้าจัดทีม กดปุ่มเดียวจัดทีมให้ทั้งตัวจริงและสำรอง”

## สิ่งที่ทำ

- ปุ่ม **จัดทีมอัตโนมัติ** บนสุดของหน้าจัดทีมในค่าย กดครั้งเดียวจัดตัวจริง 5 และสำรองเต็มช่อง (คำสั่งใหม่ `autoTeam`, กติกา `src/core/world/auto-team.ts` ใช้ร่วมกันทั้งเครื่องและเซิร์ฟเวอร์)
- เกณฑ์ (คำแนะนำจากค่าตัวเลขปัจจุบัน ไม่ใช่การจำลองการต่อสู้):
  - ความแข็ง = เลือด + โจมตี×4 + พลังเวท×2 + โบนัสดาเมจ + เกราะ + ต้านทาน + SPD/10 ของสมาชิก (รวมดาว เลเวลค่าย ผังสกิล อุปกรณ์ บาดแผล)
  - สนาม: ใส่คนรักษาที่แข็งที่สุด (Priest/Saint) และแทงก์ที่แข็งที่สุด (Knight/Warden) ก่อนถ้ามี แล้วเติมคนที่แข็งที่สุด แนวละไม่เกิน 3 ตามแนวของอาชีพ (ถ้ายังไม่ครบ 5 เพราะแนวเต็ม ให้คนแข็งที่เหลือลง แล้วแผนการยืนย้ายไปอีกแนวเอง)
  - สำรอง: คนแข็งรองลงมาจนเต็มช่อง
  - ไม่ดึงคนใน “คลังสมาชิก” · ทุกคนที่ถูกเลือกยืนแนวของอาชีพ (ล้างแนวที่ตั้งเอง) · สนามเรียงแนวหน้าก่อน
  - ผลเหมือนเดิมทุกครั้ง กดซ้ำถ้าทีมตรงอยู่แล้วจะไม่บันทึกและบอกว่า “ทีมตอนนี้ตรงกับที่จัดอัตโนมัติอยู่แล้ว”
- ผลแสดงใต้ปุ่ม (ข้อความค่ายปกติถูกหน้าต่างจัดทีมบัง)
- ไม่แตะเซฟหรือการต่อสู้ ชุดทีมที่บันทึกไว้ไม่เปลี่ยน
