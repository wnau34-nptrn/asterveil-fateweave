# CAMP-HUD-CHARACTER-QUEST-001 — 2026-11-07

เจ้าของอนุมัติให้นำ mockup หน้าค่ายไปใช้ และปรับข้อกำหนดสุดท้ายว่า HUD/ทางเข้ากระดานเควสต์ต้องโปร่ง แต่หน้ารายการเควสต์ใช้พื้นทึบได้ ต้องกระชับและกดเพื่ออ่านรายละเอียด

## ผลลัพธ์

- HUD ชื่อผู้บัญชาการ/เลเวลค่าย ทรัพยากร และปุ่มแผนฟาร์มอยู่ด้านบน พื้นรองบางเฉพาะจุด ไม่บังวิวเต็มแถบ
- ย้ายทางเข้ากระดานเควสต์จากไอคอนธงในแผงเดินทาง เป็นปุ่มชื่อเต็มด้านบน พร้อมจำนวนงาน/รางวัลตามสถานะจริง
- แถบล่างมี 6 ทางเข้าโดยตรง: ทีม / ตัวละคร / จ้าง / กระเป๋า / ช่าง / ยา ไม่มีเมนูบริการค่ายซ้อน
- ทีมเหลือชุดทีม ลงสนาม สำรอง แผนยืน และสมาชิกพักในค่าย ช่องลงสนาม/สำรองจัด 5 ช่องต่อแถว
- ตัวละครเปิดสมาชิกและแท็บล่าสุดโดยตรง ใช้ระบบเดิมครบ 5 แท็บ: ภาพรวม / อุปกรณ์ / สกิล / ผังสกิล / พัฒนา เลเวล/EXP ค่ายดูได้ในภาพรวม
- ทีมและตัวละครคงเมนูล่างให้สลับหน้าได้ ปิดหรือ Escape คืน focus; ทางเข้าจากอุปกรณ์/สมาชิกยังคืนหน้าต้นทาง
- กระดานเควสต์ด้านในเป็นพื้นทึบ แสดงชื่อ ความคืบหน้า และสถานะก่อน กด native details/summary เพื่ออ่านผู้มอบหมาย คำอธิบาย และรางวัล
- เควสต์พร้อมรับมีปุ่มรับรางวัลโดยตรง ใช้คำสั่งเดิม ตรวจคลังเต็มและป้องกันรับซ้ำตามเดิม
- ไม่เปลี่ยนกติกา progression, balance, save format, unlock pacing หรือข้อมูลเควสต์
