# UI frame กลุ่ม 1 — หัวหน้าต่าง + ปุ่มหลัก/รอง ของแผ่นบริการค่าย (2026-11-05)

ขอบเขตเจ้าของอนุมัติ 2026-11-05 (หัวข้อแรกของ [`ART-UI-LANGUAGE-001.md`](../../handoffs/ART-UI-LANGUAGE-001.md)) ทำโดย Claude ในเกมจริง เฉพาะกรอบ ไม่เปลี่ยนเนื้อหา/ลำดับ/กฎ/เซฟ/ตัวเลข ไม่แตะ HUD ต่อสู้/แผนที่ หน้าต่างตัวละคร การ์ดรางวัล ชิปสรุป ภาพไอเทม/review ช่าง

## สิ่งที่เปลี่ยน

- `src/ui/tokens.css`: token ใหม่ `--primary-plate*`, `--secondary-plate*`, `--button-*`, `--sheet-*` (ค่าเดิมของปุ่มเกม ย้ายมาเป็น token; หัวเรื่องและฟอนต์ปุ่มเป็น rem จึงขยายตามขนาดตัวอักษรของผู้เล่น)
- `src/ui/game-feel.css`: `.primary`/`.secondary` อ้าง token (หน้าตาเท่าเดิม)
- `src/ui/sheet-frame.css` (โหลดท้ายสุด): ทุกแผ่นบริการ (ทีม จ้าง/ตลาด กระเป๋า ฟาร์ม ปรุงยา ช่าง เลือกแผนที่ กระดานเควสต์) ใช้หัวเดียวกัน: ย้อนกลับซ้าย · หัวเรื่องชิดซ้าย 19px ทอง · ปิดขวา 44px วงกลม; ปุ่มหลักทอง 48px มุม 10 ฟอนต์ 16/600 แบบเดียว ปุ่มรอง 44px มุม 10 ฟอนต์ 14/600
- กรอบช่างยังเยื้อง 8px ตาม ART-UI-UX-002 (เทสต์ safe-area) — padding หัวชดเชยให้ปุ่มตรงตำแหน่งเดียวกับแผ่นอื่น
- `tests/browser/ui-language-audit.spec.ts`: ตัวเลือก `UI_AUDIT_SIZES`, `UI_AUDIT_CSS` (ใช้ทำภาพตัวอย่าง R2)
