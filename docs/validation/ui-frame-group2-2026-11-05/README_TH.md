# UI frame กลุ่ม 2 — หน้าต่างตัวละคร + แผ่นทีม (2026-11-05)

ขอบเขตตามหัวข้อแรกของ [`ART-UI-LANGUAGE-001.md`](../../handoffs/ART-UI-LANGUAGE-001.md) ทำโดย Claude ในเกมจริง Q1 = R1 (การตัดสินใจของ Claude ตามที่เจ้าของมอบสิทธิ์ 2026-11-05 ไม่ใช่คำเลือกของเจ้าของเอง) เฉพาะกรอบ ไม่เปลี่ยนเนื้อหา/กฎ/เซฟ/ตัวเลข ไม่แตะ HUD ต่อสู้/แผนที่ ไอคอนสกิลวาด ตารางจัดทีม แถบสลับตัวละคร การ์ดรางวัล ชิปสรุป ภาพไอเทม/review ช่าง

## สิ่งที่เปลี่ยน (`src/ui/sheet-frame.css` ต่อท้ายส่วนกลุ่ม 1)

- แผ่นทีมและหน้าต่างตัวละคร (ภาพรวม/อุปกรณ์/สกิล/พัฒนา/อัปดาว + review) เต็มจอบนจอแนวตั้ง แถบนำทางล่างซ่อน (`visibility:hidden`) รออยู่ข้างล่าง — Q1
- หัวหน้าต่างตัวละคร: หัวเรื่องชิดซ้าย 19px ทอง · ปิด 44px วงกลมที่ 333,11 (320px: 263,11) ตำแหน่งเดียวกับแผ่นบริการ; padding ใช้ `--star-safe-top/bottom` เดิม (เทสต์ safe-area ยังผ่าน)
- ปุ่ม `.primary`/`.secondary` ในหน้าต่างตัวละครใช้ token เดียวกับแผ่นบริการ
- ตัวอักษรในหน้าต่าง ≥ 12px (ช่องอุปกรณ์ Lv/+, Lv ของต้นไม้, ตัวเลขโหนด, คำอธิบายเล็ก) ยกเว้นแถบสลับตัวละคร (ห้ามแตะ) และตารางจัดทีม (ห้ามแตะ) ที่ยังเป็น 10–11px
- ทดสอบที่ยืนยัน "แถบนำทางต้องมองเห็นใต้แผ่นทีม/หน้าต่างตัวละคร" ปรับเป็น "แผ่นเต็มกรอบ แถบซ่อน": `portrait-keyboard`, `world`, `team-character-navigation` (ขั้นสลับแท็บจากในหน้าต่าง → ปิดหน้าต่างและแผ่นก่อน)
