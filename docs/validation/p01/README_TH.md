## Migration v43 → v44

- `campXp` = EXP รวมสูงสุดของสมาชิกถาวร (`levelXp(level)+exp` ของแต่ละคน) **ไม่รวมทุกคน**: โปรไฟล์ทุกคน (รวมคนในค่าย) + สำเนาในเที่ยวของคนที่อยู่ในค่ายแล้วหรือรับในเที่ยวนี้ (`recruited`); ไม่นับแขก (`guests`) และคนที่ยังเดินทางมา (`arrivals`); Lv/EXP หายไป = Lv1/0; ตัวที่ Lv10 ค้าง EXP ส่วนเกินเก็บไว้ได้ไม่เกินเพดาน validator (`maxCampXp`) ไม่ทำให้ Lv ล้น
- ทุนเดิมคงอยู่: ดาว ตัวซ้ำ grants ความถนัด loadout ของ ตำรา บอร์ดแช่แข็ง/`taken`; Lv ค่าย ≥ Lv เดิมของทุกคน จึงไม่มีใครเสียงบแต้ม (เทสต์ `talentsValid` ทุกคนหลังย้าย)
- เที่ยวที่ค้าง **เดินต่อได้** (ไม่บังคับกลับค่าย); `arrivals` เปลี่ยนเป็นรายชื่อ ดราฟต์ตัดเลเวลออก; ศึกที่ค้างซึ่งมีคนลงสนามเปลี่ยนเลเวล เริ่มใหม่จากเลือดตอนเริ่มศึก (ทิ้งคำสั่งเดิม ไม่ตีความคำสั่งด้วยพลังใหม่) ถ้าทุกคนในศึกอยู่ที่ Lv ค่ายแล้ว replay เดิมคงไว้
- เก็บสำเนาเซฟเดิมที่ `asterveil.fateweave.expedition.v1.backup.v43` ครั้งแรกครั้งเดียว (โหลดซ้ำไม่ทับ) เกมไม่อ่าน key นี้; storage เต็มยังโหลดได้และไม่เขียนทับเซฟเดิมจนบันทึกสำเร็จครั้งถัดไป; JSON เสีย/เวอร์ชันอนาคตปฏิเสธโดยไม่เขียนอะไร
- ผลการย้ายอยู่ใน `Game.migrated` (ไม่บันทึกลงเซฟ) เกมแสดงครั้งเดียวบนแผนที่หรือในค่าย เช่น "ย้ายเซฟเป็นเลเวลค่ายแล้ว · ค่าย Lv7 ตามเซฟาที่ก้าวหน้าที่สุด (ไม่รวม EXP ทุกคน) · ทุกคนในค่ายใช้เลเวลนี้ … · สำเนาเซฟเดิมเก็บไว้ในเบราว์เซอร์นี้" แล้วบันทึก v44 ทันที โหลดอีกครั้งไม่ย้ายซ้ำ

**ต่างจากสเปก P00 S09 (ตั้งใจ):** S09 แนะนำให้ส่งเที่ยวที่ค้างกลับค่ายแบบถอนตัว งานนี้เลือกเดินต่อ + เริ่มศึกที่ค้างใหม่จากเลือดตอนเริ่ม ตามแบบ v35/v40–v42 ของเกมนี้ เพราะการถอนตัวทำให้เสียความคืบหน้าบนแผนที่ (หมอก หีบ อีลิท แคมป์ที่ไปแล้ว) โดยไม่จำเป็น และยังรักษาหลัก "ไม่ตีความคำสั่งเดิมด้วยพลังใหม่" ไว้ครบ; กรณี "ศึกจบแล้วแต่ยังไม่ finish" เดิม parser finish ตอนโหลดอยู่แล้ว (shell finish ในการเขียนเดียวกับคำสั่งสุดท้าย) ทำต่อด้วย replay ใหม่หลังย้าย ไม่จ่ายซ้ำ
