# คำแนะนำในศึก Morvane

18 พฤศจิกายน 2026 · ต่อจาก [P11-05 step 6 และ baseline #297](../p11-05-step6/README_TH.md)

แถบคำแนะนำในศึก Morvane ใช้ advisor เดิมสำหรับการตั้งรับ รักษา และโจมตีวงกว้าง หากมีท่าบุกเป้าเดียวที่ใช้ได้ จะชี้ไปที่ Morvane จนกว่าจะลงดาเมจที่นับสิทธิ์ หลังจากนั้นจึงชี้ไปที่บอสเมื่อราชสำนักขาดคนและฮีโร่ที่ยืนอยู่ทุกคนเหลือ HP อย่างน้อยครึ่งหนึ่ง คำแนะนำอ่านสถานะปัจจุบันและตรวจคำสั่งกับกฎที่ใช้เล่นจริง ผู้เล่นเลือกท่าและเป้าเองได้ตลอด และปิดหรือเปิดแถบแยกจากคำแนะนำศึกแรกได้

## ผลจาก resolver และ replay จริง

| ทีม | ดาเมจบอสเดิม → ใหม่ | ผลการอยู่รอด |
|---|---:|---|
| ทีมเริ่มต้นสี่คนใน probe เดิม | 36 → 123 | ถึงเพดานรอบ 8 ทั้งคู่, เหลือ HP 34 → 28 จาก 226, ล้มสองคนทั้งคู่ |
| คู่รับสมัครหลังผ่านแมพ 1 (10 โปรไฟล์จาก 5 คู่) | 175–205 → 155–332 | ทั้ง 10 โปรไฟล์ลงดาเมจและถึงเพดานรอบ 8 |
| จบแมพ 3 (4 โปรไฟล์) | 267–296 → 505–615 | ถึงเพดานรอบ 8 และไม่มีคนล้ม |
| หลังแคมเปญ (4 โปรไฟล์) | 361–444 → 909–985 | ถึงเพดานรอบ 8 และไม่มีคนล้ม |

คู่ Sefa + Toma ทำดาเมจลดจาก 184 เป็น 155 และเหลือ 37/299 จากเดิม 86/299. ในร่างที่แนะนำให้ตีบอสต่อขณะทีมบาดเจ็บ คู่นี้ทำ 286 แต่ล้มทั้งทีมในรอบ 8 จึงเลือกให้กลับไปคุมลูกน้องเมื่อทีมบาดเจ็บ รอบที่ลองตีลูกน้องอย่างเดียวในทีมสี่คนยังลงดาเมจ 0 ตามกติกาการนับสิทธิ์เดิม ผลรายทีมและรายละเอียด Call the Court อยู่ใน [ตารางก่อน–หลัง](morvane-advisor.md)

## HP ส่วนกลางและการเปิดใช้งาน

| แบบจำลอง Morvane | 10 คน ถึง 50% / ล้ม 100% | 20 คน ถึง 50% / ล้ม 100% |
|---|---|---|
| advisor เดิมทั้งหมด, 400 HP/ครั้ง | 69–71% / 12–17% | 77–79% / 3–7% |
| ใช้คำแนะนำใหม่ครึ่งกลุ่ม, 400 HP/ครั้ง | 86–94% / 47–50% | 98% / 47–48% |
| ใช้คำแนะนำใหม่ครึ่งกลุ่ม, ทดลอง 350 HP/ครั้ง | 90–96% / 57–62% | 99% / 62–64% |
| ใช้คำแนะนำใหม่ครึ่งกลุ่ม, ทดลอง 300 HP/ครั้ง | 94–98% / 68–73% | 99–100% / 80–84% |

ที่ 400 HP/ครั้ง กลุ่มจำลอง 20 คนที่ใช้คำแนะนำครึ่งกลุ่มเกินเป้าร่างเดิมที่คาดว่าจะถึง 50% เกือบทุกสัปดาห์และล้มบอสราวหนึ่งในสามของสัปดาห์ จึงเก็บ 400 และกติกา Call the Court ไว้ ค่า 350/300 เป็นการทดลองในแบบจำลอง เผื่อพิจารณาหากอัตราการใช้คำแนะนำจริงต่ำกว่าสมมติฐาน

แบบจำลองใช้ 30 seeds × 6 สัปดาห์ต่อรูปแบบ และสัดส่วนทีมตามช่วงเกมจาก probe เดิม ไม่รวมสัปดาห์ที่ย้ายยอด Warden และยังไม่มีข้อมูลพฤติกรรมของผู้เล่นจริง ผลนี้ยืนยันเส้นทางการเล่นที่นับสิทธิ์และแสดงความไวต่อการทำตามคำแนะนำ คง Warden ตาม OD-51 โดยเว้น `trio.from` ระหว่างยืนยันความพร้อมเปิด จึงไม่มีผล staging load ของ trio ในงานนี้

## การทำซ้ำ

```sh
mkdir -p /tmp/morvane-coach
TRIO_OUT=/tmp/morvane-coach npx vitest run tests/probe/p1105-world-boss-trio.test.ts tests/world-boss-trio-world.test.ts
```

ชุด world test ส่งคำสั่งที่ได้จากคำแนะนำไปยัง `worldBossAttempt` และตรวจว่าบันทึกดาเมจและนับสิทธิ์จริง Browser spec ที่ 390px เปิด trio ด้วย fixture เพื่อเข้าศึก ตรวจว่าคำแนะนำแสดงตรงเป้าเดิมหลังปิด–เปิด และอยู่ที่เทิร์นเดิม Warden ใช้เส้นทางตามกฎที่จัดส่งจริง ผลตรวจใช้กับการทำงานของเกม Content version จาก build คือ `5278f631cd330bde`
