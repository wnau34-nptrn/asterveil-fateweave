# หัวแถวบนของหน้าต่อสู้ให้คมขึ้น (2026-11-06)

เจ้าของแจ้งว่าตัวหนังสือด้านบนหน้าต่อสู้ (iPhone เว็บแอป) ดูเบลอเหมือนถูกบังคับเบลอ เกรงว่ามาจาก Dynamic Island วิเคราะห์จากภาพจริง: ไม่ใช่เกาะและไม่มี filter/blur/opacity ที่ตัวแม่ (วัดสไตล์จริงด้วย Playwright) ตัวหนังสืออื่นในแผงคิวและด้านล่างคมปกติ (ความคมขอบ 0.83–0.93) เฉพาะสองจุดนี้ต่ำ (0.33 / 0.42):

- `.turn-title` ("เทิร์นของคุณ · ไลรา") 13px สีฟ้าอ่อนบาง เงา `0 1px 6px #000` ฟุ้งจนขอบกลืน → 14px สีสว่างขึ้น เงาแคบ `0 0 1px #000, 0 1px 2px #000c`
- `.beat-chip` ("รอบ 1") ขนาดจริง 9px น้ำหนัก 400 สีทองจางบนกระจก → 12px น้ำหนัก 600 สีทองสว่าง พื้นทึบขึ้น (`#08121fe6`) ขอบชัดขึ้น

ตำแหน่งและความสูงของแถวเดิม (ไม่ขยับลง); แก้เฉพาะ `portrait.css` ไม่เปลี่ยนกฎ/เซฟ/ตัวเลข
