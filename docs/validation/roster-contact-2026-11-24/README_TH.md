# ภาพและเสียงต่อสู้สำหรับตัวละครครบชุด

ฐานที่ใช้เทียบคือ `3b746ac` หลัง PR #352. ใช้ roster จากเกม ครอบคลุมตัวละครที่รับเข้าทีมได้ 15 ตัว และ Odran/Isolde ที่ยังมีได้ในเซฟเก่า. แผนที่ ตัวละคร และแอนิเมชันสกิลที่อนุมัติแล้วใช้ assets เดิม.

| ภาพและเสียงโจมตีปกติ | ตัวละคร |
|---|---|
| ใบดาบหรือหอกตามท่าและสีอาชีพ เสียงเหวี่ยงใกล้ปะทะ | Aegis, Lyra, Sefa, Garran |
| ลูกธนูหรือขวดเดิม เสียงออกจากจุดปล่อยของท่า | Mira, Toma |
| ลูกพลังตามสีอาชีพและเสียงเวท | Eira, Seren, Wynne, Astrid |
| แรงกระแทกเฉพาะจุดและเสียงทุ้ม | Brann, Corin, Kael, Odran |
| คลื่นจังหวะตามสีอาชีพและเสียงโน้ต | Lio, Cerise, Isolde |

เสียงเตรียมสกิลเลือกจากท่าและเฟรมปล่อยที่มีอยู่ แล้วใช้ event ของเทิร์นกับผลโดน โล่ หลบ และท่าสนับสนุน. สกิลแรงเฉพาะอย่าง Execute ยังใช้เสียงปะทะเดิม. เตรียมเสียงได้หนึ่งคิวและเล่นเสียงผลพร้อมกันได้สูงสุดสองสูตร. รูปแบบเวลาใน Normal/Fast, skip, ความเข้มเอฟเฟกต์, OS reduced motion, mute/volume และเซฟ v68 ใช้ระบบเดิม. ไม่มีการเพิ่มไฟล์ภาพหรือเสียงให้โหลด.

ตาราง coverage มี 119 คู่ตัวละคร–ท่า และ 91 ActionId ข้ามทุกคลาส. เทสต์ภาพรายตัวเล่นโจมตีปกติของทั้ง 17 ตัวด้วย resolver และ BattleUI/Phaser ที่ 390px. คลิปเก็บการโจมตีปกติรายตัวและเสียง Web Audio ในฉากทดสอบโดยปิดเพลงพื้นหลัง. การตรวจสกิลใช้กฎจัดเสียงร่วมและเทสต์ที่มีในโปรเจกต์. ยังไม่มีการทดสอบบนมือถือจริง.


## ผลทดสอบ

- Typecheck, lint และ Pages production build ผ่าน
- Vitest 54 กรณี ครอบคลุมเซฟ v68, ผลลัพธ์การต่อสู้, เสียง และการตรวจข้อมูล coverage
- Playwright บน dev build ผ่านครบ 42 กรณีโดยรัน Kael ซ้ำหลังแก้ตัวเก็บคิวเสียงให้เห็นทั้งเสียงปะทะและเสียงเพิ่มปราณ
- Playwright บน production build ผ่าน 5 กรณี ครอบคลุม Normal/Fast, skip, resize/reload, mute และการเล่นเสียงด้วย Web Audio

## ผลวัดก่อน–หลัง

ทดสอบ Eira โจมตีปกติใน Normal สามรอบต่อรุ่นต่อขนาดจอด้วย Chromium และ SwiftShader. ที่ 390px จำกัด CPU 4×. วัดช่วงระหว่างเฟรมจาก requestAnimationFrame หนึ่งวินาทีหลัง pointerdown โดยปิดการอัดคลิป. ค่า p95 และ FPS ใช้มัธยฐานของสามรอบ.

| ขนาดจอ | p95 ช่วงระหว่างเฟรม ก่อน → หลัง | FPS ก่อน → หลัง | Long tasks รวม 3 รอบ ก่อน → หลัง |
|---|---:|---:|---:|
| 390px | 100.0 → 100.1 ms | 29.0 → 26.0 | 6 → 7 |
| 1366px | 149.9 → 99.9 ms | 20.9 → 21.8 | 1 → 1 |

จอมือถือจำลองมีเวลาเฟรม p95 ใกล้เดิม แต่ FPS ลด 3 และมี long task เพิ่มหนึ่งครั้งในสามรอบ. ค่า p95 รายรอบที่ 390px กระจายตั้งแต่ 83.3 ถึง 300 ms. การโจมตีเวทมีกราฟิกและเสียงปล่อยเพิ่มจากฐาน เป็นงานเพิ่มที่อาจมีส่วนกับผล แต่ชุดวัดนี้แยกต้นทุนจากความผันผวนของการเรนเดอร์ด้วยซอฟต์แวร์ไม่ได้. ผลเดสก์ท็อปใช้เป็นข้อมูลของฉากทดสอบนี้เท่านั้น. ชุดวัดนี้ให้ข้อมูลเฉพาะเวลาเฟรมและ long tasks ในฉากต่อสู้.

ตัวจับคิวในคลิปเห็นเสียงเตรียมของ Eira เปลี่ยนจาก swing ที่ประมาณ 205 ms ก่อนจุดปะทะเป็น orbRelease ที่ 93 ms ก่อนจุดปะทะ. ค่านี้วัดจากเวลาที่เกมเรียกคิวในคลิป ค่าหน่วงจากลำโพงขึ้นกับอุปกรณ์.
