เจ้าของอนุมัติแบบที่ตรวจพื้นที่ 390px ด้วยคำว่า “ดำเนินการตามที่แนะนำได้”:
- แยกทีมออกจากกระเป๋า เพิ่มปุ่มทีมบน HUD และเรียก Preset ด้วยการแตะครั้งเดียว เฉพาะคนที่พามา
- ผังสกิลเป็นแท็บหลักเอง ไม่เข้าผ่านแท็บสกิล; MAP ไม่มีแท็บพัฒนา/อัปดาว/เพิ่ม Lv/แลกตำรา ส่วนค่ายยังทำบริการเดิมได้

## ผลการเปลี่ยน

- HUD แถวเดียว `เป้าหมาย | ทีม | กระเป๋า`: ทีม 72×44px กระเป๋า 96×44px ที่ 390px; จอแคบปรับขนาดปุ่มแต่ไม่น้อยกว่า 44px แผนที่/ปุ่มเดินไม่ถูกดันเพิ่มแถว จำนวนของยังดูได้ในกระเป๋าและ aria-label
- ปุ่มทีมเปิด `team-dialog` แยกจาก `pack-dialog`; **T** เปิด/ปิดทีม, **B** กระเป๋า, **I** ข้อมูล, Escape ปิดหน้าบนสุด; เคารพ native editing, modifier/repeat/IME, rotation และ modal เดิม
- ทีมแสดง Preset 4 ช่องก่อนสนาม/สำรอง/formation ช่องว่างบันทึกได้ที่ค่ายเท่านั้น ชุดที่ขาดสมาชิกแสดงชื่อที่ไม่ได้พามา; ไม่มีการดึงคนจากค่าย
- ใช้ `applyRunPreset` เดิมเพื่อสลับด้วยการแตะครั้งเดียว ไม่เปลี่ยนแผนคำนวณ/กฎช่อง/HP/ความเหนื่อย; สถานะ “ใช้อยู่” เทียบผลจัดชุดเฉพาะคนที่พามาและยังแสดงจำนวนคนขาด
- จัดทีมได้เฉพาะเงื่อนไขเดิมนอกการต่อสู้; สมาชิก/formation/preset ถูกปิดเมื่อ busy และ core guards เดิมยังอยู่
- การเปิดตัวละครจากทีมและปิดกลับ คืน dialog/scroll/focus ให้ทีม ไม่ย้อนเข้ากระเป๋า; ทางเข้าตัวละครจากอุปกรณ์ในกระเป๋ายังคืนกระเป๋าตามเดิม แคมป์พักแรม/ทางเข้าด่านยังมีบริการเดิม
- MAP มี **ภาพรวม / อุปกรณ์ / สกิล / ผังสกิล**; ค่ายมี 5 แท็บโดยเพิ่ม **พัฒนา** คีย์ลูกศร/Home/End วนเฉพาะแท็บที่มีจริง
- ผังสกิลใช้ renderer/การลงแต้มเดิม แยกเต็มหน้า; deep link จากสกิลไปโหนดและย้อนกลับยังคงสกิล/scroll/focus; reset แต้มยังค่ายเท่านั้น
- MAP สกิลมีคำอธิบาย/ติดตั้ง/เรียงลำดับ ไม่มีแถบเพิ่ม Lv หรือตำราที่กดแล้วทำไม่ได้; ค่ายยังเพิ่ม Lv/แลกตำราพร้อม preview/confirmation เดิม
- แท็บพัฒนาค่ายเหลืองานอัปดาวจริง ตัดปุ่มลิงก์ซ้ำไปอุปกรณ์/สกิล/ผังสกิล
- อัปเดต guide และคำพูด NPC ที่ยังอ้างจัดทีมในกระเป๋าหรือ 4+4; ไม่เปลี่ยนกติกาศึก เซฟ ตัวเลข รางวัล จำนวนช่อง เงื่อนไขสถานที่ หรือ availability จาก #201/#202; ไม่เพิ่ม art/animation และไม่เริ่ม P09
