### 1 การสลับสัปดาห์

- `serverDay` (รีเซ็ต 06:00 กรุงเทพ) + `weekOf` (เริ่มวันจันทร์): 05:59:59 → 2968, 06:00:00 → 2969; `nextDayAt` เวลาอาทิตย์ค่ำชี้ที่ 06:00 วันจันทร์พอดี; เสาร์ 22 พ.ย. 06:00 ไม่เปลี่ยนสัปดาห์
- ออฟไลน์ (`?server=off`): วันของเครื่อง = วันที่ท้องถิ่นย้อน 6 ชม. บนเครื่องเวลากรุงเทพได้สัปดาห์เดียวกับ server ทั้งสองฝั่งของเวลาสลับ (เครื่องที่ตั้งโซนเวลาอื่นจะสลับตาม 06:00 ของเครื่องนั้นแบบออฟไลน์ ซึ่งเป็นพฤติกรรมเดิม)
- ผ่าน Worker จริง (fake D1/DO แบบเทสต์ server อื่น, กฎจัดส่ง): ก่อน 06:00 มีแค่แถบผู้คุม และการตี trio ถูกปฏิเสธ `boss`; 06:00 เปิดสามแถบ; การตีผู้คุมหลัง 06:00 ถูกปฏิเสธ `boss` (ไม่เสียสิทธิ์) การตี trio นับและได้เศษบอส; `s-50` ของผู้คุมสัปดาห์ 2968 รับได้ในสัปดาห์ 2969; จันทร์ 30 พ.ย. 06:00 รับไม่ได้แล้ว; `/verify` replay ผ่าน
- Content version / deploy grace (OD-57): `trio.from = 2969` อยู่ใน content ตั้งแต่ PR #301 การสลับเป็นตามเวลา ไม่มี content version ใหม่ที่ 06:00 จึงไม่มีหน้าเก่าโดน 409 เพราะการสลับ (grace ใช้เฉพาะหลัง deploy)
