# P04-02 — เศษเฉพาะตัว + เศษกลาง แทนตัวซ้ำ/ตรา (save v59)

13 พฤศจิกายน 2026 · เจ้าของ OD-15–OD-26 (“ตามที่แนะนำ”) · ตัวเลขเป็นร่างจาก [P04-01](../p04-01-2026-11-13/README_TH.md)

## สิ่งที่เปลี่ยนในเกม

| เรื่อง | ก่อน | หลัง |
|---|---|---|
| ดาว ★2–5 | ตัวซ้ำ 1/2/3/4 + แร่ 20/40/70/110 (รวม 240); ตราแทนได้ไม่เกินครึ่ง | **เศษของคนนั้น 10/20/30/40 + แร่ 15/30/45/70 (รวม 160)**; ใช้เศษของคนนั้นก่อน แล้ว**เศษกลางจ่ายส่วนที่เหลือได้ทั้งหมด** |
| ตัวซ้ำ (จ้าง/ใบสัญญาซ้ำ) | +1 ตัวซ้ำ | +10 เศษของคนนั้น; ถ้าคนนั้น ★5 แล้ว → +10 เศษกลาง (OD-04) |
| ตราสัญญา | ของตก บอส หีบหายาก อีเวนต์ อีลิทเสริม มินิบอส เควสต์ hard ครั้งแรก ร้าน | **เศษกลาง**: ของตกที่เคยให้ตรา 1 อัน → 3 ชิ้น; เควสต์/ผ่าน hard ครั้งแรก ×10 (มูลค่าเท่าเดิม) |
| ผ่านแมพครั้งแรก (ปกติ) | ตำรา | ตำรา + **เศษกลาง 10** (OD-17) |
| ร้านค่าย | ตรา 60 ทอง จำกัด 2/รอบ | **ห่อเศษกลาง 10 ชิ้น 60 ทอง จำกัด 1/รอบ** |
| ตีของ | สุ่มคุณสมบัติใหม่ 1 ตรา · ย้ายคุณสมบัติ 12 แร่ 3 ฝุ่น 1 ตรา | 10 เศษกลาง แทน 1 ตรา (มูลค่าเท่าเดิม) |
| ตัวละครเนื้อเรื่องที่มีอยู่แล้ว | ข้ามไปเฉย ๆ | ผ่านแมพแล้วได้เศษของคนนั้น 10 ชิ้น **ครั้งเดียวต่อคน** (`profile.storyShards`, OD-22) |

## ย้ายเซฟ v58 → v59 (ไม่มีใครเสียของ)

ตัวซ้ำทุกตัว → เศษ 10 ชิ้นของคนนั้น · ตราในคลัง/ที่พกอยู่ในเที่ยว/ผลเที่ยวล่าสุด → เศษกลาง ×10 · ซื้อตราไปแล้วในรอบนี้ → นับเป็นซื้อห่อเศษแล้ว · ตัวละครเนื้อเรื่องที่อยู่ในค่ายแล้วถูกบันทึกว่า “พบแล้ว” เพื่อไม่จ่ายซ้ำ · server แปลงเองตอนนำเข้าเซฟเก่า (`parseGame`) และเกมที่เก็บใน Durable Object ก่อนหน้านี้ถูกแปลงตอนอ่าน (`upgradeStoredGame`) แล้วบันทึกแบบใหม่ในคำสั่งถัดไป · ข้อจำกัด: `/v1/verify` ที่ replay log เก่าข้ามการเปลี่ยนกฎนี้อาจไม่ตรง (เป็นการตรวจของผู้ดูแลเท่านั้น)
