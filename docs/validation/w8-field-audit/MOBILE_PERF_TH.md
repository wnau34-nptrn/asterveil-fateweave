# วิธีวัดเกมบนมือถือจริง (W8) — สำหรับเจ้าของ

แผงวัดผลเปิดเฉพาะเมื่อมี `?perf=1` ต่อท้ายลิงก์ ไม่มีผลกับเกมปกติ ไม่เปลี่ยนเซฟ กติกา หรือคำสั่งในศึก

## ขั้นตอน (ประมาณ 10 นาที)

1. ใช้มือถือหนึ่งเครื่อง ชาร์จแบตพอ ปิดแอปอื่น ใช้ Wi‑Fi เดิมทุกครั้งที่วัด
2. เปิด `https://wnau34-nptrn.github.io/asterveil-fateweave/?perf=1` (หลังงาน W8 เผยแพร่แล้ว) — จะมีแผงเล็กมุมซ้ายบน
3. เล่นต่อจากเซฟเดิม เข้าศึกอย่างน้อย 3 ครั้ง ให้มีศึกบอสหนึ่งครั้งถ้าทำได้ (เช่น หัวหน้ากองหน้า) และใช้สกิลหลายท่า
4. กด **คัดลอกผล** แล้ววางข้อความทั้งหมดในแชต พร้อมบอกรุ่นมือถือและเบราว์เซอร์ (เช่น iPhone 13 / Safari หรือ Samsung A54 / Chrome)
5. ถ้าแผงบังจอ กด **ย่อ**; ถ้าอยากวัดเฉพาะศึกหนึ่ง กด **ล้างเฟรม** ก่อนเริ่มศึกนั้น

## ตัวเลขในแผงหมายถึง

| บรรทัด | ความหมาย | เกณฑ์ที่หวัง (ร่าง) |
| --- | --- | --- |
| เริ่มเกม / สนามแรกพร้อม | เวลาจากเปิดหน้าจนหน้าชื่อเกมพร้อม / จนปุ่ม “เริ่มต่อสู้” ของศึกแรกกดได้ | สนามแรก < 5 วินาทีบน Wi‑Fi |
| เตรียมสนามล่าสุด | เวลาที่ปุ่มเริ่มต่อสู้ขึ้น “กำลังเตรียมสนาม…” ก่อนกดได้ ในแต่ละศึก | < 2 วินาที |
| เฟรมในศึก · fps · p95 | นับเฉพาะตอนหน้าศึกเปิดอยู่ เกมตั้งไว้ 30 fps | p95 ≤ 40 ms |
| ช้า > 50 ms · กระตุก > 100 ms | จำนวนเฟรมที่ช้าจนเห็น / สะดุด | กระตุกไม่เกิน 1–2 ครั้งต่อศึก |
| texture | หน่วยความจำภาพที่ศึกถืออยู่ (decoded RGBA) และค่าสูงสุด | ไม่โตขึ้นเรื่อยๆ เมื่อเล่นหลายศึก |
| heap | หน่วยความจำ JavaScript — **iPhone/Safari ไม่เปิดให้วัด** จะขึ้น “ไม่รองรับ” | — |

## สถานะ

- ทดสอบแผงแล้วเฉพาะ Chromium ในเครื่องพัฒนา (`tests/browser/perf-probe.spec.ts`) — **ยังไม่ได้วัดบน iOS Safari หรือมือถือจริง** จนกว่าเจ้าของส่งผลกลับมา
- ผลที่ได้จะบันทึกต่อท้ายไฟล์นี้ (รุ่นเครื่อง, เบราว์เซอร์, วันที่, JSON)
