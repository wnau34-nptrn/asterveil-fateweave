## 1. เกณฑ์แคมเปญ (`tests/campaign-sim.test.ts`)
- กลุ่ม casual รัน 48 ค่าย (seed 1001+37i, i<48 — 12 ตัวแรกตรงกับของเดิม); advisor ยัง 12
- เกณฑ์อ่านขนาดกลุ่มจากหัวกลุ่ม ("· N companies"): ช่องเสียได้ 1 ค่ายต่อ 12 (48 → 4) และผลรวมกลุ่มต้องไม่ต่ำกว่าฐาน
- ฐานเทียบ `tests/fixtures/c12-campaign-before.json` สร้างใหม่จากโค้ด 444f06b: กลุ่ม advisor เท่าเดิมทุกช่อง (10/10); กลุ่ม casual เปลี่ยนเพราะตัวอย่างใหญ่ขึ้น:

| ช่อง casual (ครั้งแรก) | 12 ค่าย | 48 ค่าย |
|---|---|---|
| rush ซากชายแดน | 100 | 98 |
| rush ป่าทึบ | 92 | 96 |
| rush แนวรอยแยก | 58 | 71 |
| rush ยาก #1 / #2 | 92 / 100 | 90 / 98 |
| explorer ป่าทึบ | 42 | 58 |
| explorer ที่เหลือ | 100 | 100 |

ตัวเลขเดิมของ rush แนวรอยแยก (58 → รายงาน P04-04 ว่าราว 70%) และ explorer ป่าทึบ (42) แกว่งเพราะตัวอย่างน้อย ยืนยันข้อ ง ของ P04-04 (casual แนวรอยแยก ~70% รอ P05)
- ผลการรัน: `SIM_REPORT=1 vitest run tests/campaign-sim.test.ts` 5/5 ผ่าน (~5 นาที; ปกติเดิม ~1.5 นาที) `roster-30/batch-1/CAMPAIGN.md` สร้างใหม่
