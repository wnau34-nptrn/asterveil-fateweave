# แผนที่ 5 เหมืองผลึกร้าง

เจ้าของอนุมัติแนวทางแผนที่ตาม OD-60 และให้ Codex รับช่วงงานเซฟ กฎต่อสู้ และสมดุลเมื่อ Claude ใช้งานต่อไม่ได้ งานอยู่บนสาขา `codex/map5-crystal-mine-design`

## สิ่งที่เล่นได้

- จบทะเลสาบเงาจันทร์แล้วเข้าถึงเหมืองจากค่าย สำรวจสามโซน จุดตะเกียง เติมผลึกพกพา 12 ก้าว พาคนงานกลับลาน และเปิดทางด้วยรถแร่หรือผลึกสะท้อนแสง
- ผลผนึกทั้งสามคู่ผ่านการทดสอบระดับคำสั่งเกม โดยใช้ศึกทดสอบแยกจากการจำลองแคมเปญ ทางตะเกียงกับคนงานเลี่ยงศึกหัวหน้าคุมเหมืองได้
- จุดรับแบรนน์ที่แคมป์ลานคนงาน และจุดรับเคลหลังเงื่อนไขผนึกข้อแรก เซฟ v69 เก็บสถานะเหมืองและเปิดเซฟทะเลสาบ v68 ได้
- ยักษ์ผลึกขึ้นเกราะในรอบแรก สะท้อนเวทตรง 35% จำกัด 15% ของ HP สูงสุดผู้ร่ายต่อแอ็กชัน เกราะหมดหลังเทิร์นบอสรอบ 3 หรือแตกด้วยการโจมตีกายภาพ 3 แอ็กชันหรือท่าทุบหนัก ผลึกถล่มลงทุก 3 รอบ พอ HP ต่ำกว่า 50% เกิดผลึกย่อยทันทีและเข้าคิวรอบถัดไป การโค่นยักษ์จบศึก
- คนงานถูกสิงยอมแพ้เมื่อศัตรูอื่นล้มหมด การปล่อยให้รอดให้แร่เพิ่ม ส่วนสมุดบัญชีสามหน้ามีรางวัลแร่หนึ่งครั้ง

## ค่าทดลองและหลักฐาน

รอบจูน 2026-11-26 (Claude) ขยายการจำลองเป็น 48 seed ต่อคู่เริ่มต้น ต่อแบบผู้เล่น และต่อเส้นทาง (768 แคมเปญ) แล้วปรับยักษ์ผลึกให้ศึกสั้นลงแต่ลงโทษผู้ไม่ตอบ intent มากขึ้น ค่าทั้งหมดยังเป็นร่าง กลไกและเกราะสะท้อน 35% ไม่เปลี่ยน ความมืดคง 125%

| ค่า | เดิม | ใหม่ |
|---|---:|---:|
| HP ยักษ์ผลึก (Lv16) | 826 | 580 |
| Crystal Fist (กายภาพ เป้าแถวหน้า) | 91 | 225 |
| Shard Beam (เวท เป้าแถวหลัง) | 69 | 205 |
| ผลึกถล่ม (ทั้งทีม ทุก 3 รอบ) | 63 | 68 |
| ผลึกย่อย HP / ดาเมจ (หลังปรับระดับ) | 82 / 27 | 59 / 45 |

`crystal-giant` เป็น version 2 เซฟที่ค้างศึกยักษ์ผลึกรุ่นเดิมจะถูกปฏิเสธอย่างปลอดภัย

| กลุ่ม (48 seed × 4 คู่) | ผ่านเหมืองครั้งแรก | เป้า | โจมตีปกติชนะบอส (บอสก่อน / ผลึกย่อยก่อน) | รอบเฉลี่ยของศึกที่ชนะ |
|---|---:|---:|---:|---:|
| advisor สายรีบ | 191/192 (99%) | ≥90% | 0% / 0% | 8.6 |
| advisor สายสำรวจ | 192/192 (100%) | ≥90% | 16% / 4% | 7.4 |
| casual สายรีบ | 150/192 (78%) | 70–80% | 1% / 0% | 8.9 |
| casual สายสำรวจ | 191/192 (99%) | ≥80% | 22% / 10% | 7.9 |

- casual สายรีบแยกคู่ 73–88% (toma + brann 88% สูงกว่าเป้า คู่อื่น 73–77%)
- ค่าเดิมที่ 48 seed: casual สายรีบผ่าน 96% และศึกยาว 10–12 รอบ ซึ่งง่ายและยาวเกินเป้า
- ชุดทีม (Lv13/16, ★1 ไม่มีอุปกรณ์ เข้าศึกที่ HP 55–100%): ทุกทีมชนะ 9–10/10 เมื่อตอบ intent และโจมตีปกติชนะ 0/10 รอบมัธยฐาน 7–12 ผลึกถล่มเป็นตัวกำหนดหลักของทีมที่เข้าศึกบาดเจ็บ: ที่ 78 ทีมโจมตีเดี่ยว Lv13 ชนะ 5/10 ที่ 60 ชนะ 10/10 แต่ casual สายรีบผ่าน 90% จึงเลือก 68
- ความมืด 100/115% และ 125/135% ได้ผลเท่ากันเพราะการปัดเศษภัยคุกคามต่อก้าว ความมืด 125% เพิ่มการต่อสู้สุ่มราว 0.5–1 ครั้งต่อเที่ยว (เป้า 0–1)
- ยังเกินเป้า: รอบเฉลี่ยของ casual สายรีบ 8.9 และชุดทีมป้องกัน Lv13 12 รอบ สูงกว่าเป้า 5–8 เล็กน้อย การลด HP ต่อทำให้โจมตีปกติชนะเกินครึ่ง

ตารางเต็ม [SIM.md](SIM.md) (`SIM_REPORT=1 MINE_SIM_SEEDS=48 npx vitest run tests/mine-sim.test.ts` ราว 35 นาที) รอบจูนใช้ `tests/mine-tune.test.ts` ซึ่งเก็บแคมเปญแผนที่ 1–4 ไว้ครั้งเดียวแล้วเล่นเฉพาะเหมืองซ้ำ (ผลตรงกับการรันเต็ม)

Chromium 390×844 ผ่าน 8 รายการในชุดเหมืองและทะเลสาบ ตรวจการจุดตะเกียง ผนึก เติมแสง โหลดกลับมา เปิดศึกยักษ์ผลึก เข้าจากค่าย และเปิดกำแพงด้วยรถแร่ ใช้ภาพเดิมชั่วคราว การตรวจนี้ยืนยันการทำงานของหน้าจอใน Chromium ส่วนภาพและ motion ของยักษ์ผลึกยังรอการทบทวนด้วยคลิปจากสนามพร้อมฮีโร่ห้าคน

งานเสริมที่ยังไม่ได้ทำ ได้แก่ เหตุการณ์สายแร่สด งานค่ายเก็บผลึกอีลิท และสูตรตีอาวุธผลึกจากสมุดบัญชี
