# ตำแหน่งยืนตามแนว + บอสกลาง (2026-11-20)

เจ้าของ (จากภาพหน้าจอ vanguard-captain 390px): “ตำแหน่งยืนมั่วมาก” → ตัดสินใจ: ห้ามยืนครึ่งแถวเพราะกระทบทวน, บอสยืนกลางพอดี, ด่านไม่มีบอสจัดให้สมดุล, “ถ้าเป็นบอส จะมีลูกน้องได้แค่ 4 ตัวมากสุด … B1 ที่อยู่หลังบอสจะไม่มี”, “ดำเนินการตามที่แนะนำได้”

## กฎ
- แนว = f1/b1, f2/b2, f3/b3 (แทงทะลุ/ผลักของทวนใช้แนวนี้) → หน้าและหลังของแนวเดียวกันยืนแถวเดียวกันเสมอ (`src/core/battle/foe-lines.ts`)
- มีบอส: แนวบอสอยู่แถวกลาง บอสยืนกลางครึ่งฝั่งศัตรูพอดี แนว 3 บน แนว 2 ล่าง; ไม่มีบอส: 1 แนว = กลาง, 2 แนว = บน/ล่าง, 3 แนว = 1 บน / 3 กลาง / 2 ล่าง
- บอสที่ใช้ซ้ำเป็นประตู elite (ไม่มีกลไกบอส) ได้ `leader` ยืนที่เดียวกับบอส
- สองฝั่งใช้แถวเดียวกัน แถวกลางอยู่กึ่งกลางระหว่างบนกับล่างเมื่อไม่ชนแถบ HP (แทนการดึงแถวบนแยกฝั่งของ 2026-11-18)
- ตัวข้างเคียง (กรด/ควัน/พิษกระเด็น) นับตามแถวที่เห็น ไม่ใช่เลขช่อง
- ด่านบอส: ลูกน้อง ≤ 4 (รวมตัวสำรอง) และไม่มีใครในแนวบอส — ตรวจใน `encounterProblems`

## เนื้อหาที่เปลี่ยน
b1 → b3: mini-veil-golem (v12, HP บอส 200 → 190), vanguard-captain (v8), elite-briar-lord (v12), wb-valdrakk (v2). rift-warden (v22) / world-boss-warden (v2): ลบ b1, ที่ 70% เรียก b2 + f3 ทั้งสองโหมด. thorn-host, rift-legion, wb-morvane (v2) จากกฎข้างเคียง
