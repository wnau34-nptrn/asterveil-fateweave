# แผนที่ 4 ทะเลสาบเงาจันทร์ — ผลตรวจ (2026-11-22)

คำสั่งเจ้าของ: OD-60 (2026-11-22 “ตามแนะนำทั้ง 4 ข้อ ทำต่อได้”) · ตัวเลขทั้งหมดเป็นร่าง

## จำลองแล้ว (`npm run sim`, `tests/lake-sim.test.ts` → [SIM.md](SIM.md))

ค่ายใหม่เล่นแผนที่ 1 → 4 ต่อกัน ไม่เล่นซ้ำ (ถึงทะเลสาบที่ Lv10 จบรอบที่ Lv13)
- คนเล่นทั่วไป (casual) ผ่านทะเลสาบครั้งแรก: สายรีบ 75% · สายสำรวจ 98% (เป้า OD-33/34 ~70–80%) · advisor 100%
- กดโจมตีอย่างเดียวชนะบอสภูตธารา 0–33% (ต่ำกว่าครึ่งทุกกลุ่ม) · อสรพิษเงา 0–42%
- ความแรงแผนที่: บอส 225% Lv14, อสรพิษ 270% Lv12 (บังคับ), นางเงือก 320% Lv12 (เสริม)
- ม่านน้ำ (Water Veil) ฟื้น 10% แล้วลดลงทุกครั้งที่สำเร็จ (10 → 5 → 3.3 …) เพื่อไม่ให้ศึกยืดไม่จบ
- เพดาน Lv ค่าย (+3 ต่อแผนที่ที่ผ่านหลังแผนที่ 2): แผนที่ 1–3 ครั้งแรกเหมือนเดิมทุกช่อง; รอบเล่นซ้ำ/โหมดยากของแผนที่ 3 ขึ้นถึง Lv13 แทน 10 ผ่านเท่าเดิม (ยาก 98–100%) กดโจมตีอย่างเดียวชนะบอสยาก 13–17% (เดิม 8%)

**ประตูเทียบแคมเปญ C12 ไม่ผ่าน และเป็นปัญหาเดิม:** กลุ่ม casual สายสำรวจได้ 220 ครั้ง ต่ำกว่าเกณฑ์ 226 ครั้ง รันจาก commit ฐาน f73f181 (ก่อนงานนี้) ได้ 220 เท่ากันทุกช่อง สาเหตุจึงเป็นงานก่อนหน้า (รายงานที่ commit ไว้ล้าสมัย) ไม่ได้ปรับเกณฑ์ (fixture) เพื่อไม่ซ่อนการถดถอย
