# TEAM-FORMATION-EDITOR-002 — 2026-11-08

เจ้าของอนุมัติ mockup ที่ให้แผนการยืนอยู่บนสุด เป็นสมาชิกลงสนามชุดเดียว ไม่มีแถบลงสนามซ้ำ และบันทึกทีมเป็น preset หลังจัดเสร็จ

## ผลลัพธ์

- แผนการยืนบนสุด หลังซ้าย/หน้าขวาตามสนามจริง เลขช่องยังเป็นลำดับ deployed ที่ศัตรูใช้เล็ง ลงสนาม ≤5 และแนวละ ≤3 ตามกติกาเดิม
- กระดานใช้เลือกตัวเดียวร่วมกับสำรองและค่าย วางในช่องว่างหรือสลับกับคนที่ยืนอยู่ได้ทั้งสองทิศทาง โดยคงตำแหน่งแนวและลำดับของสมาชิกที่ไม่ได้ย้าย
- `src/ui/camp-team.ts` รวมการย้ายกลุ่มและกำหนดแนวในคำสั่ง UI ครั้งเดียว ใช้ `placeMember` และ `formation` เดิมตรวจความจุ/คนสุดท้าย/คลังสมาชิก หากปฏิเสธคืน profile เดิมทั้งก้อน ไม่บันทึกสภาพกึ่งกลาง
- บันทึกทีมปัจจุบันอัตโนมัติตามเดิม ปุ่ม “บันทึกเป็นชุดทีม” คงอยู่เหนือเมนูล่าง เพื่อเก็บ snapshot สมาชิก/ลำดับ/สำรอง/แนวเป็นชุดไว้เรียกใช้
- ช่องว่างเปิดหน้าต่างเลือกช่อง/ตั้งชื่อโดยยังไม่เขียนเซฟ กดบันทึกจริงจึงสร้างหรือบันทึกทับชุดเดิม ปุ่มระบุชื่อชุดเมื่อจะทับ
- คงการเปลี่ยนชื่อ ล้างชุด (ยืนยันก่อน) เรียกใช้ชุดเดิม คลังสมาชิก ปลดล็อกตามบท และการใช้ preset บนแผนที่
- Dialog อยู่ในกรอบเกม ใช้ focus ของ native modal, Escape ยกเลิก, ไม่รับการกดพื้นหลังหรือการยืนยันขณะ orientation gate บล็อกเกม
- เปิดจาก NPC ยังคงมีคำทักทาย แต่ย้ายไว้หลังแผนและชุดทีม เพื่อให้แผนอยู่บนสุดเสมอ
- ไม่แก้ `src/core/battle`, `src/core/save`, balance, save version หรือ schema ของ preset
