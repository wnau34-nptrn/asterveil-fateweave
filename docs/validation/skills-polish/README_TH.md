# Polish แท็บสกิล (2026-11-06)

เจ้าของสั่ง: (1) ช่อง "สกิลที่ติดตั้ง" ให้ไอคอนสกิลวาดเด่นและจัดรูปแบบสวย (2) ตัวอักษรผังสกิลใหญ่เกินไป ให้กลับเท่าเดิมก่อนแก้

- **ผังสกิล (สาเหตุ):** กฎที่ผมเพิ่มในกรอบกลุ่ม 2 (`#app .character-dialog .character-content :is(i, small) { font-size: max(1em, 12px) }`) ตีความ `1em` เป็นขนาดของ element แม่ ตัวอักษรเล็กทุกตัวในผัง (ชื่อโหนด ตัวนับ 0/2) ขยายตามแม่ → ลบกฎนี้ และคืนค่าเดิมของ `.tree-lv`, `.talent-node i`, `.tree-legend` (เหลือเฉพาะพื้นต่ำ 12px ของแท็บอุปกรณ์: `.doll-slot b, .tile-lv, .tile-plus, .swap-list small`)
- **ช่องสกิลที่ติดตั้ง:** ไอคอนวาดใหญ่ 56px (40–44px บนจอเตี้ย) กึ่งกลางช่อง มีแสงเรืองรอบไอคอน ชื่อ 13px/600 อยู่ใต้ไอคอน ช่องที่เลือกเป็นกรอบ/แสงทอง ช่องที่ยังไม่ใช้แสดงกรอบเส้นประ "ช่องว่าง" (ไม่ใช่ปุ่ม ไม่กระทบลาก/Alt+ลูกศร) กฎขนาดไอคอนเดิมของปุ่มใน `.character-content` (16px) ถูกชนะด้วยตัวเลือกที่หนักกว่า
- จอเตี้ย (`max-height:700px`) เดิมสลับเป็นแนวนอนจนชื่อแตกทีละตัวอักษร → คงแนวตั้งแบบกะทัดรัด
- ไม่เปลี่ยนเนื้อหา/กฎ/เซฟ/ตัวเลข
