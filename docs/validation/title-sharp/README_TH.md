# ภาพหน้าแรกคมขึ้น (2026-11-05)

ที่มา: เจ้าของแจ้งว่าภาพหน้าแรกบน iPhone ไม่คมชัด สาเหตุ: `title_bg.webp` เป็นภาพแนวนอน 1920×1080 แต่จอแนวตั้ง 390×844 (3x) แสดงเฉพาะแถบกลางกว้าง ~500 พิกเซลของภาพ แล้วถูกขยายเกือบ 2.4 เท่า ยิ่งมีขอบ −5% และเอฟเฟกต์ซูมของแอนิเมชันอีกราว 9% เบราว์เซอร์จึงขยายแบบเรียบ (เบลอ)

ทำแล้ว (ไม่เปลี่ยนภาพ/การจัดวาง): `scripts/build-title-portrait.py` ตัดแถบกลาง (อัตราส่วน 0.625 = เฟรมแนวตั้งที่กว้างสุด) ขยาย 2 เท่าด้วย Lanczos + unsharp เบา ๆ → `public/assets/title/title_bg_portrait.webp` (1350×2160, ~410 KB) ใช้เมื่อเฟรมเกมกว้างไม่เกิน 600px; ลดขอบเป็น −3% และซูมดริฟต์ 1.09 → 1.04; ไฟล์ต้นฉบับและจอกว้างไม่เปลี่ยน

ข้อจำกัด: ขยายด้วยอัลกอริทึมเพิ่มความคมของขอบได้ แต่ไม่เพิ่มรายละเอียดจริง ของจริงต้องให้ Codex ทำภาพแนวตั้งต้นฉบับ (≥1290×2796) — ยังไม่ได้ส่ง brief
