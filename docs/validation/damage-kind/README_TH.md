# ป้ายประเภทดาเมจที่ศัตรูจะโจมตี (กายภาพ / เวท) — 2026-11-05

เจ้าของขอสัญลักษณ์บอกว่าศัตรูโจมตีกายภาพหรือเวท และป้ายเตือนก่อนโจมตี เพราะหลายสกิลขึ้นกับประเภท; เจ้าของสั่งตัดป้ายที่มุมการ์ดฮีโร่ที่ถูกเล็ง (ไม่ทำ)

- **การ์ดเจตนาศัตรู** (`#intent`): ไอคอนวงกลมสีตามประเภท (กายภาพ = ดาบสีอำพัน · เวท = สายฟ้าสีม่วง), ขอบซ้ายเปลี่ยนสีตาม, และป้าย "กายภาพ"/"เวท" ข้างชื่อท่า (tooltip บอกวิธีรับ: กายภาพ ลดด้วยเกราะ/ท่าป้องกัน/แนวหน้า · เวท ลดด้วยต้านพลังงานและโล่พลังงาน ถึงแนวหลังได้) รูปทรง + คำ + สี ไม่พึ่งสีอย่างเดียว
- **คิวเทิร์น**: มุมล่างขวาของรูปศัตรูแต่ละตัวมีสัญลักษณ์ประเภทของการโจมตีที่ประกาศไว้ ให้เห็นล่วงหน้าหลายเทิร์น (aria-label ต่อท้าย "โจมตีกายภาพ/เวท")
- คำว่า "เวท" แทน "พลังงาน" ในการ์ดเจตนาและแผนรอบถัดไป (ค่าในกฎยังคือ `energy`); ท่าพิเศษ/สะสมพลังที่ไม่ทำดาเมจเองไม่มีป้าย
- เฉพาะการแสดงผล: ใช้ intent ที่ประกาศอยู่แล้ว ไม่เปลี่ยนกฎ/เซฟ/ตัวเลข; โมดูล `src/ui/damage-kind.ts`, สไตล์ท้าย `battle-skin.css`, เทสต์ `tests/damage-kind.test.ts`
