# แก้ภาพว่างก่อนโหลดเสร็จ — B1 + B2 + B3 + B6 (21 พ.ย. 2026)

เจ้าของ: “ไม่ต้องการให้คนเล่นเห็นว่าภาพเป็นช่องว่างก่อนที่จะโหลดภาพ อยากให้เข้าไปแล้วเห็นภาพแสดงเลย” → “ดำเนินการตามที่แนะนำ” (B2 + B3 + B1 และ B6 จาก[รายงานวิเคราะห์](https://github.com/wnau34-nptrn/asterveil-fateweave/blob/claude/image-blank-audit/docs/validation/image-blank-2026-11-21/README_TH.md)). แก้เฉพาะการโหลด/การแสดงผล — ไม่เปลี่ยนกติกา เซฟ เนื้อหา ตัวเลข หรือภาพ

## ผลวัด (Chromium emulation 390×844 DPR 3, 4G 9 Mbps/150 ms + CPU 4×, `vite preview` build Pages — ไม่ใช่มือถือจริง, ไม่ได้วัดบน Pages)

สคริปต์ [`scripts/blank.perf.ts`](scripts/blank.perf.ts) (สำเนาจากรายงานวิเคราะห์ + `shownMs` = กดแล้วหน้าจอใหม่ขึ้น, ข้อ 5b = อยู่หน้าชื่อเกม 6 s ก่อนกด); ทุกข้อกดปุ่มทันทีที่ปุ่มขึ้น. ผลดิบ `blank-{before,after}-{cold,warm}.json`

| หน้าจอ (เปิดครั้งแรก, cache ว่าง) | ก่อน: ภาพว่างตอนหน้าจอขึ้น / ครบเมื่อ | หลัง |
|---|---|---|
| ชื่อเกม | ภาพปาร์ตี้+โลโก้ว่าง / 5.0 s | ไม่มีภาพว่าง / 2.3 s (ภาพค่อยๆ ปรากฏ) |
| ค่าย | 12 ไฟล์ว่าง / 4.4 s (ขึ้นที่ 1.0 s) | ขึ้นที่ 2.7 s (ถึงเพดาน) เหลือว่าง 1 ไฟล์ (ท่านั่งฮีโร่) / 4.5 s |
| แผนที่ | ไทล์/ของประดับ/หมอกว่าง / 3.9 s | ไม่มีภาพว่าง / 1.3 s |
| ศึก (เปิดเซฟที่ค้างในศึก กดทันที) | พื้นหลังศึกว่าง / 6.4 s; ปุ่มเริ่ม 20.2 s | ไม่มีภาพว่าง / 1.6 s; ปุ่มเริ่ม 18.8 s |
| ศึก หลังอยู่หน้าชื่อเกม 6 s (5b) | ปุ่มเริ่ม 10.7 s | ปุ่มเริ่ม 7.8 s |

เปิดซ้ำ (มี service worker): ไม่มีภาพว่างทั้งก่อนและหลัง; ชื่อเกม 1.3, ค่าย 0.8–0.9, แผนที่ 1.1 s เท่าเดิม; ศึก ปุ่มเริ่ม 11.5 → 11.5 s (กดทันที), 10.5 → 7.6 s (5b).

**การ decode/อัป texture (B6)**: เปิดซ้ำ ไฟล์ศึกทั้งหมดมาครบที่ 0.8 s หลังกด แต่ปุ่มเริ่มพร้อมที่ 7.6 s → ราว **6–7 s เป็นงานบน CPU** (decode รูป + สร้าง/อัป texture + เตรียมฉาก) ที่ CPU 4× + WebGL ซอฟต์แวร์ (SwiftShader) — ไม่ใช่การดาวน์โหลด. ต้องวัดบนมือถือจริง ถ้ายังนาน ทางต่อไปคือ atlas เล็กลง (ต้องให้เจ้าของดูภาพ) หรือ decode ทีละไฟล์

ข้อจำกัดที่ยังเหลือ: ค่ายบน 4G ครั้งแรก ถ้ากดทันทีที่ปุ่มขึ้น ภาพ ~3 MB ยังมาไม่ทันในเพดาน 1.8 s — หน้าจอขึ้นตามเพดาน และภาพที่เหลือเติมตามมา. B4 (ภาพเบลอแทนช่องว่าง) และ B5 (ไฟล์เล็กลง) ยังไม่ทำ — ต้องให้เจ้าของดูภาพก่อน
