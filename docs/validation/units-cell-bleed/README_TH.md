# ภาพตัวอื่นหลุดเข้ามาในภาพเซเรน — 2026-11-04

เจ้าของรายงานจากเครื่องจริง (iPhone): หน้าตัวละครเซเรน (ภาพรวม/อุปกรณ์) มีลูกแก้วม่วงทางซ้ายและสีแดงด้านบน

## สาเหตุ

`public/assets/art/units.webp` (ทีมดั้งเดิม 6 ช่อง 512px) มีชิ้นภาพที่วาดเลยเส้นแบ่งช่อง: ลูกแก้วไม้เท้าของไอรา (ช่อง 2) ล้นเข้าช่องเซเรน (ช่อง 3) 6,688 พิกเซล, ไลรา (ช่อง 1) 410, ศัตรูช่อง 5 อีก 80 และมีชิ้นเล็กๆ ข้ามช่องอื่นอีกรวม 9,598 พิกเซล CSS (`.hero-art`) ตัดตามช่องถูกต้อง ชิ้นที่ล้นจึงโผล่ในภาพของตัวข้างเคียง atlas อื่น (`units_mercs`/`units_foes`/`units_foes2`) ตรวจแล้วไม่มีชิ้นข้ามช่อง

## การแก้

- `scripts/clear-cell-bleed.py`: ชิ้นภาพที่ต่อกัน (alpha > 8) เป็นของช่องที่มีพิกเซลของมันมากที่สุด พิกเซลของชิ้นนั้นที่อยู่ในช่องอื่น (และขอบจาง alpha ≤ 8 ติดกัน) ถูกล้างออก พิกเซลอื่นตรงเดิมทุกพิกเซล ตรวจซ้ำแล้วไม่มีชิ้นข้ามช่องเหลือ
- บันทึกแบบ lossless (682 KB → 1.98 MB) เพราะ lossy ซ้ำทำให้ทั้งแผ่นเพี้ยน (PSNR ~38.5 dB); ใส่ `?v=6263840f` ใน `artUrl` ให้เบราว์เซอร์โหลดใหม่ (`ART_REV` ใน `assets.ts`), ปรับ route pattern ใน `combat.spec.ts` ให้รับ query
- ภาพนี้ใช้ทั้ง UI (`heroArt`) และ spritesheet สำรองในศึก ทุกที่ได้ผลเดียวกัน
