# P05 — ความยากศัตรู: เปลือกบอส + ย้ายดาเมจจิกไปไว้ที่ท่าที่ประกาศ

14 พฤศจิกายน 2026 · สาขา `claude/p05-enemy-difficulty` · ตัวเลขทั้งหมดเป็นร่าง · ไม่แตะเซฟ ดาว หรือแต้มผัง (OD-01, OD-33)

## สรุป

1. **วัดก่อน:** casual ที่แนวรอยแยก #1 แพ้เพราะ **ผู้คุมรอยแยก** (ศึกบอสครั้งแรก 82% ของ casual rush เทียบ advisor 94%) และค่ายที่ **มาถึงบอสด้วยเลือดน้อย** (แพ้เกือบทั้งหมดเมื่อเข้าศึกที่ 54–82%) ไม่ใช่ขาดคำตอบ; explorer/casual ป่าทึบ #1 แพ้ที่ **ด่านจ่าฝูง** (บังคับ) และการเสียเลือดสะสม ทุกศึกบอส/อีลิทมีรูปเดียวกัน: ลูกน้องแถวหลังตีจิก (ดาเมจเล็ก ตอบไม่ได้) ทำให้ทุกสไตล์เสียเลือดเท่ากัน (~65–170 ต่อศึก) ส่วนท่าที่ประกาศของบอสคือสิ่งที่แยก advisor (เสีย 35–90) ออกจากการกดโจมตี (174–287)
2. **เจ้าป่าหนามแพ้การกดโจมตีเพราะทีมกดโจมตีชนะแบบเฉียด** (จบศึกด้วยเลือด 8–33% เทียบ casual 50–97%) ตัวเลข 83–98% เดิมรวมรอบเล่นซ้ำที่ Lv10 ครั้งแรกจริงที่ประตูแมพ 3 คือ 57% (rush) / 85% (explorer)
3. **แก้ (เฉพาะ encounter, ไม่มีกฎใหม่):**
   - **เปลือก (veilguard)** บนเจ้าป่าหนามและผู้คุมรอยแยกในโหมดปกติ: ตีลด 25% จนกว่าจะติดตรา (Aira, ได้ตั้งแต่บทนำทุกค่าย) กรด หรือสลายเวท ใช้ trait และตัวเลขเดิมของโหมดยาก (`progression.hardTraits`) ข้อความสถานะมีอยู่แล้ว
   - **ย้ายดาเมจจิก → ท่าที่ประกาศ:** วิญญาณรอยแยกของผู้คุม 70%; ภูตแดนดิไลออนของจ่าฝูง −25% และท่าพุ่งของจ่าฝูง +25%; ลิงซ์หนามพราง −20% และท่าของเจ้าป่าหนาม ~+10% (Bloom 22→24, Storm 27→30, Lash 22→24, 24→26; Tempest 28 เท่าเดิม)
   - `elite-briar-lord` v10→11, `elite-tusk-chief` v7→8, `rift-warden` v20→21 (ศึกที่ค้างจากเวอร์ชันเก่าถูกปฏิเสธตามกลไกเดิม)
4. **ผล (แคมเปญ 48 ค่าย casual / 12 ค่าย advisor):** casual rush แนวรอยแยก #1 **71 → 79%**, explorer/casual ป่าทึบ #1 **58 → 71%**, advisor rush แนวรอยแยก #1 83 → 92%; การกดโจมตีบอสป่า 42–71% → 0–46% และประตูแมพ 3 ครั้งแรก 57/85% → 23/65%

## วิธีวัด

- **Bench ศึกบอส** (`tests/probe/p05-bench.test.ts`): เก็บสถานะก่อนเข้าศึกบอส/อีลิทจริงจากแคมเปญ casual 48 ค่าย × rush/explorer (ครั้งแรกของแต่ละแมพ, `BENCH_CAPTURE`) แล้วเล่นศึกเดียวกันซ้ำแบบกดโจมตี / advisor / casual 4 ชุดสุ่มเทิร์น (`BENCH_IN`, ตัวเลือก `playOut(…, salt)` ใหม่; salt 0 = ผลแคมเปญเดิมทุกบิต) ~13 วินาทีต่อรอบ ใช้ทดลองตัวเลข; `keep` = เลือดที่เหลือ/เลือดตอนเข้า ของ casual
- **Trace** (`p05-trace`): ดาเมจที่โดนแยกตามศัตรูแต่ละช่อง; **entry** (`p05-entry`): ผล casual เทียบเลือดตอนเข้า; **probe** (`p05-probe`): ศึกที่แพ้ของค่ายที่ไม่ผ่านครั้งแรก
- ยืนยันด้วยแคมเปญเต็ม (`SIM_REPORT=1 vitest run tests/campaign-sim.test.ts`) และชุด sim ที่เหลือของ `npm run sim`
