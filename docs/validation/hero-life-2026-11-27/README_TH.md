# ฮีโร่มีชีวิตชีวาในฉากต่อสู้ (โค้ดอย่างเดียว) — 2026-11-27

เจ้าของสั่ง “เปิด session ใหม่ ทำ ข้อ 1, 2, 3 และ 6 ได้เลย” รอบแรกทำท่าตามอาชีพ เอนตามสกิล และกระโดดตอนชนะ เจ้าของดูคลิปแล้วบอกว่า “มันตลกอ่ะ” (ภาพนิ่งแผ่นเดียวที่โดนยืด โยก กระโดด ดูเป็นตุ๊กตายาง) จึงเลือกแนวทางที่แนะนำ: “เก็บข้อ 3 ไว้ เอาเข้าเกมได้” และ “ทำตามที่คุณแนะนำ” ท่าจริงให้ Codex วาด (ART-UNIT-ANIMATION-LIFE-001, brief `docs/handoffs/CODEX-HERO-LIFE-TH.md`)

สิ่งที่อยู่ในเกม (งานภาพอย่างเดียว ตัวเลขร่าง):

| เรื่อง | ทำอะไร | โค้ด |
|---|---|---|
| หายใจ | ยืด scaleY 2.2% / หด scaleX 0.8% รอบละ ~3.6 วิ เหมือนเดิมทุกอาชีพ คำนวณทีละเฟรม ไม่มี tween วน | `src/game/visuals/hero-life.ts` |
| เลือดต่ำ | ต่ำกว่า 30% (`LOW_HP`) หายใจช้าลง 1.5 เท่า (เหนื่อย) ไม่มีการห่อหรือเอนตัว | `applyLife()` ใน `BattleScene.ts` |
| โล่ | `barrier > 0` ใน state ที่แสดง: วงแสงฟ้าบางๆ เต้นช้า | `barrierGlow` |

| ชนะ | ประกาย 4 แฉกขึ้นเหนือหัวฮีโร่ที่ยืนอยู่ทีละคน ตัวไม่กระโดด | `BattleScene.finish()` |
| แพ้ | ทุกคนทรุดลง 4px และจางลงเล็กน้อย | `slump()` |
