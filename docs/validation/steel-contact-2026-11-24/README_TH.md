# ภาพและเสียงจังหวะปะทะ — โจมตีปกติของ Duelist และ Execute

เทียบกับ `b39ed8d`. โจมตีปกติของ Duelist และ Execute เลื่อนเสียงเหวี่ยงให้ใกล้ contact cue เดิม. เสียงโดนและเสียงหนักยังเล่นตาม event ที่ contact. เมื่อโล่รับการโจมตีสายกายภาพทั้งหมด ใช้เสียงกระทบโล่สั้นเพื่อแยกจากเสียงเวทที่สร้างโล่. ถ้ายังเสีย HP ใช้เสียงโดนเดิม.

| ระยะเวลาตามตัวตั้ง ก่อน contact | ก่อน | หลัง |
|---|---:|---:|
| โจมตีปกติ · Normal | 210 ms | 145 ms |
| โจมตีปกติ · Fast | 137 ms | 137 ms |
| Execute · Normal | 298 ms | 145 ms |
| Execute · Fast | 194 ms | 145 ms |

Execute ใช้ภาพเดิม. ข้อความผลการโจมตีอยู่หน้าเอฟเฟกต์. เมื่อถูกโล่รับเต็ม ใช้ประกายสีมุกแทนการซ้อนกับเงาและสะเก็ดปะทะ. เมื่อหลบและเปิด OS reduced motion ขึ้นข้อความหลบโดยไม่มีประกายโดน. เวลาเทิร์น, resolver, เซฟ v68, skip และการตั้งค่าเสียงยังใช้ระบบเดิม.

## หลักฐาน

เก็บภาพ 390×844 ใน Chromium จาก BattleUI, Phaser และ resolver ภายใน fixture ใช้ CDP timestamps สำหรับวิดีโอ และดักเสียงจากปลายทาง Web Audio สำหรับคลิป SFX. กรณีโล่และหลบในคลิปเกิดจากศัตรูโจมตีตัวละครที่เตรียมโล่/หลบใน fixture. กรณี Execute ถูกหลบใน OS reduced motion ตรวจด้วย event ทดสอบที่ renderer. คลิปปิด SFX ได้สัญญาณ PCM เงียบ. เวลาที่จับจากเบราว์เซอร์ผันผวนตามการวาดภาพและภาระเครื่อง การอนุมัติภาพ/เสียงและการฟังบนมือถือจริงยังรอการตรวจ.

## ผลทดสอบ

Typecheck, lint และ production Pages build ผ่าน. Vitest 2,270 ผ่านและข้าม 24. เทสต์ boss-balance ที่หมดเวลาในชุดรวมผ่านเมื่อรันแยก. Playwright ผ่าน 19 กรณีจาก production build สำหรับ Execute, โหมดและการข้ามแอนิเมชัน, การคงคำสั่งเดิม และการตั้งค่าเสียง. เทสต์ VFX แบบ fixture ผ่าน 5 กรณี รวมโจมตีปกติ, โล่, หลบ และ Execute ใน OS reduced motion.
