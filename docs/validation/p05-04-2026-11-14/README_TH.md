# P05-04 — พัก/สำรอง/ความเสี่ยง ถอนตัว/แพ้ และรางวัลโหมดยาก

14 พฤศจิกายน 2026 · สาขา `claude/p05-04-hard-rewards` · วัดก่อน แก้หนึ่งจุด (กฎ hard trait) · ไม่แตะเซฟ บทลงโทษแพ้/ถอนตัว (OD-11) หรือตัวเลขรางวัล

เจ้าของยังไม่ตอบคำถาม P04-05 (บอสป่าทึบแพ้การกดโจมตีน้อยลงสำหรับค่าย rush) จึงไม่เปลี่ยนส่วนนั้น

## สรุป

1. **พัก/สำรอง/ความล้า (A6c):** วัดและแก้แล้วใน [P04-05/06](../p04-05-2026-11-14/README_TH.md) (EXP ไล่ตาม, ไฟแคมป์ 70%) ไม่มีอะไรเพิ่ม
2. **แพ้/ถอนตัว:** คงตาม OD-11 การล้มทั้งทีมเกิดน้อย (probe 24 ค่ายต่อแบบ: ปกติครั้งแรก casual rush 8%, ยาก #1 4%; รายงาน 48 ค่าย: ยาก #1 2%) แพ้บอสยากส่วนใหญ่แค่ถอยกลับแคมป์แล้วส่งสำรองไปใหม่ ค่าล้มทั้งทีม (เก็บแร่/ทอง/ตำรา 50% และของ 1 ชิ้น) หนักแต่หายาก
3. **ความยากของโหมดยาก (bench ต่อครั้งที่สู้, casual 48 ค่าย):** บอสยาก (ผู้คุมรอยแยก) เป็นศึกจริง และง่ายขึ้นเมื่อเล่นซ้ำ — ตรงกับ OD-35

   | เล่นปกติซ้ำก่อน | rush casual / advisor | explorer casual / advisor | กดโจมตี |
   |---|---|---|---|
   | 0 ครั้ง | 22% / 55% | 75% / 90% | 0–2% |
   | 1 ครั้ง | 79% / 91% | 96% / 97% | 2–6% |
   | 3 ครั้ง (รายงานแคมเปญ) | 98% / 100% | 100% / 100% | 4–15% |

   หมายเหตุ: ตาราง "Battle / Fought / Won" ในรายงานแคมเปญนับ *ทุกครั้งที่สู้* หลังเล่นซ้ำสามรอบ จึงดูเหมือนบอสยากง่าย รายงานที่ `npm run sim` เขียนจริงคือ `docs/validation/roster-30/batch-1/CAMPAIGN.md` (`balance-sim/CAMPAIGN.md` ค้างตั้งแต่ 8 พ.ย. — ใส่ป้ายแล้ว)
4. **พบข้อบกพร่อง:** `hardEncounter` *แทนที่* trait ของศัตรูด้วย trait โหมดยาก ยักษ์หิน (มินิบอส) จึงเสีย `veilguard` ที่ P05-03 ใส่ไว้ (สุ่มได้ enrage, veilguard ไปตกที่ผู้ถักแทน) กดโจมตีชนะยักษ์หินบนโหมดยากง่ายกว่าโหมดปกติ
   - **แก้:** trait โหมดยาก *เพิ่ม* เข้าไปกับ trait เดิม (`world.ts` `hardEncounter`); มีผลเฉพาะ `mini-veil-golem` (v10→v11) — ผู้คุมรอยแยกและเจ้าป่าหนามได้ชุดเดิมอยู่แล้ว
   - ยักษ์หินบนโหมดยาก กดโจมตี: rush 25→11%, explorer 68→58% (ไม่เล่นซ้ำ); 80→61% / 98→88% (เล่นซ้ำ 1); casual/advisor 100% เท่าเดิม แคมเปญ (หลังเล่นซ้ำ 3) mini:attack 100→97%
5. **รางวัลโหมดยากเทียบเล่นปกติซ้ำ (probe 24 ค่ายต่อแบบ, ก้าวเท่ากัน):** แร่/ทองเท่ากัน (rush ~143/76, explorer ~489/271), ตำรา +2 (rush 11→13, explorer 24→26), แกนรอยแยก +1 (กุญแจสกิล Lv5), ของมหากาพย์ขึ้นไป +0.5–1.5 ชิ้น และครั้งแรกโหมดยาก 30 ทอง + 20 เศษสากล ส่วนเพิ่มเล็กแต่ตรงเป้า (แกน = ทางไปสกิล Lv5) และความเสี่ยงต่ำ จึง **ไม่เปลี่ยนตัวเลข**
