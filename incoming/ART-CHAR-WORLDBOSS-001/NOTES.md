## รันซ้ำและตรวจรับ

ใช้ Python 3 + Pillow 12.3.0 จาก repo root:

```sh
python -I incoming/ART-CHAR-WORLDBOSS-001/build_handoff.py
python -I incoming/ART-CHAR-WORLDBOSS-001/build_handoff.py --verify
```

สคริปต์เขียนเฉพาะโฟลเดอร์นี้ การ build ต้องมี reference ของสาขาฐาน; `--verify` ใช้ package อย่างเดียวได้ เก็บผล generator เดิมไว้เพราะเครื่องมือไม่เปิด numeric RNG seed (seeds.json จึงไม่แต่งค่า seed สุ่มขึ้นมา) การประมวลผลซ้ำ deterministic ภายใต้ Pillow เวอร์ชันเดียวกัน ไม่รับประกันว่าสุ่มสร้างภาพใหม่จะได้พิกเซลเดิม

Normalize ด้วย uniform scale ไม่ยืดสัดส่วน/ไม่ mirror: anchor จากขอบ alpha>32, เท้าที่ y≈896; เก็บ RGB/alpha เดิม ยกเว้นกำจัด haze alpha≤8 และ resize Lanczos ตรวจขอบด้วย alpha>0 และ >32 แยกกัน

ตรวจ SHA/byte length, decode PNG เต็มทุกไฟล์, alpha มีทั้ง 0/255 และขอบโปร่งใสบางส่วน, ขอบว่างอย่างน้อย 32px, sole y=894–898, mask ของบอสไม่ทับตัวอื่น/แถบ HP ใน mockup และสูงกว่าบอส baseline ทั้งสอง การหันซ้าย กายวิภาคและไม่มีข้อความตรวจด้วยตา ไม่ได้อนุมานจาก bbox ลองเรียก `scripts/unit-anatomy-audit.py` แล้วเครื่องนี้ขาด opencv-python-headless จึงไม่มีผล automated anatomy pass; สคริปต์นั้นเทียบเฟรมการเคลื่อนไหวและยังใช้รับรองชุดท่าจาก seed เดี่ยวไม่ได้ รอบนี้ใช้ visual review เท่านั้น

`validation.json` ไม่ hash ตัวเองเพื่อหลีกเลี่ยง self-reference; SHA ของ manifest ระบุใน PR เป็น receipt หลัง push ต้อง fetch จาก remote กลับมาเข้า object database ใหม่และรัน `--verify` อีกครั้ง ไม่ใช้ local working copy เป็นหลักฐาน remote
