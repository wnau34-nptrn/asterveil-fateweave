## ภาพร่างกาย

ภูตธาราหันซ้ายตลอด ภาพเน้นมงกุฎเงินรูปจันทร์เสี้ยว ใบหน้าที่ก้มเศร้า ผ้าคลุมน้ำสีฟ้าอมเขียว และรอยร้าวม่วงจางที่อก ไม่มีอุปกรณ์ถือ ทุกเฟรมคงมงกุฎและผ้าคลุม ส่วนคลื่นหรือแสงของท่าอยู่ในเลเยอร์ VFX

`seeds/sentinel-cell8.png` คือต้นแบบสเกลที่ตัดจากช่อง 8 ของ `public/assets/art/units_foes.webp` ส่วน `seeds/water-spirit-idle.png` คือภาพตั้งต้นที่สร้างใหม่ในกรอบ 1024 × 1024 ขนาดร่างยืนอิงความสูงส่วนทึบของ Sentinel เมื่อใช้กรอบสองเท่าแบบบอส จุดยึดคือ (512, 896) และแกนพื้นคือ 896/1024 ตาม `BOSS_SOLE` ฝั่งซ้ายเป็นทิศออกท่า ภาพย่อในกรอบเรนเดอร์ใช้ `displayRatio: 2` ตามบอสอ้างอิง

`raw/` มีแถบแนะนำ 6 ท่าและแถบทางเลือก 3 แถบ รวม hit 2 เฟรม และ down 3 เฟรม แต่ละไฟล์เป็นแถวเดียว มีช่องว่างโปร่งใสจริง 80 px ระหว่างเซลล์ 1024 px ทุกเซลล์ เฟรมท่าเรียง wind-up → anticipation → contact → follow-through ใช้ idle ที่ต้นและท้ายตาม `bossMove` เฟรม 0 เป็น idle และเฟรม 29 เป็นท่าล้มค้างตามผังที่เสนอใน `strips.json`

## VFX และ storyboard

`vfx/` มี 12 PNG ขนาด 256 × 256 RGBA เฟส prepare → peak → settle ของแต่ละท่า พิกัด pivot เป็นพิกเซลจากมุมซ้ายบนของแผ่น ขนาดแสดงผลเป็นความกว้างของแผ่นรวมขอบใสที่จอ 390 px เวลาเป็นข้อเสนอด้านภาพสำหรับ Claude ให้ผูกกับจังหวะและเหตุการณ์จริงของเกม

| ท่า | จุดยึด | เตรียม / พีค / จบ | แผ่นบนจอ 390 px |
| --- | --- | --- | --- |
| Water Veil | กลางตัวบอส (128, 133) | 200 / 180 / 220 ms | 144 / 156 / 130 px |
| Surging Wave | เท้าเป้า (167, 211) | 170 / 120 / 220 ms | 74 / 94 / 76 px |
| Great Wave | ทั้งฝั่งฮีโร่ แผ่นย่อยที่เท้าแต่ละเป้า (128, 211) | 140 / 210 / 220 ms ต่อแผ่น เริ่มเหลื่อม 42 ms | 93 / 104 / 94 px ก่อนคูณตัวลดขนาด |
| Reflection | เท้าของเงาในช่อง b2 (128, 214) | 170 / 180 / 240 ms | 67 / 80 / 73 px |

- **Water Veil** เริ่มด้วยสายน้ำหยกเปิดกลาง หยดน้ำไต่ขึ้นข้างลำตัว และมือประคองเข้าหาตัว สีเขียวหยกกับสายน้ำที่เปิดและยกตัวช่วยแยกจาก Ward ฟ้าเงินที่โอบปิด ให้ peak แสดงเมื่อเกิดการฟื้นเลือดจริง ถ้าถูกผนึกให้หยุดที่ภาพเตรียม
- **Surging Wave** ใช้รูปยอดคลื่นสูงสีคราม หันสันกระแทกทางซ้าย เป้าตามเหตุการณ์จริง ยอดคลื่นเยื้องไปทางซ้ายในแผ่นเพื่อให้เห็นข้างตัวละคร
- **Great Wave** ใช้ริ้วกวาดเตี้ยสีฟ้าอมม่วง เริ่มจากเป้าด้านหน้าไล่ไปด้านหลังใน storyboard ย่อขนาดแต่ละเป้าตามลำดับ 100%, 91%, 80%, 70%, 60% การเหลื่อมใช้กับภาพเท่านั้น ผูกการปะทะและตัวเลขกับเหตุการณ์จริง
- **Reflection** เริ่มด้วยผิวน้ำแตก ยกเศษกระจกน้ำไว้ข้างช่องให้เงาปรากฏตรงกลางเมื่อเกิดเหตุการณ์เรียกเงาจริง

`storyboard-390.png` อ่านบนลงล่างตามลำดับตาราง VFX ท่าละสามช่อง ใช้ฉากรอยแยกและตัวละครอ้างอิงจาก branch ต้นทางเพื่อทดสอบพื้นที่วางภาพ ตัวจำลองวางเอฟเฟกต์หลังตัวละครและป้าย HP และกันพื้นที่ใบหน้า แถบ HP และตัวเลขลอยด้วยมาสก์ ในภาพไม่มีป้ายข้อความหรือตัวเลข ใช้ตำแหน่งมาสก์เป็นหลักฐานแบบออฟไลน์ ให้ตรวจซ้ำกับ HUD จริงตอนนำเข้า

## ทำซ้ำและตรวจไฟล์

ใช้ Python 3 พร้อม Pillow, NumPy และ opencv-python-headless จาก checkout ที่มีฉากรอยแยก แอตลาสอ้างอิงสี่ไฟล์ใน `public/assets/art/` และ `scripts/unit-anatomy-audit.py`

```bash
python3 incoming/ART-UNIT-ANIMATION-LAKE-BOSS-001/build_handoff.py
python3 incoming/ART-UNIT-ANIMATION-LAKE-BOSS-001/build_handoff.py --verify
```

`sources/` เก็บภาพต้นทาง ImageGen ตามที่ได้มา `prompts.json` เก็บคำสั่งที่ส่งจริง และ `source-layout.json` เก็บช่องตัด จุดพื้นและสเกลร่วมของแต่ละแถบ สคริปต์ตัดแถบ กรอง alpha ชายขอบและปรับสเกลร่วมทั้งแถบ เฟรมล้มรักษาระดับต่ำของท่าไว้ `validation.json` บันทึกผล anatomy audit ของ idle และทุกเฟรมรวมตัวเลือก ผลวัดพื้นที่กัน HUD และ SHA-256 ของไฟล์ทั้งหมดในชุดยกเว้นตัว manifest เอง
