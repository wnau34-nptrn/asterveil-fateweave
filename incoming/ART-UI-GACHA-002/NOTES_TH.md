# ส่งต่อภาพกาชา ART-UI-GACHA-002

วันที่9พฤศจิกายน2026 (Asia/Bangkok) เจ้าของขอ “นำภาพที่อนุมัติเข้า Github ไว้อ้างอิง” หลังปรับวงแหวนดาวเสาร์และการแยกเศษ/ตัวละคร งานนี้เก็บภาพเพื่ออ้างอิง ไม่ใช่คำสั่งนำเข้าระบบจริง

## สิ่งที่ยึดจากคำขอเจ้าของ

- ใช้ธีมเดียวกับเกมปัจจุบัน: navy/champagne/cyan, Kanit/Noto Sans Thai และตัวละครchibi
- artworkหน้ากาชาใหม่: แท่นทอชะตา ผลึกกลางและเส้นแสง สร้างจากภาพเกมนี้เป็นภาพอ้างอิง
- ผลสุ่ม10ครั้งเป็นวงแหวนเอียงเหมือนดาวเสาร์ ตั้งใจให้ลากหมุนได้ ไม่ใช้ตารางเป็นแบบหลัก
- ต้องเห็นทันทีว่าอันไหนเป็นตัว/เศษ: ตัวเต็มใช้การ์ดสี่เหลี่ยมเห็นตัวเต็ม; เศษใช้ผลึกแตก มีใบหน้า/คำว่าเศษ/จำนวน; ตัวซ้ำแสดงเศษที่แปลงแล้ว
- ภาพนิ่งยังไม่พิสูจน์การลากจริง ลำดับโคจร การเลือกหน้า/หลัง occlusion หรือจำนวนทุกชิ้นในเฟรมที่สร้าง ต้องderiveจากรายการผลจริงตอนimplementation ไม่อ่านจำนวนจากภาพ

## สถานะการอนุญาต

คำสั่งเก็บภาพเป็นการอนุญาตบันทึกชุดอ้างอิงนี้ ไม่ใช่อนุมัติทุกข้อความ/ตัวเลข/การ์ดในภาพเป็นproduction spec และไม่ใช่อนุมัติmotionที่เล่นจริง ยังไม่ได้เพิ่มกาชา/แก้เกมจริง

เจ้าของระบุในแชตว่าจะค่อยปรับตัวเลขภายหลัง ให้คุย/วางระบบก่อน; เมื่อเกมเสร็จจะมีครบทุกหมวดและfeature จึงใช้ภาพรวมเกมที่มีครบเป็นฐานเศรษฐกิจ80–96 ไม่ตีความว่าโหมดที่ยังไม่เปิดต้องถูกตัดทิ้งจากระบบสุดท้าย เป้า7–10ครั้งยังเปิดให้ทบทวน ไม่ใช่เกณฑ์ตายตัวจากภาพ

## สำหรับงานพัฒนาภายหลัง

- ใช้main-screen.pngเป็นทิศทางศิลป์ล่าสุดและsaturn-ring-reward-types.pngเป็นหลักของผลสุ่ม ไม่คัดลอกmockupเป็นภาพUIทั้งหน้า
- สร้างUIจากstateจริง: จำนวนตั๋ว/แต้ม/ราคา/ชื่อ/ผลซ้ำ/เศษทุกช่อง; ข้อความต้องเป็นDOMอ่านง่าย ไม่ฝังตัวเลขจากภาพ
- วงแหวน: ลากซ้ายขวา/ปุ่มลูกศร, snapช่องหน้า, keyboard/reduced motion; รูปรางวัลแยกด้วยshape+ภาพ+label ไม่พึ่งสีอย่างเดียว
- ผูกผลที่บันทึกสำเร็จแล้วกับการแสดง; เปิด/ข้าม/ลาก/reloadไม่สุ่มใหม่หรือแจกซ้ำ
- storyboardเป็นภาพนิ่งเสนอประมาณ2.4วินาที ไม่ใช่คลิปหรือsprite sheetพร้อมโหลด; เอฟเฟกต์โปร่งใสเป็นภาพวัตถุรวม ยังต้องแยกชั้น/pack/ทดสอบตามขอบเขตที่ได้รับต่อไป
- Corinเป็นตัวเต็ม, portraitshardsเป็นเศษเฉพาะ, เศษกลางไม่มีหน้าตัวละคร; สีแสงไม่เพิ่มSR/SSR
- ทดสอบ390pxและinteractionจริงก่อนกล่าวว่าใช้งานได้; owner visual/motion reviewของงานในเกมยังแยกจากผลdecode/CI
