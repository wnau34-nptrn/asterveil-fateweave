| ช่วงเฟรม | ภาพ | ลำดับท่า |

| 0 | Idle | ท่ายืนที่อนุมัติ |

| 13–16 | Undertow R1 | โน้ม → เอื้อมต่ำ → กระชากกลับ → ตั้งตัว |
| 17–20 | Great Wave R1 | เปิดแขน → กางแขน → กวาดไปซ้าย → ตามแรง |

แถบใน `raw/` มีหนึ่งแถวและช่องโปร่งใส 80 พิกเซลระหว่างเฟรม เซลล์ 1024×1024 พิกเซล จุดยึดที่ (512, 896) และเส้นพื้น y=896 ใช้สเกลเดียวกันทุกเฟรมในแต่ละแถบ โพสลงต่ำคงการลดระดับของตัวละคร ทั้งชุดหันซ้าย ใช้ผังเฟรม VFX และจังหวะของ PR #345 ชุดนี้ส่งภาพร่างกายให้ตรวจ motion ก่อนนำเข้า

ดู [เฟรมทุกท่าที่ความกว้าง 390 พิกเซล](preview-390.png) และ [พิกัดเซลล์](strips.json) ไฟล์ `sources/` เก็บภาพสร้างต้นฉบับ ส่วน `source-layout.json` ระบุขอบตัดและการตั้งสเกล ใช้ Pillow รัน `python3 -I build_handoff.py` เพื่อสร้างแถบ seed และไฟล์ SHA-256 ซ้ำ

## ตรวจชุดภาพก่อนนำเข้า

- สคริปต์ตรวจสัดส่วนจับจุดอ้างอิงศีรษะได้ครบ 29 เฟรมเคลื่อนไหว ทุกเฟรมอยู่ในช่วงคลาดเคลื่อนไม่เกิน 12% ของท่ายืน ค่ามัธยฐาน 0.938 [รายงานสัดส่วน](anatomy-audit.json)
- ทดลองย่อเฟรมเป็น 768×768 และบรรจุแบบ lossless ด้วยการเรียง 5 แถวตาม [packing.json](packing.json) ได้ atlas 1979×1974 พิกเซล หรือ 14.90 MiB หลัง decode ตรวจประกอบกลับจาก atlas ตรงทุกพิกเซลที่มองเห็น การเรียงแถวนี้ช่วยผ่านเพดานด้านละ 2048 px เมื่อใช้ตัวแพ็กเดิมแล้วหาผังที่พอดีไม่เจอ
