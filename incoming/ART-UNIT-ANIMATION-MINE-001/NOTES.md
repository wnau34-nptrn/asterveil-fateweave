# ศัตรูเหมืองผลึกร้างห้าตัว · รอบที่ 2

สไปรต์ร่างกาย semi-chibi หันซ้าย ใช้เส้นขอบเข้ม สีอิ่ม เงา cel และแสงขอบเพื่อให้อ่านบนพื้นถ้ำมืด ค้างคาวใช้สีม่วงและผลึกมรกต โกเลมใช้แร่ทองแดงและสนิม คนงานหลังค่อมถือจอบ หัวหน้าคุมเหมืองตัวใหญ่ที่สุด และตัวกินผลึกเป็นสัตว์สี่ขากรามใหญ่

- `strips.json` ใช้ cell 512×512 และจุดอ้างอิงพื้น y=497 พัก 0, ตี 1–8, สกิล 9–16, hit 17–18, down 19–21 ค้างคาวเพิ่ม hover 22–25 และลดระดับเมื่อร่วง ตัวที่มีท่าเดียวใช้ท่าพักเป็น fallback ในช่องสกิล คนงานก้มจอบลง คุกเข่าวางจอบ และชูมือยอมแพ้ในเฟรม 19–21
- `raw/` เก็บภาพต้นทางแบบแยกท่า ชุดที่เครื่องมือส่งมาพร้อมพื้นจำลองผ่านการแยก alpha ก่อนแพ็ก `pose-scale.json` เทียบสเกลกายวิภาคกับท่าพัก `strips/` ใช้หนึ่งแถวต่อท่า ภาพร่างกายมีเฉพาะตัวละครและอุปกรณ์
- `seeds/overseer-r2.png` เป็นแบบหมวกเหล็กและผลึกฝังไหล่ `seeds/eater-r2.png` เป็นแบบตุ่นยักษ์เล็บขุด ภาพเทียบอยู่ใน `preview/elite-variants-390.png` คอลัมน์ซ้ายเป็น R1 ที่ใช้ในแอนิเมชัน คอลัมน์ขวาเป็นภาพนิ่งแบบ R2
- `preview/field-00-390.png` เป็นภาพประกอบ 390×844 ในฉาก `bg_mine` จาก PR #357 พร้อมฮีโร่ห้าคน มี GIF สำหรับท่าตี สกิล และ hover ใน `preview/`
- สร้างซ้ำจาก repository ด้วย `python3 build.py` โดยติดตั้ง Pillow, NumPy และ OpenCV สคริปต์รัน `scripts/unit-anatomy-audit.py` ให้ครบห้าตัวก่อนสร้าง `validation.json` ผลตรวจรายเฟรมอยู่ใน `anatomy/`
- รอเจ้าของเลือกแบบและอนุมัติ motion ภาพสนามเป็น preview สำหรับตรวจรับก่อนนำ asset เข้าเกม

## รอบที่ 3 · 2026-11-26

- เจ้าของเลือกหัวหน้าคุมเหมือง R2 และตัวกินผลึก R1 สีม่วง ภาพพักของหัวหน้าคุมเหมืองใช้ `seeds/overseer-r2.png` โดยตรง ภาพ ImageGen จากต้นแบบนี้ใน `raw/overseer-*.png` ให้ครบ 22 เฟรม รวมเฟรมพัก หมวกเหล็กและผลึกฝังไหล่อ่านออกทุกเฟรมที่ตรวจ
- หันซ้ายตามต้นแบบ เท้า y=497 ใน cell 512×512 สเกลภาพพักสูง 402 พิกเซลตามรอบ 2 ตรวจการย่อที่ 390 พิกเซลในฉาก `bg_mine` กับฮีโร่ห้าคน ภาพ `field-13-390.png` เพิ่มจังหวะ Crystal Spark และ GIF แสดงลำดับตีและสกิล
- รัน `python3 build.py --overseer-only` เพื่อทำซ้ำรอบนี้และตรวจด้วย `scripts/unit-anatomy-audit.py` รายงาน `anatomy/overseer.json` วัดครบทุกเฟรม ค่ามัธยฐานสเกลศีรษะ 0.961 ศัตรูอีกสี่ตัวใช้ไฟล์รอบ 2
