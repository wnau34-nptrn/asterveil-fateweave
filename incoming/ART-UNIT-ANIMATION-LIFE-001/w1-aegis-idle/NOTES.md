# เอกิส W1 · ท่ายืนวนลูปจาก seed

ท่านำร่อง 8 เฟรมที่ 400 ms ต่อเฟรม วนรอบละ 3.2 วินาที สร้างจากพิกเซล seed เดิมด้วยสคริปต์ Python โดยตรง เฟรม `000.png` เป็นสำเนาไฟล์ต้นฉบับทุกไบต์

## สร้างซ้ำจากราก repository

```sh
python3 incoming/ART-UNIT-ANIMATION-LIFE-001/w1-aegis-idle/tools/warp_idle.py --seed incoming/ART-UNIT-ANIMATION-A2-001/aegis-seed.png
```

สคริปต์อ่าน mask ที่ส่งมาด้วย ใช้ Pillow 12.3.0 และ NumPy 2.3.5 ตอนสร้างและทดสอบสร้างซ้ำ ผล PNG, WebP และ metadata ตรงกันทุกไบต์เมื่อใช้ชุดไลบรารีเดียวกัน

## การเคลื่อนไหวและผลวัด

ใช้ mask ระดับเทา 8 บิต ลาดน้ำหนักราว 9 px รอบขอบของแต่ละบริเวณ ดึงพิกเซลย้อนตามสนามการเคลื่อนที่แบบคาบเดียวด้วย bilinear sampling และ premultiplied alpha ช่วงหัวขยับเฉพาะส่วนยอดผมและปอยที่แยก mask ไว้ ช่วงอกและไหล่ใช้บริเวณผ้าและรอยต่อเพื่อให้หน้า ตา และผิวแผ่นเกราะหลักนิ่ง ดาบ โล่ มือ ขา เท้า และขอบแคนวาสทั้งสี่ด้านอยู่นอก mask เศษสีเล็กที่ขอบขวาจาก seed จึงยังอยู่ตำแหน่งเดิม

| ส่วน | ขยับสูงสุด (px) | ขีดจำกัด (px) |
| --- | ---: | ---: |
| อกและไหล่ | 3.0000 | 3 |
| ส่วนหัว | 2.0000 | 2 |
| ปอยผม | 2.6401 | 3 |
| ขอบผ้าคลุม | 3.6000 | 4 |
| ปลายผ้า | 3.2000 | 4 |

ปอยผมตามหลัง 1/8 รอบ และผ้าตามหลัง 1/4 รอบ ฟังก์ชันกลับสู่ตำแหน่ง seed ที่เฟส 1 พอดี โดยส่งเฟส 0 ถึง 7/8 สำหรับการวนต่อ เนื้อภาพนอก mask เปลี่ยน 0 พิกเซลทุกเฟรม `diff/` ทำสีเฉพาะจุดที่ค่า RGBA ต่างจาก seed

## ตรวจคุณภาพ

- รัน `python3 scripts/unit-anatomy-audit.py --cells incoming/ART-UNIT-ANIMATION-LIFE-001/w1-aegis-idle/frames` แล้ว Median และค่าสูงสุด 1.000 วัดได้ทุกเฟรม
- เปิด WebP วนใน Chromium และตรวจภาพจากการเล่นจริงที่ 400 และ 200 ms ต่อเฟรม รวมรอยต่อ 8→1 ตรวจขอบที่ขนาด 512 px บนพื้นเข้ม และตัวอย่างสูง 111 px บนพื้นอ่อน ไม่เห็นขอบซ้อน ฉีก หรือ halo ใหม่
- ตัวอย่าง 111 px ใช้กรอบครอบร่วมกันทุกเฟรมและย่อตามความสูงของร่างใน seed เพื่อให้จุดยึดนิ่ง
- งานนำเข้าและการเล่นในเกมยังไม่ได้ตรวจ การอนุมัติ motion เป็นของเจ้าของ

`validation.json` ระบุ SHA-256 และจำนวนไบต์ของทุกไฟล์ประกอบ แฮชของ manifest เองเทียบแยกจากไฟล์ที่ fetch กลับ
