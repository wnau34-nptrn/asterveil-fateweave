## สิ่งที่แก้ครบตามคำขอ

1. **HUD สร้างใหม่เป็น DOM/CSS จริง:** ชิปรอบ, คิวภาพ+SPD ที่เลื่อนได้, การ์ดเจตนา, ป้ายชื่อ/HP, ทีม5คน, dock3คำสั่ง, HUDแผนที่ และ D-pad ใช้ components/tokens จริง ภาพด้านหลังเป็นฉาก/ตัวละครล้วนที่ซ่อนHUDเดิมทั้งชุดก่อนจับ ไม่ได้เก็บกรอบHUDไว้แล้วแปะกล่องดำปิดข้อความเดิม ลบ `.hud-label/.hud-readout/.hud-control` ของรอบแรกออกแล้ว
2. **ปิด/ย้อนกลับ:** SVGเส้นจาก `src/ui/svg/close.svg` และ `left.svg`, กล่อง24×24px ในพื้นที่แตะ44×44, stroke `--icon-stroke` ไม่ใช้ตัวอักษร ×/‹
3. **แถบนำทางค่าย:** ไอคอนจากชุดเดิมและชื่อทั้ง6ช่อง พร้อมจำนวนจริง `5+3`, `4`, `6` จาก DOMค่ายของfixture ไม่ตัดbadgeออก R2 Q1และหน้าค่ายใช้navเดียวกัน
4. **บริการค่าย:** คืนภาพและบทพูด NPC ใน `details.npc-fold` ตามแหล่งจริงของแต่ละหน้า รักษาสถานะเปิด/ปิดจากภาพก่อน; ป้ายจ้างยังมีลิงก์ไปเควสต์ในแถบข่าว การ์ดยาปรับเป็นภาพ40px / ข้อความ / ปุ่มกับราคาด้านขวา ทำให้ยา4รายการพอดี390×844 ทั้งR1และR2 รวมเมื่อเปิดบทพูดNPC ไม่ต้องเลื่อนเพื่อหารายการที่4
5. **verify เพิ่ม:** ไอคอนในปุ่ม/summaryต้อง≥20px; หัวต้องมีSVGจริง; ตรวจทุกพื้นทึบ/ภาพในHUDกับbboxตัวละครจากภาพก่อน; ตรวจHUDไม่ตกบรรทัด; R1ตัวเลข12px/R2ตัวเลข11pxจริง; ตรวจpixelของPNG R1/R2ว่าต่างกันจริง; ตรวจNPC/nav/ยา4รายการ; ป้องกันใช้ผลpassเก่าเมื่อสคริปต์ล้ม
6. **แพ็กเกจเล็กลง:** PNGก่อน/หลังเก็บเพียงชุดเดียว ไม่มีPNGใน `export/before-after/` หรือ `export/r1-r2/` อีก หน้าHTMLเปรียบเทียบอ้างภาพชุดเดียว ฟอนต์/artอ้างไฟล์เกม ไม่คัดลอก ลดDOM evidenceด้วยgzipแบบไม่สูญเสียข้อมูล และบีบอัดPNGแบบlosslessโดยไม่ลดสี/ขนาดDPR

## ข้อจำกัดของ 12px ที่แสดงในภาพตรง ๆ

ไม่ลดข้อมูลตัวเลขหรือราคาเพื่อให้พอดี R2เปลี่ยนเฉพาะป้ายตัวเลขล้วนเป็น11px; ชื่อและข้อความทุกอย่างยัง≥12px จึงไม่ได้ทำให้ชื่อยาวขึ้นได้ในR2

ป้ายชื่อศัตรูที่390pxต้องใช้ **ellipsis (…) บรรทัดเดียว** เพื่อไม่ให้แผ่นทึบชนตัวละคร ชื่อเต็มยังเป็นDOM textและtitleของป้าย ไม่แต่งชื่อย่อขึ้นใหม่:

| ขนาด | ชื่อเต็ม | พื้นที่ข้อความจริง / ความกว้างที่ต้องใช้ (CSS px) |
|---|---|---|
| 390×844 | Lv10 แมงมุมเศษผลึก | 81 / 113 |
| 390×844 | Lv10 วิญญาณรอยแยก | 60 / 121 |
| 390×844 | Lv10 ผู้คุมรอยแยก | 81 / 100 |
| 390×650 | Lv10 แมงมุมเศษผลึก | 81 / 113 |
| 390×650 | Lv10 วิญญาณรอยแยก | 76 / 121 |
| 390×650 | Lv10 ผู้คุมรอยแยก | 81 / 100 |

ที่320×568 โครงเกมเดิมไม่แสดงป้ายชื่อศัตรูเต็มอยู่แล้ว คงโครงนั้นและชื่อเต็มในlabelของเป้าหมาย; HPยังแสดงเป็นDOM ไม่เอาชื่อเต็มมายัดลงสนาม
ชื่อแมงมุมที่390×650เลื่อนไปช่องว่างด้านขวาของตัวมัน และHPทุกชิ้นวางพ้นเท้าตัวละคร/ตัวข้างเคียง นี่คือการจัดป้ายภายในสนามเพื่อรักษารูป ไม่ย้ายตัวละครหรือพื้นที่HUDหลัก
R1/R2 Q4เห็นความต่างที่SPD, HP, จำนวน/รอบในภาพจริง ตรวจทั้งfont computedและpixel-differenceครบ6คู่ ไม่อ้างว่า11pxดีกว่าหรือได้รับเลือกแล้ว
รูปแบบHPตัดช่องว่างรอบ `/` เพื่อให้ตัวเลขครบโดยไม่ตกบรรทัด ไม่ตัดเลขใดออก
จอสั้นอื่นยังเลื่อนเนื้อหาบริการตามพื้นที่จริง ไม่ลดอักษรต่ำกว่า12pxเพื่อยัดให้ครบ

## วิธีวัดการบังตัวละคร

`capture-hud.spec.ts` จับภาพก่อนและฉากไม่มีHUDจากเกมบนฐานเดิม แล้วซ่อนร่างทีละตัว **ในbrowserทดสอบเท่านั้น** เพื่อเปรียบเทียบpixelกับฉากเดิม
`measure_character_bounds.py` ใช้ผลต่างRGB>12ที่DPR2เพื่อหาbboxของร่าง/เงาที่วาดจริง ไม่ใช้ช่องatlasที่มีขอบโปร่งใสเป็นbbox
แผนที่ใช้กรอบparty-tokenจากภาพก่อนแบบอนุรักษนิยม รวมกรอบรอบภาพด้วย รวม27กรอบใน3ขนาด
ข้อมูลอยู่ใน `character-bounds.json` และดูภาพก่อนพร้อมเส้นกรอบได้ใน `character-bounds.html`
verifyเปรียบเทียบbboxเหล่านี้กับพื้นbackground/imageที่วาดจริงทุกชิ้นในHUD ของทั้งR1/R2 ไม่ยกเว้นป้ายชื่อหรือHPจากการตรวจ ยกเว้นเฉพาะscene plateที่เป็นฉากอ้างอิง
การinstrumentเป็นroute responseของViteในPlaywright ไม่แก้ไฟล์ `src/` และไม่แก้กฎ/เซฟ/ข้อมูลเกม
