## ประเด็น UX ที่ต้องปรับ

1. **ทางเข้าอยู่กับการจัดทีม:** ผู้เล่นต้องเลือกสมาชิกในผิวหน้าที่ใช้ย้ายทีมด้วย จึงแยกเป้าหมายไม่ชัด เสนอทางเข้าหลัก `ตัวละคร → พัฒนา → อัปดาว` และทางลัดจากจำนวนดาวในภาพรวม หน้าทีมคงลิงก์ “อัปดาว” แทนการใช้ทรัพยากรทันที
2. **ผลก่อน–หลังไม่อยู่ข้างต้นทุน:** ปุ่มเดิมบอกดาว/ราคา แต่ไม่มีตารางผลตัวละครใน memberPanel เสนอเทียบตัวละครคนเดิม โดยคงเลเวลค่าย อุปกรณ์ บาดแผล และ state อื่นเดิม ใช้การจำลองผ่านกฎเดิม ไม่คำนวณสูตรเพิ่ม % ซ้ำใน UI
3. **สาเหตุทำไม่ได้ถูกรวม:** `upgradeReason` ส่ง `dupes` ทั้งกรณีเกินเพดานใช้ตราและตราในคลังไม่พอ แต่ UI ปัจจุบันแสดง “ตัวซ้ำไม่พอ” เหมือนกัน เสนอแยกข้อความด้าน presentation ว่า “ตัวซ้ำขั้นต่ำขาด N”, “ตราขาด N”, “แร่ขาด N” และแสดงพร้อมกันได้ โดยคำสั่งยืนยันยังตรวจผ่าน core เดิมเสมอ
4. **ตัวซ้ำกับตราเข้าใจยาก:** ต้องบอก ใช้/มี/คงเหลือ และเพดานตราขั้นนี้ แสดงว่าใช้ตัวซ้ำก่อน ตราเติมอัตโนมัติตามสูตร ไม่เพิ่ม toggle ที่ทำให้เลือกใช้ตราแทนตัวซ้ำที่มีได้โดยไม่มีกฎรองรับ
5. **ปุ่มเลิกจ้างอยู่ใกล้อัปดาว:** ย้ายการเลิกจ้างไปจัดการสมาชิก/เมนูเพิ่มเติมของตัวละคร คงเงื่อนไขและการยืนยันเดิม ไม่แสดงเป็น CTA คู่กับอัปดาว
6. **ไม่มีหน้าตรวจเฉพาะดาว:** เสนอเพิ่ม review ที่เห็นชื่อคน ดาวถัดไป รายการใช้ ยอดเหลือ และผลที่จะได้ ก่อนปุ่ม “ยืนยันอัปดาว <ชื่อ>” ไม่ทำ auto-repeat หรืออัปหลายดาว

## โครงหน้าจอใน Artwork 03

- หน้า 1 — ดาวปัจจุบัน → ถัดไป, ตัวละคร/เลเวลค่าย, ผลค่าสถานะจาก preview, ผลอื่นที่กฎปัจจุบันให้จริง, ตัวซ้ำ/ตรา/แร่พร้อมยอดมี, เพดานใช้ตรา, “ตรวจรายการอัปเป็น N ดาว”
- หน้า 2 — review: ชื่อคน/ดาว, ใช้ครั้งนี้/คงเหลือ, ผลที่จะได้รับ, ย้อนแก้ไข และยืนยันหนึ่งครั้ง การเปิดหน้านี้ยังไม่เสียทรัพยากร
- หน้า 3 — ตัวซ้ำขั้นต่ำไม่พอแม้มีตรา: แสดงขาดเท่าไร ตราแทนได้เท่าไร และลิงก์ดูแหล่งหาที่เปิดจริง ไม่เสนอซื้อเงินจริงหรืออ้างว่ามีแหล่งฟาร์มที่ยังไม่เปิด

ตัวอย่างที่ใช้ในภาพตรงสูตรปัจจุบัน: ★3→★4 ต้องเทียบเท่าตัวซ้ำ 3 และแร่ 70 ใช้ตราได้ไม่เกิน 2 มีตัวซ้ำ 1/ตรา 3/แร่ 120 จึงใช้ 1/2/70 เหลือ 0/1/50 หากมีตัวซ้ำ 0 ยังทำไม่ได้ แม้มีตรา 3 ตัวอย่างนี้เป็นสถานการณ์ประกอบ ไม่ใช่การปรับราคา

ค่าสถานะในภาพใช้คำว่าเดิม→ใหม่เพื่อไม่แต่งค่าของตัวละคร ค่า preview จริงต้องมาจาก state และข้อมูลอาชีพปัจจุบัน ไม่เพิ่ม SPD/เทิร์น/สกิลพิเศษด้วย artwork

## สถานะเพิ่มเติมและเกณฑ์ตรวจรับ

| กรณี | สิ่งที่ต้องแสดง/ตรวจ |
| --- | --- |
| ตราขาดแต่ตัวซ้ำขั้นต่ำพอ | บอกจำนวนตราที่ต้องใช้/ขาดจริง ไม่เหมารวมว่าตัวซ้ำขาด |
| มีตัวซ้ำครบ | ใช้ตัวซ้ำครบและตรา 0 ตาม upgradeCost; ตราแสดงว่าไม่ใช้หรือซ่อนอย่างมีเหตุผล |
| ขาดหลายทรัพยากร | แสดงขาดแยกทุกชนิด ไม่ให้ผู้เล่นแก้ทีละอย่างเพื่อพบข้อจำกัดถัดไป |
| ★5 เต็ม | แสดง 5 ดาวเต็มและ “ดาวสูงสุดแล้ว” ไม่มีปุ่มหักทรัพยากร; ไม่สร้างคำสั่งเลื่อนอาชีพก่อนระบบพร้อม |
| เปลี่ยนตัวละคร | ยกเลิก review เดิม สร้าง preview/ต้นทุนใหม่โดยไม่ส่งคำสั่ง |
| profile เปลี่ยนระหว่าง review | invalidate review; คำนวณใหม่และให้ตรวจอีกครั้งก่อนยืนยัน |
| ยืนยันสำเร็จ | แสดงดาว/ทรัพยากรจากผลจริง ข้อความประกาศให้ screen reader, กลับคนเดิม ไม่ auto-upgrade ขั้นถัดไป |
| ย้อนกลับ/Escape | ไม่หักของ คืนแท็บพัฒนาและ focus ต้นทาง เก็บ filter/scroll ของ roster |
| ระหว่างเดินทาง/ต่อสู้ | แสดงตาม capability เดิมของค่าย ไม่เปิดการอัปดาวบนแผนที่/กลางศึกเอง |
