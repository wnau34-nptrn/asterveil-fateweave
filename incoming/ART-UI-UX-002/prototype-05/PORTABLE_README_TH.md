# ต้นแบบหน้าตีบวก Asterveil: Fateweave

แตก ZIP ทั้งชุด แล้วเปิด terminal ในโฟลเดอร์ที่มี README นี้ รัน:

```sh
python3 -m http.server 5185 --bind 127.0.0.1
```

เปิด http://127.0.0.1:5185/prototype-05/ ใน browser ของเครื่องเดียวกัน ไม่ต้องติดตั้ง npm หรือเชื่อมเกม

เลือกตัวอย่างพร้อม/ไม่พอ/ถึงเพดาน/ไม่มีผู้สวม/ชื่อยาวจากแผงนอกกรอบ ลองตรวจรายการ กลับแก้ไข ยืนยัน ดูขั้นถัดไป เปลี่ยนชิ้น ล็อก รายละเอียด และปิดกลับหน้าต้นทางจำลองได้ แผงทดลองบนจอมือถืออยู่ใต้กรอบ

ข้อมูลทั้งหมดอยู่ในหน่วยความจำ รีโหลดหรือกดเริ่มใหม่เพื่อreset ไม่เชื่อมบัญชี เซฟ หรือAPIเกม และไม่ใช้ของจริง
