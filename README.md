# Asterveil: Rise Beyond

Independent Fateweave browser-game project.

## สาขาที่พัฒนาเกม (Development branch)

โค้ดเกม, asset และเอกสารการผลิตอยู่ในสาขา **`feature/fateweave-initial-prototype`** ไม่ได้อยู่ใน `main`

- `main` มีเพียง README, `CLAUDE.md` และ workflow ที่ต้องอยู่บน `main` เพื่อให้สั่งรันด้วยมือได้ (เช่น `.github/workflows/cloudflare-load.yml`)
- งานใหม่ให้แตกสาขาจาก `feature/fateweave-initial-prototype` และรวมกลับเข้าสาขานั้น
- สาขาอื่นเป็นสาขางานย่อย เช่น `art/*` (งานภาพ) และ `claude/*`

Game code, assets and production docs live on the `feature/fateweave-initial-prototype` branch, not on `main`.
